## Story Summary

V2.10.S15 ports Firedancer's `fd_shmem` shared memory infrastructure to macOS and Windows, enabling Tickoni's multi-process tile architecture to run on all three platforms. The implementation deviated from the spec's planned separate `cross_shmem.zig` modules and instead extended the existing C shim layer (`wksp.c`, `topo_run_platform_*.c`, `os.c`) with cross-platform implementations, added `process_api.zig` updates for Windows process polling, and created `topo_run_platform_common.h` to reduce duplication.
