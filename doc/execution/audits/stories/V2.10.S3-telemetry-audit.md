## 3. Diagnostic Signal Audit (telemetry.md §Phase 0 Diagnostics)

**Finding: PASS — no diagnostic signals added.**

Phase 0 diagnostics are produced by `PaymentPipelineState.snapshotDiag()` in the Zig runtime (`src/app/tickoni/supervisor.zig` and `src/tickoni/tiles/payment_pipeline.zig`). The Qt terminal files are entirely independent of this runtime path:

- `CMakeLists.txt` — no diagnostic registration, no `snapshotDiag()` calls.
- `main.cpp` — standard Qt app bootstrap; returns from `main()` or `app.exec()`. No diagnostic snapshot logic.
- `Main.qml` — pure presentation; no diagnostic output.

The `build-qt` justfile recipe invokes CMake only; it does not print or capture diagnostic signals. No Phase 0 snapshot pattern is affected.
