# Plan: Periodic Metric Sampling for "No Black Boxes" Audit Fix

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Fix V2.22.S4 telemetry audit FAIL #1 ("No black boxes") by adding per-tile metric sampling every ~1 second during pipeline execution, making all tiles visible during runtime instead of only at the end.

**Architecture:** The supervisor already has `snapshotMetrics()` (thread mode) and `snapshotProcessMetrics()` (process mode) that read atomic counters. Currently these are called once at the very end in `cmdStart` / `cmdStartProcess`. The fix: wrap `sup.wait()` / the polling loop in a sampling loop that calls snapshot every ~1s, prints deltas with per-tile breakdown, and stops on pipeline completion. No shared memory port needed — works on both modes.

**Tech Stack:** Zig runtime supervisor, existing `PaymentPipelineState.MetricSnapshot`, `Supervisor.ProcessMetricSnapshot`, `std.fmt.bufPrint`, `std.time`.

## Task 3: Add per-tile delta printing helper

**Objective:** Create a helper that compares two snapshots and prints per-tile deltas.

**Files:**
- Create: `src/app/tickoni/metric_watchdog.zig`

**Step 1: Write the file**

```zig
/// Periodic metric sampling and delta printing for the supervisor.
///
/// This file implements the "No Black Boxes" audit fix: tiles produce
/// counters visible every ~1 second during execution, not only at the end.
const std = @import("std");
const util = @import("util");
const logger = @import("logger");
const rt = @import("runtime");

pub const TileMetricSnapshot = struct {
    tile_id: [6]u8,
    produced: u64,
    normalized: u64,
    invalid: u64,
    duplicates: u64,
    allowed: u64,
    denied: u64,
    audited: u64,
};

pub fn printPerTileDeltas(
    stdout: std.Io.Writer,
    prev: []const TileMetricSnapshot,
    curr: []const TileMetricSnapshot,
) !void {
    const log = logger.get();
    const count = @min(prev.len, curr.len);
    for (prev[0..count], 0..) |p, i| {
        const c = curr[i];
        const delta_prod = @as(i64, @intCast(c.produced)) - @as(i64, @intCast(p.produced));
        const delta_norm = @as(i64, @intCast(c.normalized)) - @as(i64, @intCast(p.normalized));
        const delta_inv = @as(i64, @intCast(c.invalid)) - @as(i64, @intCast(p.invalid));
        const delta_dup = @as(i64, @intCast(c.duplicates)) - @as(i64, @intCast(p.duplicates));
        const delta_allow = @as(i64, @intCast(c.allowed)) - @as(i64, @intCast(p.allowed));
        const delta_deny = @as(i64, @intCast(c.denied)) - @as(i64, @intCast(p.denied));
        const delta_audit = @as(i64, @intCast(c.audited)) - @as(i64, @intCast(p.audited));
        const id_str = std.mem.asBytes(&c.tile_id)[0..6];
        const line = try std.fmt.allocPrint(
            stdout.allocator,
            "  tile={s}  dP={d} dN={d} dI={d} dD={d} dA={d} dR={d} dU={d}\n",
            .{ id_str, delta_prod, delta_norm, delta_inv, delta_dup, delta_allow, delta_deny, delta_audit },
        );
        defer stdout.allocator.free(line);
        try stdout.writeAll(line);
    }
}
```

Wait — `stdout.allocator` may not exist in this IO abstraction. Fix to use a buffer:

```zig
/// Print per-tile metric deltas between two snapshots to stdout.
/// Uses a fixed buffer to avoid heap allocation during the sampling loop.
pub fn printPerTileDeltas(
    stdout: std.Io.Writer,
    prev: []const TileMetricSnapshot,
    curr: []const TileMetricSnapshot,
) !void {
    const count = @min(prev.len, curr.len);
    for (prev[0..count], 0..) |p, i| {
        const c = curr[i];
        const delta_prod = @as(i64, @intCast(c.produced)) - @as(i64, @intCast(p.produced));
        const delta_norm = @as(i64, @intCast(c.normalized)) - @as(i64, @intCast(p.normalized));
        const delta_inv = @as(i64, @intCast(c.invalid)) - @as(i64, @intCast(p.invalid));
        const delta_dup = @as(i64, @intCast(c.duplicates)) - @as(i64, @intCast(p.duplicates));
        const delta_allow = @as(i64, @intCast(c.allowed)) - @as(i64, @intCast(p.allowed));
        const delta_deny = @as(i64, @intCast(c.denied)) - @as(i64, @intCast(p.denied));
        const delta_audit = @as(i64, @intCast(c.audited)) - @as(i64, @intCast(p.audited));
        var buf: [256]u8 = undefined;
        const line = try std.fmt.bufPrint(
            &buf,
            "  tile={s}  dP={d} dN={d} dI={d} dD={d} dA={d} dR={d} dU={d}\n",
            .{ c.tile_id, delta_prod, delta_norm, delta_inv, delta_dup, delta_allow, delta_deny, delta_audit },
        );
        try stdout.writeAll(line);
    }
}
```

```zig
    try sup.startPaymentPipeline(.{ .event_count = 10_000, .queue_depth = 64 });
    log.debug("main", "cmdStart", "pipeline started, monitoring tiles") catch {};

    // Periodic metric sampling — visible per-tile deltas every ~1s.
    // Fixes V2.22.S4 "No black boxes" audit FAIL #1.
    const sample_interval_ns: u64 = 1 * std.time.ns_per_s;
    const max_samples: u32 = 600; // 10 min bound
    var sample_count: u32 = 0;

    // Initialize previous snapshot
    var prev_snap = sup.pipeline.?.snapshotMetrics();
    const prev_time = std.time.timestamp();
    var prev_lines_buf: [8192]u8 = undefined;
    const prev_line = try std.fmt.bufPrint(
        &prev_lines_buf,
        "produced={d} normalized={d} invalid={d} dup={d} allow={d} deny={d} audited={d}\n",
        .{ prev_snap.produced, prev_snap.normalized, prev_snap.invalid, prev_snap.duplicates, prev_snap.allowed, prev_snap.denied, prev_snap.audited },
    );

    // Poll for completion with per-tile delta output
    while (sample_count < max_samples) : (sample_count += 1) {
        if (prev_snap.audited >= 10_000) break;
        util.process.sleepNanos(sample_interval_ns);
        util.process.sleepNanos(sample_interval_ns);

        const cur_snap = sup.pipeline.?.snapshotMetrics();
        const cur_time = std.time.timestamp();
        var cur_lines_buf: [8192]u8 = undefined;
        const cur_line = try std.fmt.bufPrint(
            &cur_lines_buf,
            "produced={d} normalized={d} invalid={d} dup={d} allow={d} deny={d} audited={d}\n",
            .{ cur_snap.produced, cur_snap.normalized, cur_snap.invalid, cur_snap.duplicates, cur_snap.allowed, cur_snap.denied, cur_snap.audited },
        );

        // Print deltas if counters changed
        const d_prod = @as(i64, @intCast(cur_snap.produced)) - @as(i64, @intCast(prev_snap.produced));
        const d_norm = @as(i64, @intCast(cur_snap.normalized)) - @as(i64, @intCast(prev_snap.normalized));
        const d_inv = @as(i64, @intCast(cur_snap.invalid)) - @as(i64, @intCast(prev_snap.invalid));
        const d_dup = @as(i64, @intCast(cur_snap.duplicates)) - @as(i64, @intCast(prev_snap.duplicates));
        const d_allow = @as(i64, @intCast(cur_snap.allowed)) - @as(i64, @intCast(prev_snap.allowed));
        const d_deny = @as(i64, @intCast(cur_snap.denied)) - @as(i64, @intCast(prev_snap.denied));
        const d_audit = @as(i64, @intCast(cur_snap.audited)) - @as(i64, @intCast(prev_snap.audited));
        if (d_prod != 0 or d_norm != 0 or d_inv != 0 or d_dup != 0 or d_allow != 0 or d_deny != 0 or d_audit != 0) {
            const delta_line = try std.fmt.bufPrint(
                &buf,
                "  delta @ {}s:  P={d} N={d} I={d} D={d} A={d} R={d} U={d}\n",
                .{ cur_time - prev_time, d_prod, d_norm, d_inv, d_dup, d_allow, d_deny, d_audit },
            );
            try stdout.writeAll(delta_line);
            try stdout.writeAll("\n");
        }

        prev_snap = cur_snap;
        prev_time = cur_time;
    }

    log.debug("main", "cmdStart", "pipeline completed") catch {};
```

```zig
    log.debug("main", "cmdStartProcess", "process-mode pipeline started, monitoring tiles") catch {};

    // Periodic metric sampling for "No Black Boxes" — visible per-tile deltas.
    const sample_interval_ns: u64 = 1 * std.time.ns_per_s;
    const max_samples: u32 = 600; // 10 min bound
    var sample_count: u32 = 0;

    // Collect per-tile snapshots for delta comparison.
    var prev_per_tile: [8]ProcessMetricSnapshot = undefined;
    for (&prev_per_tile, 0..) |*s, i| {
        if (sup.snapshotProcessMetricsForTile(i)) |snap| s.* = snap else |e| return e;
    }

    // Poll for pipeline completion with per-tile delta output
    while (sample_count < max_samples) : (sample_count += 1) {
        if (sup.snapshotProcessMetrics().audited >= process_config.event_count) break;
        util.process.sleepNanos(sample_interval_ns);
        util.process.sleepNanos(sample_interval_ns);

        const curr_per_tile: [8]ProcessMetricSnapshot = blk: {
            var result: [8]ProcessMetricSnapshot = undefined;
            for (&result, 0..) |*s, i| {
                if (sup.snapshotProcessMetricsForTile(i)) |snap| s.* = snap else |e| return e;
            }
            break :blk result;
        };

        // Print per-tile deltas
        try metric_watchdog.printPerTileDeltas(stdout, &prev_per_tile, &curr_per_tile);
        try stdout.writeAll("\n");

        for (0..curr_per_tile.len, 0..) |s, i| {
            prev_per_tile[i] = curr_per_tile[i];
        }
    }
```

**Step 2: Add `snapshotProcessMetricsForTile` to supervisor**

In `src/app/tickoni/supervisor.zig`, add after `snapshotProcessMetrics`:

```zig
    /// Read metrics for a single tile in process-mode.
    pub fn snapshotProcessMetricsForTile(self: *const Supervisor, tile_idx: usize) !ProcessMetricSnapshot {
        const state = self.process_state orelse return error.NoProcessState;
        const h = self.handles[tile_idx];
        const tile = self.topo.tiles[tile_idx];
        const cnc = state.cncs[tile_idx] orelse return error.CncNotFound;
        const entry = tile_registry.findById(tile.id) orelse return error.TileNotFound;
        var snap = ProcessMetricSnapshot{};
        for (entry.counters) |c| {
            const v = rt.cnc_counters.appCounterRead(cnc, c.idx);
            switch (c.field) {
                .produced => snap.produced = v,
                .normalized => snap.normalized = v,
                .invalid => snap.invalid = v,
                .duplicates => snap.duplicates = v,
                .allowed => snap.allowed = v,
                .denied => snap.denied = v,
                .audited => snap.audited = v,
            }
        }
        return snap;
    }
```

## Risk Assessment

| Risk | Likelihood | Mitigation |
|---|---|---|
| Thread mode `sup.wait()` blocks for too long, preventing sampling | Low | The poll loop checks `audited >= event_count` each iteration — as soon as pipeline finishes, sampling stops. |
| Process mode cnc counter reads are slow at 1s interval | None | `appCounterRead` is a single load from a memory-mapped region — microseconds, not milliseconds. |
| Delta printing adds noise to CI logs | Medium | Output is structured and grep-friendly; CI can filter on `delta @` or `tile=` prefixes. |
| Max sample bound not reached before pipeline finishes | Low | 10-minute bound is far more than any realistic test run. |
