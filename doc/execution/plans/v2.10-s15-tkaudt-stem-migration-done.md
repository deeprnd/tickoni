# tkaudt — fd_stem Migration Plan

> **For Hermes:** Execute tasks sequentially. Each task is self-contained — the build compiles after each one. The full pipeline hangs after tkaudt migrates until the upstream tiles (tkings→tknorm→tkdedu→tkpoly) are also migrated.

**Goal:** Migrate tkaudt from the `tile_process.zig` WorkFn closure pattern to Firedancer's `fd_stem` callback lifecycle. tkaudt is the simplest pipeline tile to migrate: 1 input link, 0 output links, single callback (`DURING_FRAG`) maps nearly 1:1 to the existing `while(pop())` loop.

**Prerequisite:** tkpoly must be migrated to fd_stem first, so tkaudt receives fragments from a stem-driven producer.

**Key files:**
- Tile business logic (unchanged): `src/tickoni/tiles/payment_pipeline/audit_stage.zig` (pure logic), `src/tickoni/tiles/payment_pipeline/audit_sink.zig` (record builder)
- Process-mode harness (modified): `src/tickoni/runtime/tile_process.zig`, `src/tickoni/c_abi/shim/tile_run.c`
- Tile shim (new): `src/tickoni/c_abi/shim/tk_audit_stem.c`
- Reference implementation: `src/tickoni/c_abi/shim/tk_metric_tile.c`
- Firedancer stem: `src/disco/stem/fd_stem.c`

## Current State (Before Migration)

### Thread-mode spike (audit_stage.zig)

```zig
pub fn runAudit(state: *PaymentPipelineState) void {
    var offset: u64 = 0;
    while (state.q_poly_audit.pop(&state.stop)) |msg| {
        offset += 1;
        queue.updateMaxU64(&state.max_latency_hops, @as(u64, msg.pipeline_hops) + 1);
        state.audit.append(.{
            .source_offset = msg.raw.source_offset,
            .event_hash = msg.event_hash,
            .decision = @fromBackingInt(@intCast(@backingInt(msg.decision))),
            .tile_id = msg.decided_by,
        }) catch {
            state.crashed_tile.store(4, .release);
            state.requestStop();
            log.err("tkaudt", "runAudit", "audit log append failed");
            break;
        };
        _ = state.audited.fetchAdd(1, .release);
        log.kvFmt("tkaudt", "runAudit", "offset={d} event_hash={x} decided_by={d}", .{ msg.raw.source_offset, msg.event_hash, msg.decided_by[0] });
    }
    state.audit_done.store(true, .release);
}
```

### Process-mode (process.zig → runAuditProcess)

```zig
pub fn runAuditProcess(
    process_cfg: ProcessRuntimeConfig,
    tile_idx: u32,
    input: *rt.link.Consumer,
    cnc: *c_abi.cnc.Cnc,
    audit_log: *audit_sink.AuditLog,
) void {
    const cfg = process_cfg.pipeline;
    var buf: [msg_size]u8 = undefined;
    var audited: u64 = 0;
    var i: u64 = 0;
    while (i < cfg.event_count) : (i += 1) {
        maybeBlockForTest(process_cfg, tile_idx, i);
        if (halted(cnc)) break;
        _ = input.consume(&buf, &idle_polls, &stop_flag, cnc) orelse break;
        const msg = std.mem.bytesToValue(PaymentMessage, buf[0..msg_size]);
        audit_log.append(.{
            .source_offset = msg.raw.source_offset,
            .event_hash = msg.event_hash,
            .decision = @fromBackingInt(@intCast(@backingInt(msg.decision))),
            .tile_id = msg.decided_by,
        }) catch break;
        audited += 1;
    }
    rt.cnc_counters.appCounterWrite(cnc, 0, audited);
}
```

**Link shape:** 1 input (from tkpoly), 0 outputs. Consumes `PaymentMessage` fragments from dcache.

## Fragment Format

### Input: PaymentMessage Fragment

tkaudt receives the same `PaymentMessage` struct that tkpoly emits. No new fragment type needed — it's the standard pipeline message:

```c
/* PaymentMessage — received from tkpoly, consumed in DURING_FRAG */
typedef struct {
    RawPayment raw;           /* source_offset, idempotency_key, account_id, amount_cents, currency */
    uint64_t event_hash;      /* stable event hash (from tknorm or tkpoly) */
    uint8_t pipeline_hops;    /* hop counter */
    uint8_t duplicate;        /* dedupe flag */
    uint8_t decision;         /* PolicyOutcome enum */
    uint8_t decided_by[6];    /* tile id that decided (tknorm/tkpoly) */
} PaymentMessage;

/* RawPayment */
typedef struct {
    uint64_t source_offset;
    uint64_t idempotency_key;
    uint32_t account_id;
    int64_t amount_cents;
    uint8_t currency[3];
    uint8_t malformed;
} RawPayment;

#define PAYMENT_MSG_SIZE sizeof(PaymentMessage)
```

## tkaudt Context

```c
/* tk_audit_ctx_t — tkaudt stem tile context */
typedef struct {
    /* Audit state */
    uint64_t audited;           /* Total audit records written */
    uint64_t max_latency_hops;  /* Peak pipeline depth */
    uint64_t consecutive_empty; /* Ticks with no DURING_FRAG */
    
    /* Lifecycle */
    int32_t input_exhausted;    /* Set after N idle ticks */
    int32_t done;               /* Set when replay_checked or HALT */
    
    /* CNC reference (set in unprivileged_init) */
    void *cnc;                  /* fd_cnc_t* for HALT detection */
    
    /* Audit log (owned by scratch space) */
    uint64_t audit_count;
    uint64_t prev_hash;         /* Hash chain: seed on first record */
    /* Audit events stored in a pre-allocated array in scratch */
} tk_audit_ctx_t;

#define TKAUDT_CTX_ALIGN alignof(tk_audit_ctx_t)
#define TKAUDT_IDLE_THRESHOLD 1000  /* Ticks before marking input_exhausted */
#define TKAUDT_AUDIT_CAPACITY 16384 /* Pre-allocatable audit record slots */
```

## tkaudt DURING_FRAG (consume + audit)

```c
#ifndef STEM_CALLBACK_DURING_FRAG
#define STEM_CALLBACK_DURING_FRAG tk_audit_during_frag
#endif

static void
tk_audit_during_frag( tk_audit_ctx_t * ctx,
                      ulong            in_idx,
                      ulong            seq,
                      ulong            sig,
                      ulong            chunk,
                      ulong            sz,
                      uint             ctl ) {
    /* 1. Validate fragment size */
    if (sz != PAYMENT_MSG_SIZE) return;
    
    /* 2. Parse PaymentMessage from fragment chunk */
    PaymentMessage * msg = (PaymentMessage *)chunk;
    
    /* 3. Update max_latency_hops */
    uint64_t hops = (uint64_t)msg->pipeline_hops + 1;
    if (hops > ctx->max_latency_hops)
        ctx->max_latency_hops = hops;
    
    /* 4. Append to audit log (hash-chained) */
    audit_event_t event;
    buildAuditEvent(&event, ctx->audit_count, msg, ctx->prev_hash);
    
    if (appendAuditRecord(&ctx->audit_records[ctx->audit_count], &event)) {
        ctx->prev_hash = event.header.record_hash;
        ctx->audit_count += 1;
        ctx->consecutive_empty = 0;
    } else {
        /* Audit log full — record crash, signal stop */
        /* TODO: set crashed_tile atomic, signal HALT via CNC */
        return;
    }
    
    /* 5. Update CNC counter: audited */
    fd_cnc_app_counter_write((fd_cnc_t *)ctx->cnc, 0, ctx->audited);
    ctx->audited += 1;
}
```

## tkaudt BEFORE_CREDIT (idle tracking)

```c
#ifndef STEM_CALLBACK_BEFORE_CREDIT
#define STEM_CALLBACK_BEFORE_CREDIT tk_audit_before_credit
#endif

static void
tk_audit_before_credit( tk_audit_ctx_t * ctx,
                        fd_stem_t *      stem,
                        int *            charge_busy ) {
    /* Track consecutive ticks with no DURING_FRAG.
     * After N consecutive ticks, mark input_exhausted so
     * SHOULD_SHUTDOWN can exit. */
    ctx->consecutive_empty += 1;
    if (ctx->consecutive_empty >= TKAUDT_IDLE_THRESHOLD) {
        ctx->input_exhausted = 1;
    }
    *charge_busy = 0;
    (void)stem;
}
```

#ifndef STEM_CALLBACK_SHOULD_SHUTDOWN

4. Implement `tk_audit_unprivileged_init` — find CNC, set `ctx->cnc`, log startup
5. Implement `tk_audit_run` — find scratch, set `ctx->cnc`, call `stem_run`
6. Define `TK_AUDIT_RUN` — `fd_topo_run_tile_t` with all callbacks wired

- tkaudt has 1 input link (vs 0 for metric), so `DURING_FRAG` fires

- tkaudt idle threshold tracking is different from metric's heartbeat

## Key Design Decisions

1. **Single DURING_FRAG callback.** tkaudt has no output links, so no AFTER_CREDIT needed. The `while(pop())` loop maps directly to `DURING_FRAG` — each fragment is one audit event.

2. **Idle threshold for shutdown.** Unlike tiles with explicit "work complete" counts, tkaudt has no external "done" signal from tkpoly. It tracks consecutive empty ticks and sets `input_exhausted` after 1000 idle ticks. This is the same pattern tk_metric uses for HTTP server idle detection.

3. **Audit log in scratch space.** The audit log (`AuditLog` struct from audit_sink.zig) is allocated from the tile's scratch space, not shared memory. Each tile process owns its own audit log. This matches the process-mode pattern where dedup state and audit log are local to each tile's process.

4. **No hash chaining beyond scratch.** The hash chain (prev_hash → record_hash) is maintained in the tile's scratch context. If the tile crashes and restarts, the audit log is fresh — this is intentional for process-mode isolation.

5. **CNC counter for audited.** The same CNC counter index (0) and field (.audited) as the process-mode registry already uses, so supervisor monitoring works without changes.

---

## Risks and Mitigations

1. **Fragment size mismatch:** PaymentMessage is ~64 bytes, well within typical dcache MTU (128). No fragmentation concerns.

2. **Audit log overflow:** If tkpoly produces more events than the pre-allocated audit capacity, append fails. Mitigated by setting audit capacity to event_count (same as process-mode). Crash-on-full behavior is intentional — audit log full is a fatal condition.

3. **Idle threshold tuning:** 1000 ticks may be too aggressive or too conservative. The threshold should be tuned based on actual tkpoly→tkaudt message throughput. Start with 1000 and adjust if the tile exits prematurely or hangs.

4. **Hash chain reset on restart:** Each process-mode restart creates a fresh audit log with a new hash chain. This is correct for process isolation — each tile process is an independent audit trail. Cross-tile audit correlation happens via shared event_hash, not the intra-tile prev_hash chain.

5. **Platform parity:** On non-Linux, tkaudt falls back to WorkFn (process-mode) until the stem shim is ported. This means two code paths exist temporarily, matching the existing tk_metric pattern.
