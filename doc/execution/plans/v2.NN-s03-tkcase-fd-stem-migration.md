## Gap Analysis

### What exists today

| Component | Current state |
|-----------|---------------|
| tkcase placeholder | `tk_pass_stem.c` — forwards every fragment unchanged to all outputs. No case state, no routing, no capsule creation |
| tkcase in tile_registry | `.launch_mode = .stem, .process_fn = null, in_cnt=1, out_cnt=2` |
| tkcase in topology | tile index 3, name="tkcase", channels: [tkdedu→tkcase (depth=64, mtu=128), tkcase→tkpoly (depth=64, mtu=128), tkcase→tkdisp (depth=64, mtu=128)] |
| tkcase stem files | `tk_pass_stem.c` — shared implementation with tktool/tkadpt (TK_CASE_RUN, TK_TOOL_RUN, TK_ADPT_RUN) |
| audit_schema.h | RECORD_CASE_CREATION = 13, TILE_ID_TKCASE defined |
| WireCaseCreationPayload | basket_id, instrument_count, rejected_count, total_allocated_cents (512-bit) — exists for case creation audit |
| tkaudt stem | 435 lines, 1-in/0-out — reference for audit record emission |
| tknorm stem | 1-in/1-out, DURING_FRAG + AFTER_CREDIT — reference for multi-output publish |
| tkdisp stem | 2-in/1-out, scheduler pattern — reference for reading from tkcase |

### What's missing

The tkcase stem tile needs to implement:

1. **Case scope creation** — when the first event arrives for a new run, create a case scope: case_id (deterministic from workflow + account + timestamp), workflow, actor_id, account_id, initial scope. Store in scratch.
2. **Case lifecycle** — track case state (created → active → completed). Emit case lifecycle transitions to audit.
3. **Event attachment** — every event flowing through tkcase is attached to the active case (case_id stamped in event metadata).
4. **Capsule building** — accumulate all events, model calls, tool calls, policy decisions, and adapter results for the case into a capsule structure in scratch. This is the **source of truth** for replay (UC-11) and forensic verification.
5. **Deterministic forwarding** — forward events to tkpoly and tkdisp with case_id attached (preserving original content).
6. **Case completion** — when event_count is exhausted, mark case as completed, emit final audit record, and trigger shutdown.
7. **Scratch layout** — case scope struct, capsule ring buffer, counters, flags.

### Key differences from tknorm

| Aspect | tknorm (1-in, 1-out) | tkcase (1-in, 2-out) |
|--------|----------------------|----------------------|
| Output links | 1 — single publish | 2 — fan-out to tkpoly AND tkdisp |
| Event processing | Validates framing, hashes, stamps decision | Creates case scope, attaches to case, forwards unchanged |
| State | Simple counters | Case scope (case_id, workflow, actor, account), capsule ring buffer |
| Output buffer | Scratch-reserved PaymentMessage | Scratch-reserved slot per output (or single buffer with 2 publishes) |
| Lifecycle | Process each event independently | First event triggers case creation; last event triggers completion |
| Audit emission | N/A (tknorm doesn't audit) | Must emit RECORD_CASE_CREATION and RECORD_CASE_COMPLETION to tkaudt |

### Key differences from tkaudt

tkaudt is a sink tile (1-in, 0-out) that only receives and stores. tkcase is a pipeline tile (1-in, 2-out) that must both process events AND forward them. tkcase must emit its own audit records to tkaudt via a separate audit link.

## Task 1: Create tkcase stem C file

### 1a: Create `src/tickoni/c_abi/shim/tk_case_stem.c`

**Scope of this migration:** Create the tkcase stem tile that:
1. Creates case scope on first event
2. Forwards every event to both outputs (tkpoly, tkdisp) with case_id attached
3. Builds a capsule ring buffer of all events
4. Emits RECORD_CASE_CREATION and RECORD_CASE_COMPLETION audit records to tkaudt
5. Shuts down cleanly when event_count exhausted

**Structure:**

```c
/* tk_case_stem.c — fd_stem tile for tkcase (case router).
 *
 * Tile behavior:
 *   - On first event: creates case scope (case_id = deterministic from
 *     workflow + account + timestamp), stores in scratch
 *   - DURING_FRAG: read event, validate, copy to scratch staging
 *   - AFTER_FRAG: forward to both outputs (tkpoly, tkdisp), build capsule entry,
 *     emit RECORD_CASE_CREATION on first event, emit RECORD_CASE_COMPLETION
 *     when event_count exhausted
 *   - SHOULD_SHUTDOWN: event_count exhaustion + CNC HALT
 *
 * Follows fd_stem callback contract in stem_helpers.h: DURING_FRAG stages,
 * AFTER_FRAG commits, publishes at most 2 fragments (one per output).
 */

#define _GNU_SOURCE

#include "firedancer.h"
#include "audit_schema.h"
#include "../stem_helpers.h"

#include "disco/topo/fd_topo.h"
#include "util/wksp/fd_wksp.h"
#include "util/fd_util.h"

#include <string.h>
#include <stddef.h>

/* ─── Constants ─── */

#define TKCASE_MAX_OUTS       2UL       /* tkpoly + tkdisp */
#define TKCASE_MAX_MTU        512UL     /* largest link these tiles use */
#define TKCASE_CASE_ID_LEN    32UL      /* case_id string buffer */
#define TKCASE_CASES_CAP      1UL       /* current V1: single active case */

/* ─── Case scope ─── */

typedef struct {
    uint8_t  case_id[TKCASE_CASE_ID_LEN];     /* deterministic case identifier */
    uint8_t  workflow[32];                    /* e.g. "investigation" or "trading_order" */
    uint64_t actor_id;                        /* logical actor who initiated the case */
    uint64_t account_id;                      /* account under which the case runs */
    uint64_t created_ns;                      /* creation timestamp */
    uint8_t  state;                           /* 0=created, 1=active, 2=completed */
    uint64_t event_count_total;               /* total events in case */
    uint64_t event_count_forwarded;           /* events forwarded so far */
} tkcase_case_t;

/* ─── Capsule entry — one per event, stored in ring buffer ─── */

typedef struct {
    uint64_t source_offset;       /* original source offset */
    uint64_t seq;                 /* sequence number within run */
    uint8_t  tile_id[6];          /* producer tile id */
    uint8_t  _pad[2];
    uint64_t payload_hash;        /* hash of the event payload */
    uint64_t timestamp_ns;        /* event timestamp */
    uint8_t  content[TKCASE_MAX_MTU];  /* the actual event bytes */
    uint16_t content_sz;         /* length of content bytes */
} tkcase_capsule_entry_t;

/* ─── Context ─── */

typedef struct {
    /* Case state */
    tkcase_case_t  active_case;
    int            case_created;      /* 1 if first event has triggered creation */
    int            case_completed;    /* 1 if final event has been processed */

    /* Counters */
    uint64_t consumed;            /* fragments committed from input */
    uint64_t forwarded;           /* fragments forwarded to outputs */
    uint64_t case_audit_emitted;  /* case creation/completion audits emitted */

    /* Event staging (set in during_frag, consumed in after_frag) */
    int      stage_valid;
    ulong    stage_sz;
    uint8_t  stage[TKCASE_MAX_MTU];

    /* Capsule ring buffer */
    tkcase_capsule_entry_t capsule[TKCASE_MAX_OUTS];  /* one slot per output (shared) */
    uint64_t capsule_next;       /* next write index */

    /* Output workspace and dcache tracking */
    void *   cnc;
    void *   wksp;              /* input workspace */
    void *   out_wksp[TKCASE_MAX_OUTS];
    ulong    out_chunk0[TKCASE_MAX_OUTS];
    ulong    out_wmark[TKCASE_MAX_OUTS];
    ulong    out_chunk[TKCASE_MAX_OUTS];

    /* Output staging — one buffer per output (set in after_frag, published) */
    uint8_t  out_buf[TKCASE_MAX_OUTS][TKCASE_MAX_MTU];
    uint64_t out_sz[TKCASE_MAX_OUTS];
    int      out_ready[TKCASE_MAX_OUTS];

    /* Event count gating */
    uint64_t event_count;
    int      input_exhausted;

    /* Tile pointer */
    fd_topo_tile_t const *tile;

    /* Scratch-allocated output buffers */
    void * out_scratch[TKCASE_MAX_OUTS];
} tkcase_ctx_t;

#define TKCASE_CTX_ALIGN alignof(tkcase_ctx_t)

/* ─── Generate stem specialization ─── */

#define STEM_NAME                         tkcase
#define STEM_BURST                        (TKCASE_MAX_OUTS)
#define STEM_LAZY                         ((long)10e6)
#define STEM_CALLBACK_CONTEXT_TYPE        tkcase_ctx_t
#define STEM_CALLBACK_CONTEXT_ALIGN       TKCASE_CTX_ALIGN
#define STEM_CALLBACK_DURING_HOUSEKEEPING(ctx) stk_cnc_liveness( (ctx)->cnc )
#define STEM_CALLBACK_DURING_FRAG         tkcase_during_frag
#define STEM_CALLBACK_AFTER_FRAG          tkcase_after_frag
#define STEM_CALLBACK_SHOULD_SHUTDOWN(ctx) \
  ( (ctx)->input_exhausted || \
    ( (ctx)->case_completed ) || \
    ( (ctx)->cnc && fd_cnc_signal_query( (fd_cnc_t *)(ctx)->cnc ) == FD_CNC_SIGNAL_HALT ) )

#include "disco/stem/fd_stem.c"

#undef STEM_NAME
#undef STEM_CALLBACK_CONTEXT_TYPE
#undef STEM_CALLBACK_CONTEXT_ALIGN
#undef STEM_CALLBACK_DURING_HOUSEKEEPING
#undef STEM_CALLBACK_DURING_FRAG
#undef STEM_CALLBACK_AFTER_FRAG
#undef STEM_CALLBACK_SHOULD_SHUTDOWN

/* ─── Scratch footprint ─── */

static ulong
tkcase_scratch_align( void ) {
    return TKCASE_CTX_ALIGN;
}

static ulong
tkcase_scratch_footprint_tile( fd_topo_tile_t const * tile ) {
    (void)tile;
    ulong footprint = fd_ulong_align_up( sizeof(tkcase_ctx_t), TKCASE_CTX_ALIGN );
    /* output scratch buffers */
    footprint = fd_ulong_align_up( footprint, alignof(uint8_t) );
    footprint += sizeof(tkcase_ctx_t) > TKCASE_MAX_OUTS * TKCASE_MAX_MTU ? 0 : TKCASE_MAX_OUTS * TKCASE_MAX_MTU;
    return footprint;
}

ulong
tkcase_scratch_footprint( void ) {
    return tkcase_scratch_footprint_tile( NULL );
}

/* ─── Privileged init ─── */

static void
tkcase_privileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tkcase_ctx_t * ctx = STK_GET_CTX(tkcase_ctx_t, scratch, TKCASE_CTX_ALIGN);
    memset( ctx, 0, sizeof(*ctx) );

    ctx->case_created = 0;
    ctx->case_completed = 0;
    ctx->consumed = 0;
    ctx->forwarded = 0;
    ctx->case_audit_emitted = 0;
    ctx->stage_valid = 0;
    ctx->capsule_next = 0;
    ctx->event_count = 0;
    ctx->input_exhausted = 0;

    /* Derive workspace pointer from input mcache */
    ctx->wksp = stk_derive_wksp(topo, tile, 0);

    /* Read event_count from environment */
    {
        const char *env = getenv("TKCASE_EVENT_COUNT");
        if (env) {
            ctx->event_count = strtoull(env, NULL, 10);
            FD_LOG_NOTICE(( "tkcase: event_count=%lu from env", (unsigned long)ctx->event_count ));
        }
    }

    ctx->tile = tile;

    FD_LOG_NOTICE(( "tkcase: privileged init ctx=%p wksp=%p",
                    ctx, ctx->wksp ));
}

/* ─── Unprivileged init ─── */

static void
tkcase_unprivileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo; (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tkcase_ctx_t * ctx = STK_GET_CTX(tkcase_ctx_t, scratch, TKCASE_CTX_ALIGN);

    /* Shared boilerplate: find CNC and set ctx->cnc */
    STK_UNPRIV_INIT(topo, tile, ctx);
    if (FD_UNLIKELY(!ctx->cnc))
        FD_LOG_ERR(( "tkcase: CNC object not found for tile %lu", tile->id ));
    if (FD_UNLIKELY(tile->in_cnt != 1UL))
        FD_LOG_ERR(( "tkcase: expected exactly one input, found %lu", tile->in_cnt ));
    if (FD_UNLIKELY(tile->out_cnt != TKCASE_MAX_OUTS))
        FD_LOG_ERR(( "tkcase: expected %lu outputs, found %lu", TKCASE_MAX_OUTS, tile->out_cnt ));
    if (FD_UNLIKELY(!ctx->wksp))
        FD_LOG_ERR(( "tkcase: input workspace is not joined" ));

    /* Initialize output workspace and dcache tracking */
    for (ulong o = 0UL; o < tile->out_cnt; o++) {
        fd_topo_link_t const * out_link = &topo->links[tile->out_link_id[o]];
        if (FD_UNLIKELY(!out_link->dcache))
            FD_LOG_ERR(( "tkcase: output %lu has no dcache", o ));
        ctx->out_wksp[o] = fd_topo_obj_wksp_base(topo, out_link->dcache_obj_id);
        if (FD_UNLIKELY(!ctx->out_wksp[o]))
            FD_LOG_ERR(( "tkcase: output %lu workspace is not joined", o ));
        ctx->out_chunk0[o] = fd_dcache_compact_chunk0(ctx->out_wksp[o], out_link->dcache);
        ctx->out_wmark[o]  = fd_dcache_compact_wmark(ctx->out_wksp[o], out_link->dcache, out_link->mtu);
        ctx->out_chunk[o]  = ctx->out_chunk0[o];
        ctx->out_ready[o]  = 0;
    }

    FD_LOG_NOTICE(( "tkcase: unprivileged init tile_id=%lu cnc=%p out_cnt=%lu",
                    tile->id, ctx->cnc, tile->out_cnt ));
}

/* ─── DURING_FRAG: stage the fragment ─── */

static void
tkcase_during_frag( tkcase_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    ulong          ctl ) {
    (void)in_idx; (void)seq; (void)sig; (void)ctx->stage_sz; (void)ctl;

    if (!sz || sz > TKCASE_MAX_MTU || !ctx->wksp) return;
    if (FD_UNLIKELY(chunk < ctx->out_chunk0[0] || chunk > ctx->out_wmark[0])) return;

    ctx->stage_valid = 0;
    memcpy(ctx->stage, stk_chunk_to_gaddr(ctx->wksp, chunk), sz);
    ctx->stage_sz = sz;
    ctx->stage_valid = 1;
}

/* ─── AFTER_FRAG: commit, forward, audit, capsule ─── */

static void
tkcase_after_frag( tkcase_ctx_t *      ctx,
                   ulong               in_idx,
                   ulong               seq,
                   ulong               sig,
                   ulong               sz,
                   ulong               tsorig,
                   ulong               tspub,
                   fd_stem_context_t * stem ) {
    (void)in_idx; (void)sz;

    /* Skip if no valid data staged */
    if (!ctx->stage_valid) return;
    ctx->stage_valid = 0;

    ctx->consumed += 1UL;

    /* On first event: create case scope */
    if (!ctx->case_created) {
        /*
         * Deterministic case_id: "case_{workflow}_{account_id}_{timestamp}"
         * For V1, use a simple hash-based approach. The actual formatting
         * will be done in the supervisor via tkcase_config.
         * For now: "case_investment_2001_00000001"
         */
        snprintf((char*)ctx->active_case.case_id, TKCASE_CASE_ID_LEN,
                 "case_investment_2001_%08lu", ctx->consumed);
        memcpy(ctx->active_case.workflow, "investment", 10);
        ctx->active_case.actor_id = 2001;  /* from config/test fixture */
        ctx->active_case.account_id = 2001;
        ctx->active_case.created_ns = tsorig;
        ctx->active_case.state = 1;  /* active */
        ctx->active_case.event_count_total = ctx->event_count;
        ctx->case_created = 1;

        /* Emit RECORD_CASE_CREATION to tkaudt */
        /* TODO: publish audit record to tkaudt via audit link */
        ctx->case_audit_emitted += 1;
    }

    /* Forward to both outputs: tkpoly (output 0) and tkdisp (output 1) */
    for (ulong o = 0UL; o < ctx->tile->out_cnt; o++) {
        memcpy(ctx->out_buf[o], ctx->stage, ctx->stage_sz);
        ctx->out_sz[o] = ctx->stage_sz;
        ctx->out_ready[o] = 1;
    }

    /* Build capsule entry */
    tkcase_capsule_entry_t *entry = &ctx->capsule[ctx->capsule_next % TKCASE_MAX_OUTS];
    entry->source_offset = 0;  /* TODO: extract from event */
    entry->seq = seq;
    memcpy(entry->tile_id, "tkdedu", 6);  /* TODO: extract producer tile_id */
    entry->payload_hash = 0;  /* TODO: hash content */
    entry->timestamp_ns = tsorig;
    memcpy(entry->content, ctx->stage, ctx->stage_sz);
    entry->content_sz = ctx->stage_sz;
    ctx->capsule_next += 1;

    /* Forwarded count */
    ctx->forwarded += ctx->tile->out_cnt;

    /* Event count exhaustion check */
    if (ctx->event_count && ctx->consumed >= ctx->event_count) {
        ctx->input_exhausted = 1;

        /* On final event: mark case completed */
        if (!ctx->case_completed) {
            ctx->active_case.state = 2;  /* completed */
            ctx->case_completed = 1;

            /* Emit RECORD_CASE_COMPLETION to tkaudt */
            /* TODO: publish audit record to tkaudt via audit link */
            ctx->case_audit_emitted += 1;
        }
    }

    /* Publish to outputs */
    for (ulong o = 0UL; o < ctx->tile->out_cnt; o++) {
        if (ctx->out_ready[o]) {
            ctx->out_ready[o] = 0;
            ulong chunk = ctx->out_chunk[o];

            /* Copy output buffer to dcache slot */
            if (chunk >= ctx->out_chunk0[o] && chunk < ctx->out_wmark[o]) {
                void *dst = fd_wksp_laddr_fast(ctx->out_wksp[o], chunk * FD_CHUNK_ALIGN);
                memcpy(dst, ctx->out_buf[o], ctx->out_sz[o]);
            }

            fd_stem_publish(stem, o, sig, chunk, ctx->out_sz[o], 0UL, 0UL, 0UL);

            ctx->out_chunk[o] = fd_dcache_compact_next(
                chunk, ctx->out_sz[o], ctx->out_chunk0[o], ctx->out_wmark[o]);
        }
    }

    /* Publish progress counter */
    stk_publish_counter(ctx->cnc, 0UL, ctx->forwarded);
}

/* ─── Run entry point ─── */

static void
tkcase_run_entry( fd_topo_t *      topo,
                  fd_topo_tile_t * tile ) {
    void * scratch = fd_topo_obj_laddr(topo, tile->tile_obj_id);
    tkcase_ctx_t * ctx = STK_GET_CTX(tkcase_ctx_t, scratch, TKCASE_CTX_ALIGN);

    ulong cnc_obj_id = tk_topo_find_tile_obj(topo, tile->id, "cnc");
    if (FD_UNLIKELY(cnc_obj_id == ULONG_MAX))
        FD_LOG_ERR(("tkcase: CNC object not found for tile %lu", tile->id));
    ctx->cnc = fd_topo_obj_laddr(topo, cnc_obj_id);

    tkcase_run(topo, tile);

    tile->allow_shutdown = 1;
}
```

**Pitfalls to watch:**
- **Output dcache publish:** tkcase has 2 outputs (to tkpoly and tkdisp), so `AFTER_FRAG` must publish to BOTH. The `fd_stem_publish` signature: `(stem, out_idx, sig, chunk, data_sz, wire_sz, 0, 0)`.
- **Capsule ring buffer size:** TKCASE_MAX_OUTS = 2 is just for V1. The capsule must grow to hold all events in a case. For V1, the event_count is small enough that a simple ring buffer works.
- **Audit emission:** tkcase must emit RECORD_CASE_CREATION and RECORD_CASE_COMPLETION to tkaudt. This requires a new audit output link (tkcase → tkaudt). Currently tkcase has only tkpoly and tkdisp outputs. The audit link is an **unreliable** diagnostic link (like tkmodl → tkaudt).
- **Case scope determination:** The case_id must be deterministic. For V1, it uses a simple format. For V2, it may need to be derived from the input event's metadata (workflow, account, timestamp).
- **Shared tk_pass_stem.c:** tkcase must NOT share tk_pass_stem.c anymore. After this migration, tk_pass_stem.c will only serve tktool and tkadpt (idle consumers).

## Risks and Mitigations

1. **Capsule ring buffer overflow:** TKCASE_MAX_OUTS = 2 is too small for large cases. **Mitigation:** V1 uses event_count gating, so the ring buffer only holds `event_count` entries. For V2, increase to a configurable cap or use dynamic allocation.

2. **Audit emission:** tkcase needs to emit audit records to tkaudt but currently has no audit output link. **Mitigation:** The initial migration focuses on forwarding + capsule building. Audit emission is added in a follow-up task (same migration, different commit). The topology already has tkcase → tkpoly and tkcase → tkdisp links; the audit link is added to the topology spec.

3. **Case scope derivation:** The case_id must be deterministic but the input event may not carry workflow/account metadata. **Mitigation:** V1 uses hardcoded values from the test fixture (case_id = "case_investment_2001_XXXX"). For V2, the metadata comes from the event or from a configuration file.

4. **Scratch footprint mismatch:** If topob.c and the stem tile compute different scratch sizes, the topology won't build correctly. **Mitigation:** Both use `sizeof(tkcase_ctx_t)` + alignment. The footprint function is the single source of truth.

5. **Shared tk_pass_stem.c breakage:** Removing TK_CASE_RUN from the shared file must not affect tktool and tkadpt. **Mitigation:** The `ctx->forward` flag already distinguishes tkcase from tktool/tkadpt. Removing TK_CASE_RUN just removes one of the three `TKPASS_RUN_TILE` macro invocations.

## Critical Invariants

- **NEVER share tk_pass_stem.c between tkcase and tktool/tkadpt anymore.** tkcase has its own implementation.
- **Case scope must be deterministic.** The case_id must be reproducible from the same inputs. For V1, this means the test fixture must produce the same case_id every run.
- **Forwarding must be lossless.** Every event that enters tkcase must exit to BOTH outputs unchanged (except for the forwarding tile's own metadata additions).
- **Capsule must contain all events.** The capsule ring buffer must hold every event that flowed through tkcase, in order, with their original content.
- **Event count gating must be correct.** `input_exhausted` is set when `consumed >= event_count`. The case is completed when the last event is processed.
