1. **Input: `tkcase -> tkrepl`**, the side-channel of

   `replay_capsule_input`. tkcase streams the case capsule: every event it
   appends, exactly as forwarded (`TK_LINK_SIG_EVENT`). After the event that
   closes the case it sends one `TkCaseCapsuleMsg` (`TK_LINK_SIG_CASE_CAPSULE`)
   carrying the case id, event count, first and last offset, trace and capsule
   hash. The link is tkcase's fourth output, and exists only where the topology
   has tkrepl. The spine is unchanged.
2. **Output: `tkrepl -> tkaudt`**, one `RECORD_REPLAY_RESULT` record
   (`TkReplAuditMsg` carrying the existing `WireReplayResultPayload`;
   `capsule_id` is the capsule hash). It does not go to tkings: tkings takes only
   whole TkEvents on its single input. tkaudt holds the replay input until the
   case completion record is committed, so the replay result is the chain's
   last record, and tkaudt's event gate waits for it. The verdict also goes to
   CNC slots 1 (`replay_match`) and then 0 (`replay_checked`).
3. **Verify: capsule-only, through a pure Zig hook.** `verifyAllowedTrade*`
   needs a basket, a ticket and a drift contract that the tile does not have,

   receives into its own observation. On the summary it calls
   `TkReplHooks.verify`, which is `src/tickoni/tiles/replay/decision.zig`
   (module `replay_decision`, installed by `tile_main_config.loadReplaySetup`).
   The hook follows tk_agent_hooks.h's rules: fixed-size data, no I/O, pure.
   Divergences are counted per field with the shared `DivergenceTracker`,
   which moved into `decision.zig`; `capsule.zig` re-exports it. An unknown
   summary version is a hard divergence.
4. **Phase 2 is not started.** It depends on capsule delivery to tkgate and on

## Architecture Context

### Current state (in-process spike)

tkrepl runs inside the payment pipeline spike via `runReplay()`:
- Polls `audit_done` atomic from `PaymentPipelineState`
- Recomputes deterministic replay via `deterministicReplayDivergences()`
- Sets `replay_checked`/`replay_match`/`replay_divergences` atomics
- Zero input/output links — no topology channels

### Target state (Firedancer fd_stem tile)

- **1 input link** (`replay_capsule_input`) — receives replay capsule JSON from external source (test harness or replay entrypoint)
- **1 output link** (`tkrepl_tkings`) — publishes divergence report to tkings
- **Observer role** — tkdiag already reads tkrepl's CNC app slots 0 (`replay_checked`) and 1 (`replay_match`)
- **Callbacks:** DURING_FRAG (receive capsule), AFTER_FRAG/AFTER_CREDIT (publish divergence), BEFORE_CREDIT (shutdown polling), SHOULD_SHUTDOWN (lifecycle)

### Why capsule I/O matters

The spike generates synthetic events from `runtime.syntheticPayment()` — no external capsule needed. Real replay must load a capsule from disk (JSON), verify its integrity, then replay deterministically from that capsule. Capsule I/O enables replay from captured production events, not just synthetic test streams. Divergence reporting to tkings enables CaseOps to display replay results.

### tkdiag integration

`tk_diag_stem.c` already reads tkrepl's CNC app-region slots 0 and 1 (`TKREPL_SLOT_REPLAY_CHECKED`, `TKREPL_SLOT_REPLAY_MATCH`). No changes needed to tkdiag — it reads these slots the same way whether tkrepl is spike or stem.

### Unified flow position

Per `doc/knowledge/unified-flow-diagram.md`, the deterministic event pipeline is:
```
tkings → tknorm → tkdedu → tkcase → tkpoly → tkaudt
```
tkrepl sits outside this spine: it reads a replay capsule, verifies the pipeline's deterministic behavior, and reports divergence. It is test infrastructure with no UC mapping in the main flow.

### UC-11: Agent Decision Audit alignment

Per `doc/strategy/roadmap/usecases/11-agent-decision-audit.md`, tkrepl's
full role is:
```
Term → tk_gate (case_replay) → tkcase (capsule) → tkaudt (audit records)
     → tkrepl (replay, external effects disabled) → tk_gate (narrative)
     → Term (decision story)
```

Phase 1 implements the **deterministic replay path** (capsule I/O, divergence
report). Phase 2 implements the **narrative path** (case_replay handler,
policy version swap, counterfactual replay, CaseOps narrative display).
Phase 1 does not include `tk_gate` or `tkcase.capsule()` — `tk_gate` is
already migrated and available; `tkcase.capsule()` requires tkcase to be
moved from its `tk_pass_stem.c` placeholder to a real implementation.

### Key differences from other stem tiles

| Aspect | tkings (1-in, 1-out) | tkaudt (N-in, 0-out) | metric (0-in, 0-out) | tkrepl (1-in, 1-out) |
|--------|---------------------|---------------------|---------------------|---------------------|
| Input | TkEvent fragments | — | — | Replay capsule fragments |
| Output | TkEvent fragments | — | — | Divergence report fragment |
| Logic | Framing validation | Audit hash chain | HTTP metrics | Capsule load, deterministic verify |
| Shutdown | Event count + HALT | Event count + HALT | CNC HALT | `replay_checked` + HALT |
| External I/O | None | None | fd_http_server | JSON file loading (capsule path) |
| Complexity | Medium | Low | Delegated | **High** — needs existing Zig verify logic |

### Reuse strategy

tkrepl's verification logic already exists in `src/tickoni/tiles/replay/mod.zig` (verifyAllowedTrade, verifyOversizedTradeBlock, verifyRestrictedInstrumentBlock) and `capsule.zig` (ReplayCapsuleWire, DivergenceTracker, loadReplayCapsule, checkCapsuleVersions). The C stem must **not** reimplement this logic — instead it should:

1. Load the capsule JSON fragment received on the input link into a scratch buffer
2. Call the existing Zig `verifyAllowedTradeWithCapsulePath()` or equivalent via a C FFI bridge
3. Read the `ReplayVerification` result (match/mismatch, divergence count)
4. Publish a divergence report fragment to the output link

This avoids C/Zig hash divergence and keeps verification truth in one place.

**Phase 2 extension:** The same FFI bridge (`build-lib/ffi/replay_bridge.zig`)
gains narrative assembly: it iterates the capsule's audit records, classifies
event types (policy check, model response, tool call, agent proposal), and
fills the `narrative` struct in `tkrepl_ctx_t`. The narrative is then
published as a larger 2048-byte fragment on the output link.

## Task 1: Create fragment types and stem C files

### 1a: Create `src/tickoni/c_abi/shim/tkrepl_frag.h`

**Fragment format — input (replay capsule):**

```c
/* tkrepl_frag.h — Replay capsule and divergence fragment formats. */
#ifndef HEADER_fd_src_tickoni_tkrepl_frag_h
#define HEADER_fd_src_tickoni_tkrepl_frag_h

#include <stdint.h>

/* Input fragment: replay capsule metadata from replay entrypoint.
 * The full capsule JSON payload arrives as a separate payload or is
 * carried within this fragment's buffer. For now, this fragment carries
 * the capsule's structural metadata; the raw JSON is carried in the
 * same chunk's data area. */
typedef struct {
    uint16_t schema_version;    /* Must match replay_capsule_schema_version (1) */
    uint16_t ticket_id_len;     /* Length of ticket_id */
    uint64_t event_count;       /* Expected number of audit records */
    char     ticket_id[64];     /* Capsule ticket ID */
    uint64_t capsule_hash;      /* Hash of the full capsule JSON */
    uint32_t model_sub_count;   /* Model substitutions in capsule */
    uint32_t adapter_sub_count; /* Adapter substitutions in capsule */
    uint8_t  no_live_model_call;      /* Assertion: no live model call */
    uint8_t  no_live_adapter_call;    /* Assertion: no live adapter call */
    uint8_t  no_paper_fill_emitted;   /* Assertion: no paper fill emitted */
    uint8_t  _pad[37];                /* Padding to 128 bytes */
} tkrepl_capsule_frag_t;

/* Output fragment: divergence report published to tkings. */
typedef struct {
    uint32_t divergences;         /* Total divergence count */
    uint32_t is_match;            /* 1 = match (0 divergences), 0 = mismatch */
    uint32_t capsule_id;          /* Capsule ID that was replayed (hash lower 32) */
    uint64_t event_count;         /* Expected event count */
    uint64_t actual_count;        /* Actual event count processed */
    uint64_t first_div_seq;       /* Sequence of first divergence */
    uint64_t first_div_expected;  /* Expected record hash */
    uint64_t first_div_actual;    /* Actual record hash */
    char     first_div_field[32]; /* Field that diverged */
    uint8_t  _pad[32];            /* Padding to 128 bytes */
} tkrepl_divergence_frag_t;

#define TKREPL_CAPSULE_SCHEMA_VERSION 1
#define TKREPL_CAPSULE_FRAG_SIZE 128
#define TKREPL_DIV_FRAG_SIZE 128

#endif /* HEADER_fd_src_tickoni_tkrepl_frag_h */
```

   - verifyReplay() calls into replay mod.zig's verify functions

*/

#include "firedancer.h"
#include "audit_schema.h"
#include "tkrepl_frag.h"
#include "../stem_helpers.h"

#include "../../../disco/topo/fd_topo.h"

/* ─── C FFI bridge to Zig verification ───
 *
 * These extern declarations bridge to the existing Zig replay verification
 * functions. The actual implementations live in build-lib/lanes/ and are
 * compiled into the same shim library. The C stem calls verifyReplay()
 * with the capsule data from scratch, and reads back the result.
 *
 * The Zig side provides:
 *   - verifyReplay(allocator, io, capsule_ptr, capsule_len, model_backend,

 *   - Returns ReplayVerification struct via scratch output

extern int verifyReplay(
    uint8_t const * capsule_data, ulong capsule_len,
    uint64_t * out_divergences, ulong * out_first_div_seq,
    char * out_first_div_field, ulong field_buf_sz,

/* ─── Context ─── */

    uint64_t   capsule_hash;

static void
tkrepl_privileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tkrepl_ctx_t * ctx = STK_GET_CTX(tkrepl_ctx_t, scratch, TKREPL_CTX_ALIGN);

    memset( ctx, 0, sizeof(*ctx) );
    ctx->capsule_loaded = 0;
    ctx->replay_match = 0;
    ctx->divergences = 0;
    ctx->idle_ticks = 0;
    ctx->cnc = NULL;
    ctx->input_exhausted = 0;
    ctx->divergence_published = 0;

    /* Derive workspace pointer from input mcache */
    ctx->wksp = stk_derive_wksp(topo, tile, 0);

    /* Validate link counts: 1 input, 1 output */
    if( FD_UNLIKELY( tile->in_cnt != 1UL ) )
        FD_LOG_ERR(( "tkrepl: exactly one input link, found %lu", tile->in_cnt ));
    if( FD_UNLIKELY( tile->out_cnt != 1UL ) )
        FD_LOG_ERR(( "tkrepl: exactly one output link, found %lu", tile->out_cnt ));

    FD_LOG_NOTICE(( "tkrepl: privileged init ctx=%p", (void*)ctx ));
}

static void
tkrepl_unprivileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tkrepl_ctx_t * ctx = STK_GET_CTX(tkrepl_ctx_t, scratch, TKREPL_CTX_ALIGN);

    /* Shared boilerplate: find CNC and set ctx->cnc */
    STK_UNPRIV_INIT(topo, tile, ctx);

    if( FD_UNLIKELY( !ctx->cnc ) )
        FD_LOG_ERR(( "tkrepl: CNC object not found for tile %lu", tile->id ));

    /* Initialize output link for divergence reports */
    stk_link_out_init( &ctx->out, topo, tile, 0UL, (ulong)TKREPL_DIV_FRAG_SIZE );

    FD_LOG_NOTICE(( "tkrepl: unprivileged init tile_id=%lu cnc=%p", tile->id, ctx->cnc ));
}

static void
tkrepl_during_frag( tkrepl_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    ulong          ctl ) {
    (void)in_idx; (void)seq; (void)sig; (void)ctl;

    /* Validate fragment size */
    if( FD_UNLIKELY( sz != TKREPL_CAPSULE_FRAG_SIZE ) ) return;
    if( FD_UNLIKELY( !stk_validate_frag(sz, TKREPL_CAPSULE_FRAG_SIZE, ctx->wksp) ) ) return;
    if( FD_UNLIKELY( !stk_link_in_contains( &ctx->in, chunk ) ) ) return;

    /* Copy capsule fragment */
    tkrepl_capsule_frag_t * frag = (tkrepl_capsule_frag_t *)stk_link_in_laddr( &ctx->in, chunk );

    /* Validate schema version — hard reject if mismatch */
    if( frag->schema_version != TKREPL_CAPSULE_SCHEMA_VERSION ) {
        ctx->divergences = 1;
        ctx->replay_match = 0;
        ctx->capsule_loaded = 1;  /* Mark as attempted, but failed */
        return;
    }

    /* Store capsule metadata into scratch */
    ctx->capsule_schema_version = frag->schema_version;
    ctx->event_count = frag->event_count;
    ctx->capsule_hash = frag->capsule_hash;
    ctx->capsule_len = 0;  /* Full JSON payload would be carried separately */
    ctx->capsule_loaded = 1;

    /* For now: deterministic replay against the capsule.
     * In the spike, replay generates synthetic events and compares.
     * In the stem tile, we load the capsule from the input link and run
     * verification against it. The actual verifyReplay() bridge call
     * goes here — it returns divergences, first_div_seq, etc. */
    // verifyReplay(ctx->capsule_buf, ctx->capsule_len,
    //              &ctx->divergences, &ctx->first_div_seq,
    //              ctx->first_div_field, sizeof(ctx->first_div_field),
    //              &ctx->first_div_expected, &ctx->first_div_actual);

    /* For the initial migration, set replay_match based on whether
     * the capsule loaded successfully and schema version matched.

}

static void
tkrepl_after_credit( tkrepl_ctx_t *    ctx,
                     fd_stem_t *       stem,
                     fd_stem_tile_in_t * poll_in,
                     int *             charge_busy ) {
    (void)poll_in;

    /* Publish divergence report if replay completed */
    if( ctx->capsule_loaded && ctx->divergence_published == 0 ) {
        /* Build divergence report */
        tkrepl_divergence_frag_t * report = (tkrepl_divergence_frag_t *)ctx->div_buf;
        memset( report, 0, sizeof(*report) );
        report->divergences = (uint32_t)ctx->divergences;
        report->is_match = (uint32_t)ctx->replay_match;
        report->capsule_id = (uint32_t)(ctx->capsule_hash & 0xFFFFFFFF);
        report->event_count = ctx->event_count;
        report->actual_count = ctx->actual_count;
        report->first_div_seq = ctx->first_div_seq;
        report->first_div_expected = ctx->first_div_expected;
        report->first_div_actual = ctx->first_div_actual;
        memcpy( report->first_div_field, ctx->first_div_field, sizeof(ctx->first_div_field) );

        /* Publish to output link */
        stk_link_out_publish( &ctx->out, stem, 0UL, 0UL, ctx->div_buf, TKREPL_DIV_FRAG_SIZE );
        ctx->divergence_published = 1;
    }

    *charge_busy = 0;
}

## Task 7: Create C FFI bridge to Zig verification (core logic)

### 7a: Create `build-lib/ffi/replay_bridge.zig`

This module provides the C FFI bridge between `tk_repl_stem.c`'s `verifyReplay()` call and the existing Zig replay verification functions.

**What it does:**
1. Receives capsule JSON from C (ptr + len)
2. Parses it into `ReplayCapsuleWire` using `capsule.zig.loadReplayCapsule()`
3. Calls `mod.zig.verifyAllowedTradeWithCapsulePath()` or equivalent
4. Fills in the C output struct with divergence details

**FFI signature:**
```zig
export fn verifyReplay(
    capsule_data: ?[*]const u8,
    capsule_len: usize,
    out_divergences: *u64,
    out_first_div_seq: *u64,
    out_first_div_field: [*]u8,
    field_buf_sz: usize,
    out_first_div_expected: *u64,
    out_first_div_actual: *u64,
) callconv(.C) c_int {
    // 1. Validate capsule_data is non-null and non-empty
    // 2. Parse JSON using std.json.parseFromSlice
    // 3. Call verifyAllowedTradeWithCapsulePath with fixture backends
    // 4. Extract divergence details into output parameters
    // 5. Return 0 on success, non-zero on parse/fail
}
```

**Pitfalls:**
- The Zig verify functions currently take `capsule_path` (file path), not raw bytes. We need a byte-based variant or write the capsule to a temp file.
- Model and adapter backends must be fixture backends — no live I/O.
- The `DivergenceTracker` already accumulates divergences; we need to extract `count`, `first_field`, `first_seq` from it.
- Memory management: the C side owns the capsule buffer; the Zig side must not free it.

## Risks and Mitigations

1. **Zig FFI complexity:** Bridging C → Zig verification requires careful memory management (who owns the capsule buffer, who allocates the output struct). **Mitigation:** The Zig side uses scratch memory for output; the capsule buffer is passed as a const pointer and not freed.

2. **Capsule JSON format mismatch:** The C fragment format must match the JSON structure parsed by `capsule.zig`. **Mitigation:** The fragment carries minimal metadata; the raw JSON is passed as a blob. The Zig side parses the full JSON — the C side only validates the schema version.

3. **Deterministic replay logic divergence:** If C reimplements the verify logic instead of bridging to Zig, C and Zig hashes could diverge. **Mitigation:** Task 7 ensures all verification goes through the Zig bridge — C only orchestrates I/O.

4. **Shutdown ordering:** The stem loop evaluates `SHOULD_SHUTDOWN` before `AFTER_CREDIT`, so the final `AFTER_CREDIT` may be skipped. **Mitigation:** `AFTER_FRAG` is used for publishing (same fix as the tknorm plan's `AFTER_CREDIT` → `AFTER_FRAG` correction). Or set a flag in `DURING_FRAG` and publish in the next `BEFORE_CREDIT` iteration.

5. **Link topology changes:** Adding tkrepl links changes the topology's channel count and must not break existing topology validation. **Mitigation:** tkrepl is optional in the topology — topologies that don't include tkrepl continue to work as before. The topology builder only adds tkrepl channels when explicitly configured.

## Critical Invariants

- **NEVER reimplement verify logic in C.** All verification must go through the Zig FFI bridge to `mod.zig`. C only handles I/O (fragments, links, CNC).
- **Capsule schema version check is mandatory.** A mismatch is a hard divergence — set `replay_match = 0` and publish the report.
- **tkdiag integration is read-only.** tkdiag already reads `replay_checked` (slot 0) and `replay_match` (slot 1). tkrepl writes these to the CNC app-region; no changes to tkdiag are needed.
- **tkings must accept TK_EVENT_SOURCE_TKREPL.** The existing `tkings_framing_ok()` check already allows events with `ev->source == TK_EVENT_SOURCE_TKREPL`. If this changes, the C bridge must be updated too.
- **External effects must be disabled.** The replay verification must use only fixture backends — no live model, adapter, or trading calls. This is enforced by the existing `model_backend.isEffectFree()` check in the Zig verify functions.
- **Tile name must match topology exactly.** Both `TK_REPL_RUN.name` and `tile_is_replay()` must use `TILE_ID_TKREPL` = `"tkrepl"`.
