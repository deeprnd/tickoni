# Plan: Move build artifacts comparison before project-build gate

## Goal

Move the cross-platform build artifact comparison from **after demo tests** to **immediately after build matrix**, before the project-build gate. This makes conformance a true build-quality gate that blocks downstream work if platforms diverge, rather than an after-the-fact check that runs 10+ minutes into CI.

Rename the step from "conformance" (misleading) to "build artifacts comparison" (accurate).

## Current state

CI order:
```
quality/security-secrets → build(matrix) → project-build → unit → integration/system/demo/coverage(parallel) → conformance(after demo) → project-tests → security-deep → project-security → ci-required
```

Problems:
1. **Wrong placement**: Conformance runs after Demo (~10+ minutes into CI) when it only needs Build artifacts. It should block project-build immediately.
2. **Unnecessary dependency**: Conformance depends on `needs.demo`, which is irrelevant — the conformance bundles come from Build, not Demo.
3. **Misleading name**: Called "conformance" / "demo conformance" when it's really "cross-platform binary output comparison". It compares compiled binaries, not demo behavior.
4. **No value in gate**: If platforms diverge, downstream tests (unit, integration, system, demo) waste time on broken builds.

## Target state

CI order:
```
quality/security-secrets → build(matrix) → build-artifacts-comparison → project-build → unit → integration/system/demo/coverage(parallel) → project-tests → security-deep → project-security → ci-required
```

Conformance runs as early as possible: it downloads `conformance-linux-x86`, `conformance-linux-arm`, `conformance-macos-15-x86`, `conformance-macos-15-arm`, `conformance-macos-26-x86`, `conformance-macos-26-arm`, `conformance-windows-x86`, `conformance-windows-arm` artifacts from Build, compares them, and either passes (all platforms match) or fails (platform diverges). Downstream stages never run on divergent builds.

## What the comparison does

Runs `tickoni-supervisor demo investment --json --manifest demo.manifest.json` on each compiled binary, captures the output, and compares deterministic fields across all 8 platforms:
- `preflight` result
- `suite[].scenario` names
- `suite[].normalized_event_hash`
- `suite[].policy_outcome`
- `suite[].proposal_hash`
- `suite[].replay_match`
- `suite[].divergence_count`
- `suite[].external_effects_disabled`
- `suite[].blocked_diagnostic` (if any)

Strips platform-specific fields: `runtime_tier`, `isolation_tier`, `comparison` block.

This detects: floating-point drift, endianness bugs, hash implementation differences, policy logic divergence between platforms.
