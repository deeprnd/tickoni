# Plan: Migrate tknorm to fd_stem

> **For Hermes:** Execute this plan task-by-task. Each task is self-contained — the build compiles after each one.

**Goal:** Migrate `tknorm` (normalize tile) from the `tile_process.zig` WorkFn closure pattern to Firedancer's `fd_stem` callback lifecycle (`BEFORE_CREDIT` → `DURING_FRAG` → `AFTER_CREDIT`), using the per-tile include pattern proven by `tk_metric_tile.c` and `tk_audit_stem.c`.

**Architecture:** Follow Firedancer's own pattern — the tile's C shim defines `STEM_CALLBACK_*` macros and includes `fd_stem.c` directly. No global callback registry. The tile is self-contained.

**Key files:**
- Tile business logic (unchanged): `src/tickoni/tiles/payment_pipeline/normalize.zig`
- Process-mode harness (modified): `src/tickoni/runtime/tile_process.zig`, `src/tickoni/c_abi/shim/tile_run.c`
- Shared header: `src/tickoni/c_abi/topo_run/tk_norm_stem.h` (new)
- Tile shim (new): `src/tickoni/c_abi/shim/tk_normalize_stem.c`
- Reference implementation: `src/tickoni/c_abi/shim/tk_audit_stem.c` (closest peer — also 1-in, 1-out pipeline tile)
- Firedancer stem: `src/disco/stem/fd_stem.c`

## Current State (Before Migration)

tknorm's current implementation in `src/tickoni/tiles/payment_pipeline/normalize.zig`:

```zig
pub fn runNormalize(state: *PaymentPipelineState) void {
    var offset: u64 = 0;
    while (state.q_ing_norm.pop(&state.stop)) |msg_in| {
        var msg = msg_in;
        offset += 1;
        if (!runtime.validFraming(msg.raw)) {
            _ = state.invalid.fetchAdd(1, .release);
            msg.pipeline_hops += 1;
            msg.event_hash = runtime.stableEventHash(msg.raw);
            msg.decision = .malformed_drop;
            msg.decided_by = audit_sink.tile_id_tknorm;
            state.q_norm_dedu.push(msg, &state.stop) catch break;
            continue;
        }
        msg.pipeline_hops += 1;
        msg.event_hash = runtime.stableEventHash(msg.raw);
        _ = state.normalized.fetchAdd(1, .release);
        state.q_norm_dedu.push(msg, &state.stop) catch break;
    }
}
```

**Topology:** 1 input link (from tkings), 1 output link (to tkdedu).

**Current behavior:**
- Consumes from `q_ing_norm` (tkings output queue)
- Validates framing via `validFraming(msg.raw)`
- Computes stable event hash via `stableEventHash(msg.raw)`
- Increments `pipeline_hops` on every event
- Malformed events: sets `decision = .malformed_drop`, `decided_by = tknorm`, increments `invalid` counter, still pushes to output (downstream dedupe/policy see the decision)
- Valid events: increments `normalized` counter, pushes to output
- Tracks `offset` (sequence counter)

## Task 2: Create `tk_normalize_stem.c` — tknorm fd_stem shim

**File:** `src/tickoni/c_abi/shim/tk_normalize_stem.c` (new)

This is the main deliverable. It mirrors the structure of `tk_audit_stem.c` (the closest peer — a 1-in, 1-out pipeline tile that also reads PaymentMessage fragments and produces them with modifications):

```c
/* tk_normalize_stem.c — Tickoni's tknorm normalize tile, fd_stem-based.
 *
 * Consumes payment events from tkings (1-in), validates framing,
 * computes stable event hash, and publishes normalized events to
 * tkdedu (1-out).
 *
 * Callback mapping from current while(pop()) loop:
 *   DURING_FRAG  ←  while(pop()) body (consume → validFraming → stableEventHash → push)
 *   AFTER_CREDIT ←  push to tkdedu output link
 *   BEFORE_CREDIT ← idle tick tracking (consecutive_empty counter)
 *   SHOULD_SHUTDOWN ← work_done (consecutive_empty >= threshold) or HALT
 *
 * Design notes:
 *   • Each tile's C shim is self-contained: defines STEM_CALLBACK_* macros,
 *     includes fd_stem.c, and produces a TKNORM_RUN fd_topo_run_tile_t.
 *   • Fragment passthrough: tknorm reads the raw fragment from input dcache,
 *     validates it, and writes to output dcache. Same memory layout
 *     as the PaymentMessage struct defined inline here.
 *   • The fragment format matches tk_audit_stem.c's PaymentMessage —
 *     tknorm receives the same fragment shape that tkings emits.
 *   • Backpressure: stem handles via cr_avail. tknorm doesn't check
 *     queue depth — stem won't call AFTER_CREDIT if no credits available.
 */

#if FD_HAS_LINUX || FD_HAS_MACOS || FD_HAS_WINDOWS

#define _GNU_SOURCE

#include "../../../util/fd_util.h"
#include "../../../tango/dcache/fd_dcache.h"
#include "../../../tango/cnc/fd_cnc.h"
#include "../../../disco/topo/fd_topo.h"
#include "../topo_run/tk_norm_stem.h"
#include "../shim/audit_schema.h"  /* PolicyOutcome, TILE_ID_TKNORM */

/* Local declaration for topo object lookup (implemented in topob.c,
   declared in tk_metric_tile.h — we avoid including that header to
   prevent the extern stem_run declaration from colliding with our
   static stem_run compiled from fd_stem.c). */
extern ulong tk_topo_find_tile_obj( fd_topo_t const * topo, ulong tile_id,
                                    char const * obj_type );

/* ---------------------------------------------------------------------
   PaymentMessage layout — mirrors tk_audit_stem.c's definition.
   tknorm receives the same fragment shape that tkings emits.
   Must match the Zig binary layout exactly.
   --------------------------------------------------------------------- */

typedef struct {
  ulong  source_offset;
  ulong  idempotency_key;
  uint   account_id;
  long   amount_cents;
  uchar  currency[3];
  uchar  malformed;
  uchar  _pad[5];
} RawPayment;

typedef struct {
  RawPayment raw;
  ulong  event_hash;
  uchar  pipeline_hops;
  uchar  duplicate;
  uchar  decision;
  uchar  decided_by[6];
} PaymentMessage;

#define PAYMENT_MSG_SIZE (sizeof(PaymentMessage))

/* ---------------------------------------------------------------------
   tknorm_ctx_t — tknorm stem tile context in scratch space.
   --------------------------------------------------------------------- */

typedef struct {
    /* Counters */
    uint64_t events_processed;
    uint64_t malformed_count;
    uint64_t normalized_count;

    /* Fragment I/O state */
    int output_ready;     /* Set in DURING_FRAG, cleared in AFTER_CREDIT */
    uint8_t  output_buf[PAYMENT_MSG_SIZE];  /* Output fragment buffer */

    /* Idle / shutdown */
    uint64_t consecutive_empty;
    int input_exhausted;  /* Set when consecutive_empty exceeds threshold */

    /* CNC & workspace pointers */
    void * cnc;           /* CNC pointer — joined in unprivileged_init */
    fd_wksp_t * wksp;     /* Input workspace — set in unprivileged_init */
} tknorm_ctx_t;

#define TK_NORM_IDLE_THRESHOLD 10000UL  /* Ticks before input_exhausted */

/* ---------------------------------------------------------------------
   Scratch helpers — footprint and alignment.
   --------------------------------------------------------------------- */

ulong
tk_norm_scratch_align( void ) {
    return TK_NORM_CTX_ALIGN;
}

ulong
tk_norm_scratch_footprint_tile( fd_topo_tile_t const * tile ) {
    (void)tile;
    ulong l = FD_LAYOUT_INIT;
    l = FD_LAYOUT_APPEND( l, TK_NORM_CTX_ALIGN, sizeof(tknorm_ctx_t) );
    l = FD_LAYOUT_APPEND( l, alignof(PaymentMessage), PAYMENT_MSG_SIZE );
    return FD_LAYOUT_FINI( l, TK_NORM_CTX_ALIGN );
}

/* ---------------------------------------------------------------------
   tknorm_privileged_init — initialize ctx fields.
   --------------------------------------------------------------------- */

static void
tknorm_privileged_init( fd_topo_t const *      topo,
                        fd_topo_tile_t const * tile ) {
    (void)topo;
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tknorm_ctx_t * ctx = (tknorm_ctx_t *)fd_ulong_align_up(
        (ulong)scratch, TK_NORM_CTX_ALIGN );

    ctx->events_processed = 0;
    ctx->malformed_count = 0;
    ctx->normalized_count = 0;
    ctx->output_ready = 0;
    ctx->consecutive_empty = 0;
    ctx->input_exhausted = 0;
    ctx->cnc = NULL;
    ctx->wksp = NULL;
}

/* ---------------------------------------------------------------------
   tknorm_unprivileged_init — find CNC, set ctx->cnc; join input wksp.
   --------------------------------------------------------------------- */

static void
tknorm_unprivileged_init( fd_topo_t const *      topo,
                          fd_topo_tile_t const * tile ) {
    (void)topo;
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tknorm_ctx_t * ctx = (tknorm_ctx_t *)fd_ulong_align_up(
        (ulong)scratch, TK_NORM_CTX_ALIGN );

    /* Look up input workspace from the first input link. */
    if (tile->in_cnt > 0) {
        fd_topo_link_t const * link = &topo->links[tile->in_link_id[0]];
        fd_topo_wksp_t const * link_wksp = &topo->workspaces[topo->objs[link->dcache_obj_id].wksp_id];
        ctx->wksp = link_wksp->wksp;
    }

    ulong cnc_obj_id = tk_topo_find_tile_obj( (fd_topo_t const *)topo, tile->id, "cnc" );
    if (cnc_obj_id != ULONG_MAX) {
        void * cnc_laddr = fd_topo_obj_laddr( (fd_topo_t const *)topo, cnc_obj_id );
        ctx->cnc = cnc_laddr;
    }
}

/* ---------------------------------------------------------------------
   tknorm_during_frag — consume, validate, hash, prepare output
   Signature: (ctx, in_idx, seq, sig, chunk, sz, ctl)
   chunk is a dcache chunk offset — resolve via fd_chunk_to_laddr.
   wksp comes from ctx->wksp (set up in unprivileged_init).
   --------------------------------------------------------------------- */

#ifndef STEM_CALLBACK_DURING_FRAG
#define STEM_CALLBACK_DURING_FRAG tknorm_during_frag
#endif

static void
tknorm_during_frag( tknorm_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    uint           ctl ) {
    (void)in_idx; (void)seq; (void)sig; (void)ctl;

    /* 1. Enforce fragment size */
    if (sz != PAYMENT_MSG_SIZE) return;

    /* 2. Decode PaymentMessage from fragment chunk.
     *    ctx->wksp is set in unprivileged_init from the input link's workspace. */
    void * chunk_laddr = fd_chunk_to_laddr( ctx->wksp, chunk );
    PaymentMessage const * msg = (PaymentMessage const *)chunk_laddr;

    /* 3. Copy fragment to scratch for modification */
    PaymentMessage * out = (PaymentMessage *)ctx->output_buf;
    *out = *msg;

    /* 4. Validate framing — inline check matching Zig runtime.validFraming:
     *    - currency must be 3 ASCII uppercase letters (A-Z)
     *    - account_id must be > 0 */
    int valid = 1;
    for (int i = 0; i < 3; i++) {
        char c = out->raw.currency[i];
        if (c < 'A' || c > 'Z') { valid = 0; break; }
    }
    if (out->raw.account_id == 0) valid = 0;

    if (valid == 0) {
        /* Malformed: set decision using canonical value from audit_schema.h */
        out->decision = POLICY_MALFORMED_DROP;
        memcpy(out->decided_by, TILE_ID_TKNORM, 6);
        ctx->malformed_count++;
    } else {
        /* 5. Compute stable event hash — inline FNV-1a placeholder.
         *    Same inputs as Zig stableEventHash: (source_offset,
         *    idempotency_key, account_id, amount_cents).
         *    TODO: replace with exact Zig hash once verified. */
        ulong h = 0xcbf29ce484222325ULL;  /* FNV offset basis */
        h = (h ^ out->raw.source_offset) * 0x100000001b3ULL;
        h = (h ^ out->raw.idempotency_key) * 0x100000001b3ULL;
        h = (h ^ out->raw.account_id) * 0x100000001b3ULL;
        ulong amt = (ulong)(long)out->raw.amount_cents;
        h = (h ^ amt) * 0x100000001b3ULL;
        out->event_hash = h;
    }

    /* 6. Increment pipeline_hops */
    out->pipeline_hops += 1;

    /* 7. Mark output as ready — publish in AFTER_CREDIT */
    ctx->output_ready = 1;
    ctx->events_processed++;
    if (valid) ctx->normalized_count++;
    ctx->consecutive_empty = 0;
}

/* ---------------------------------------------------------------------
   tknorm_after_credit — publish to tkdedu output link.
   Signature: (ctx, stem, poll_in, charge_busy)
   --------------------------------------------------------------------- */

#ifndef STEM_CALLBACK_AFTER_CREDIT
#define STEM_CALLBACK_AFTER_CREDIT tknorm_after_credit
#endif

static void
tknorm_after_credit( tknorm_ctx_t *      ctx,
                     fd_stem_context_t * stem,
                     fd_stem_tile_in_t * poll_in,
                     int *               charge_busy ) {
    (void)stem; (void)poll_in;
    /* If output fragment is ready from during_frag, publish now.
     * Otherwise this is just a credit-check tick. */
    if (ctx->output_ready) {
        /* Publish to output link index 0 (tkdedu).
         * stem_run handles backpressure via cr_avail. */
        fd_stem_publish( stem,
                         0,                          /* output link index */
                         PAYMENT_MSG_SIZE,
                         ctx->output_buf,
                         PAYMENT_MSG_SIZE,
                         0, 0, 0 );
        ctx->output_ready = 0;
    }
    *charge_busy = 0;
}

/* ---------------------------------------------------------------------
   tknorm_before_credit — idle tick tracking, HALT check.
   Signature: (ctx, stem, charge_busy)
   --------------------------------------------------------------------- */

#ifndef STEM_CALLBACK_BEFORE_CREDIT
#define STEM_CALLBACK_BEFORE_CREDIT tknorm_before_credit
#endif

static void
tknorm_before_credit( tknorm_ctx_t *      ctx,
                      fd_stem_context_t * stem,
                      int *               charge_busy ) {
    (void)stem;
    ctx->consecutive_empty++;
    /* If idle threshold exceeded, mark input_exhausted so
     * SHOULD_SHUTDOWN can exit. */
    if (ctx->consecutive_empty >= TK_NORM_IDLE_THRESHOLD) {
        ctx->input_exhausted = 1;
    }
    *charge_busy = 0;
}

/* ---------------------------------------------------------------------
   stem_run — generated via the fd_stem template.
   stem_run is compiled here with tknorm_ctx_t as CONTEXT_TYPE.
   We do NOT override STEM_EXPORT, so it defaults to static.
   This keeps stem_run internal to the tknorm translation unit.
   --------------------------------------------------------------------- */

#define STEM_BURST (1UL)
#define STEM_LAZY ((long)10e6)

#define STEM_CALLBACK_CONTEXT_TYPE  tknorm_ctx_t
#define STEM_CALLBACK_CONTEXT_ALIGN TK_NORM_CTX_ALIGN

#define STEM_CALLBACK_BEFORE_CREDIT tknorm_before_credit
#define STEM_CALLBACK_DURING_FRAG tknorm_during_frag
#define STEM_CALLBACK_AFTER_CREDIT tknorm_after_credit

/* SHOULD_SHUTDOWN as a macro — matches tk_audit_stem.c pattern.
   Checks both input_exhausted (idle threshold) and CNC HALT. */
#define STEM_CALLBACK_SHOULD_SHUTDOWN( ctx ) \
  ( (ctx)->input_exhausted || \
    ( (ctx)->cnc && fd_cnc_signal_query( (fd_cnc_t *)(ctx)->cnc ) == FD_CNC_SIGNAL_HALT ) )

#include "../../../disco/stem/fd_stem.c"

/* Clear STEM_EXPORT after the include so subsequent STEM instantiations
   (e.g. verify tile) see no STEM_EXPORT and use their own #ifndef
   STEM_EXPORT / #define STEM_EXPORT static blocks to default to static. */
#undef STEM_EXPORT

/* ---------------------------------------------------------------------
   tknorm_run — calls stem_run directly.
   We set ctx->cnc and ctx->wksp before calling stem_run.
   --------------------------------------------------------------------- */

static void
tknorm_run( fd_topo_t *      topo,
            fd_topo_tile_t * tile ) {

    tknorm_ctx_t * ctx = (tknorm_ctx_t *)fd_ulong_align_up(

        void * cnc_laddr = fd_topo_obj_laddr( topo, cnc_obj_id );
        ctx->cnc = cnc_laddr;
    }

    stem_run( topo, tile );
}
```

## Task 4: Register tknorm scratch requirements in topology build

**File:** `src/app/tickoni/topologies.zig`

### How scratch requirements flow (code path)

The scratch footprint/alignment for a tile is set via a single code path:

1. **`topologies.zig`** — Tile descriptors declare `.scratch_reqs = .{ .scratch_align = N, .footprint = M }`. This is the *only* place scratch requirements are declared. Currently:
   - `tkaudt`: `.scratch_reqs = .{ .scratch_align = 64, .footprint = 4096 }`
   - `metric`: `.scratch_reqs = .{ .scratch_align = 128, .footprint = 33554432 }`
   - `tknorm`: **no** `.scratch_reqs` field (defaults to null — no property written)
   - All other tiles: **no** `.scratch_reqs` field

2. **`topo_build.zig` `build()`** — Iterates `topo_desc.tiles`, and for any tile with `t.scratch_reqs != null`:
   ```zig
   for (topo_desc.tiles) |t| {
       if (t.scratch_reqs) |reqs| {
           c_abi.topob.topobSetTileObjPropertyUlong(topo, name_z, 0,
               "tickoni.scratch_footprint", reqs.footprint);
           c_abi.topob.topobSetTileObjPropertyUlong(topo, name_z, 0,
               "tickoni.scratch_align", reqs.scratch_align);
       }
   }
   ```
   This calls into `topob.c` to write properties on the tile's scratch object.

## Callback Mapping: Current → fd_stem

| Current Loop Step | fd_stem Callback |
|---|---|
| `while(state.q_ing_norm.pop(&state.stop))` | `DURING_FRAG` (driven by stem's input polling) |
| `validFraming(msg.raw)` | `DURING_FRAG` (inline validation) |
| `stableEventHash(msg.raw)` | `DURING_FRAG` (inline FNV-1a hash) |
| `decision = .malformed_drop` | `DURING_FRAG` (set via POLICY_MALFORMED_DROP) |
| `state.q_norm_dedu.push(msg, ...)` | `AFTER_CREDIT` (fd_stem_publish) |
| `state.stop` check | `SHOULD_SHUTDOWN` (macro: input_exhausted \|\| CNC HALT) |

## Key Design Decisions

1. **Inline framing validation in C.** The Zig `validFraming()` does a simple check (currency A-Z, account_id > 0). We replicate this inline in `tknorm_during_frag` rather than calling back to Zig — this avoids C/Zig boundary overhead per fragment.

2. **Canonical policy constants.** Uses `POLICY_MALFORMED_DROP` and `TILE_ID_TKNORM` from `audit_schema.h` — not local defines. This matches the tkaudt approach and ensures consistency across tiles.

3. **FNV-1a hash placeholder.** The `stableEventHash` function uses inline FNV-1a in `tknorm_during_frag`. Same algorithm as `tk_audit_stem.c`'s hash chain. TODO: verify output matches Zig `stableEventHash` once the canonical implementation is verified.

4. **Idle threshold: 10000 ticks.** The original loop exits when the input queue is empty (pop returns null). In fd_stem, there's no "queue empty" signal — instead we track consecutive empty ticks. 10000 ticks at ~1μs = ~10ms of idle, which is enough to detect "no more events coming" without hanging the tile. Same pattern as tk_audit_stem.c (which uses 1000).

5. **Output buffer in scratch.** tknorm holds one output fragment in `ctx->output_buf` so `DURING_FRAG` can prepare it and `AFTER_CREDIT` can publish it. This matches Firedancer's pattern where scratch space is the temporary workspace.

6. **SHOULD_SHUTDOWN as a macro.** Matches the tk_audit_stem.c pattern (`#define STEM_CALLBACK_SHOULD_SHUTDOWN(ctx) ...`) rather than a standalone function. The macro checks both `input_exhausted` and CNC HALT in a single expression.

7. **FD_LAYOUT_* for scratch footprint.** Uses `FD_LAYOUT_INIT`/`FD_LAYOUT_APPEND`/`FD_LAYOUT_FINI` for proper alignment tracking, matching the tk_audit_stem.c pattern. This is more correct than the old `fd_ulong_align_up()` approach.

8. **wksp pointer in context.** tknorm resolves chunk addresses via `fd_chunk_to_laddr(ctx->wksp, chunk)`, matching the tk_audit_stem.c pattern. The workspace pointer is set in `unprivileged_init` from the input link's workspace.

9. **WorkFn remains as fallback.** On non-Linux, tknorm continues to use the Zig WorkFn path via `TK_TILE_RUN`. The C shim is only active when `FD_HAS_LINUX` or `FD_HAS_MACOS` or `FD_HAS_WINDOWS` is defined AND `tile_run.c` dispatches to `TKNORM_RUN`.

10. **No separate fragment header.** Unlike the original plan (Task 1), tknorm reuses the `PaymentMessage` struct defined inline — the same layout as `tk_audit_stem.c` — since tknorm receives the exact fragment shape that tkings emits. No new fragment type is needed.

## Risks and Mitigations

1. **Hash mismatch between C and Zig.** If the inline FNV-1a produces different output than `stableEventHash`, downstream dedupe will see different hashes. *Mitigation:* Verify the hash output against the Zig implementation using the same fixture events. If the Zig hash uses a different algorithm, align the C implementation to match.

2. **Framing validation difference.** If the C inline check misses edge cases that the Zig `validFraming` catches, malformed events will be normalized instead of dropped. *Mitigation:* Test with the same fixture events used by the Zig unit test (`test "sandbox failure records crash diagnostics and stops normalize"`).

3. **Scratch space sizing.** If `tknorm_ctx_t` + `PaymentMessage` exceeds the allocated 4096-byte footprint, the tile will crash. *Mitigation:* Verify the footprint calculation matches `FD_LAYOUT_FINI()` output and the `scratch_reqs.footprint = 4096` in `topologies.zig`.

4. **Backpressure handling.** If stem's credit system doesn't match the current push behavior, events may be dropped or delayed. *Mitigation:* The current `q_norm_dedu.push(msg, &state.stop) catch break` already handles backpressure by breaking on error. fd_stem's `fd_stem_publish` returns silently if no credits — stem won't call AFTER_CREDIT if no credits available, which is the correct behavior.

5. **Platform parity.** On non-Linux, tknorm uses the WorkFn path. This means two code paths exist until the fd_stem shim is ported to non-Linux. *Mitigation:* Same as the metric and audit tiles — fd_stem is Linux/macOS-first, non-Linux uses WorkFn. This is acceptable for the initial migration.
