# tile_ids: Central tile ID source

**Goal:** Eliminate scattered `"tknorm"` / `"tkdedu"` / `"tkpoly"` / `"tkaudt"` / `"tkings"` / `"tkrepl"` / etc. string literals and `[6]u8` constants. One canonical `TileId` registry in `src/tickoni/runtime/tile_ids.zig`, consumed by audit, topology, tests, and C shim code.

## Current State

- 272 matches for tile ID strings across 44 source files.
- `tile.zig` defines `TileId = struct { bytes: [6]u8 }` with `parse()`, `slice()`, `eql()`.
- `audit_sink.zig` / `audit_shared.zig` define `pub const tile_id_tknorm: [6]u8 = "tknorm".*;` — raw bytes, not `TileId`.
- `topo_build.zig` tests use `TileId.parse("tknorm")` scattered inline.
- `topob.c` / `tile_run.c` use `strcmp(tile->name, "tknorm")` etc. for C-side tile dispatch.
- `PaymentMessage.decided_by: [6]u8` expects raw bytes.

## Design

### 1. Create `src/tickoni/runtime/tile_ids.zig`

Single module that owns every tile ID as a `TileId` value:

```zig
const tile = @import("tile.zig");
pub usingfield tile.TileId;

pub const tkings:  TileId = .{ .bytes = "tkings".*  };
pub const tknorm:  TileId = .{ .bytes = "tknorm".*  };
pub const tkdedu:  TileId = .{ .bytes = "tkdedu".*  };
pub const tkpoly:  TileId = .{ .bytes = "tkpoly".*  };
pub const tkaudt:  TileId = .{ .bytes = "tkaudt".*  };
pub const tkrepl:  TileId = .{ .bytes = "tkrepl".*  };
pub const tkcase:  TileId = .{ .bytes = "tkcase".*  };
pub const tkdisp:  TileId = .{ .bytes = "tkdisp".*  };
pub const tkagnt:  TileId = .{ .bytes = "tkagnt".*  };
pub const tkmodl:  TileId = .{ .bytes = "tkmodl".*  };
pub const tktool:  TileId = .{ .bytes = "tktool".*  };
pub const tkadpt:  TileId = .{ .bytes = "tkadpt".*  };
pub const tkexec:  TileId = .{ .bytes = "tkexec".*  };
pub const tkapi:   TileId = .{ .bytes = "tkapi0".*  };
pub const metric:  TileId = .{ .bytes = "metric".*  };
pub const tkdiag:  TileId = .{ .bytes = "tkdiag".*  };

/// All known tile IDs, ordered by Firedancer tile index.
pub const all: [16]TileId = .{
    tkings, tknorm, tkdedu, tkpoly, tkaudt, tkrepl, tkcase, tkdisp,
    tkagnt, tkmodl, tktool, tkadpt, tkexec, tkapi, metric, tkdiag,
};

/// Lookup: returns the TileId for a name string, or null.
pub fn lookup(name: []const u8) ?TileId {
    for (all) |id| {
        if (std.mem.eql(u8, id.slice(), name)) return id;
    }
    return null;
}
```

### 2. Update audit code to use `TileId`

- **`audit_shared.zig`** — delete. Its 4 constants are superseded by `tile_ids.zig`.
- **`audit_sink.zig`** — keep `audit_seed`, `AuditLog`, `Decision`, `buildPolicyDecisionEvent`, `fillEventMetadata`. Remove the tile_id constants (already moved).
- **`runtime.zig`** — change `PaymentMessage.decided_by` from `[6]u8` to `tile_ids.TileId`. Update default: `decided_by: TileId = tile_ids.tkpoly`.
- **`normalize.zig`**, **`policy.zig`**, **`process.zig`**, **`audit_stage.zig`**, **`replay.zig`** — change `msg.decided_by = ...` to use `tile_ids.tknorm` etc. (these are now `TileId`, not `[6]u8`).
- **`replay.zig`** — `decided_by` is now `tile_ids.TileId` (no more `[6]u8` cast needed in `buildReplayEvent`).

### 3. Update topology code

- **`topo_build.zig`** — replace `TileId.parse("tknorm")` etc. with `tile_ids.tknorm` etc. in tests. The `build()` function already calls `tile.TileId.parse()` on runtime-recovered names — that stays (it's the only place that does runtime string→TileId).
- **`tile_registry.zig`** — replace `TileId.parse("tknorm")` with `tile_ids.tknorm` etc.

### 4. Update test fixtures

- **`test/fixtures/investment/audit_trace.zig`** — replace `"tknorm"` etc. in `fixtureHeader()` calls with `tile_ids.tknorm.slice()` or `tile_ids.tknorm.bytes`.
- **`test/integration/*.zig`** — replace `TileId.parse("tknorm")` with `tile_ids.tknorm` etc.
- **`test/perf/*.zig`** — same.

### 5. Update C shim code

- **`c_abi/shim/audit_schema.h`** — replace string literals with `#define TILE_ID_TKNORM "tknorm"` etc. (C doesn't have typed TileId, but at least they're named constants in one header).
- **`c_abi/shim/tile_run.c`** — replace `strcmp(tile->name, "audit_tile")` with a macro or switch table using `TILE_ID_TK_AUDIT` constant.
- **`c_abi/shim/tk_audit_stem.c`** — same.

### 6. Delete stale files

- **`audit_shared.zig`** — delete (superseded by `tile_ids.zig`).
- No need to delete `audit_sink.zig` — it still owns `AuditLog`, `Decision`, `buildPolicyDecisionEvent`, `fillEventMetadata`.

## Risks

- `PaymentMessage.decided_by` changing from `[6]u8` to `TileId` is a struct layout change. Need to verify serialization/deserialization is compatible (Zig structs with same layout should be binary-compatible).
- C shim code can't use `TileId` — it uses `strcmp` on C strings. The C header `audit_schema.h` should own C-level tile ID strings; Zig code should own `TileId` values. They can coexist.
- 272 references across 44 files — this is a large refactor. Do it in phases: (1) create tile_ids.zig, (2) audit code, (3) topology code, (4) tests, (5) C shim.

## Execution Order

1. Create `tile_ids.zig`
2. Delete `audit_shared.zig`, update audit code (`runtime.zig` `decided_by` type change, consumers)
3. Update topology/build code (`topo_build.zig`, `tile_registry.zig`, `topologies.zig`)
4. Update test fixtures
5. Update C shim headers/files
6. Run `zig build test-unit-tk` + `zig build test-integration-tk`
