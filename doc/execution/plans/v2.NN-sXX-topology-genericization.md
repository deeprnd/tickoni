# v2.NN-sXX-topology-genericization

## Problem

The topology/orchestrator/supervisor assumes tile ordering and tile count.
Channels reference tiles by array index, not by identity. The supervisor
uses fixed `[8]` arrays everywhere. C shims do `strcmp(tile_name, "tkaudt")`
and `strcmp(tile_name, "metric")` — scattered string comparisons that tie
the runtime to specific tile IDs/names.

Changes that broke things:

1. `topologies.zig`: changed `.name` from `"tkaudt"` → `"audit_tile"`,
   `"tkrepl"` → `"replay_tile"`, `"tkdiag"` → `"diag_tile"`.
2. `tile_run.c`: changed `strcmp(tile->name, "tkaudt")` → `"audit_tile"`.
3. `topob.c`: still checks `"tkaudt"` (TileId string) — **inconsistent**.
   Now `tile_run.c` matches `.name`, `topob.c` matches TileId. They diverge.

Rule: only the tk-audit file and build system should know about `tkaudt`.
The orchestrator, supervisor, topology builder, and C shims must not do
string comparisons against tile IDs.

## Root Cause

- Channels use `src_idx: u32, dst_idx: u32` — positional, not identity-based.
- `topo_build.zig` indexes `topo_desc.tiles[ch.src_idx]` — array position.
- `supervisor.zig` uses `[8]` fixed arrays for CNCs, children, configs.
- `tile_registry.zig` mirrors topology order.
- `topob.c` does `strcmp(tile_name, "tkaudt")` — C-level string matching.
- No abstraction layer between tile identity and tile position.

## Solution Overview

Replace positional topology with identity-based topology, introduce TileRole
enum for property-based behavior, and replace fixed arrays with dynamic
sizing.

## Phases

### Phase 0: Immediate Fix (unbreak the build)

**Goal:** Fix the `topob.c` inconsistency.

**Action:** Align `topob.c` with the `.name` field. Change
`strcmp(tile_name, "tkaudt")` → `strcmp(tile_name, "audit_tile")` in
`topob.c:397/414`. This is a stopgap — Phase 1 removes string comparisons.

**Files:** `src/tickoni/c_abi/shim/topob.c`

### Phase 1: Centralize tile identity — introduce TileRole

**Goal:** Replace all `strcmp(tile_name, "tkaudt") == 0` with a single
centralized lookup that doesn't use string comparisons.

**Design:**

```zig
// src/tickoni/topology/tile_role.zig (new file)

pub const TileRole = enum {
    ingest,
    normalize,
    dedupe,
    policy,
    audit,
    replay,
    metric,
    diag,
};

pub const TileRoleInfo = struct {
    role: TileRole,
    is_audit_stem: bool = false,
    is_metric: bool = false,
    scratch_footprint: usize = 1,
    scratch_align: usize = 1,
};

pub const registry: [8]TileRoleInfo = .{
    .{ .role = .ingest },
    .{ .role = .normalize },
    .{ .role = .dedupe },
    .{ .role = .policy },
    .{ .role = .audit, .is_audit_stem = true, .scratch_footprint = ... },
    .{ .role = .replay },
    .{ .role = .metric, .is_metric = true, .scratch_footprint = ... },
    .{ .role = .diag },
};

pub fn findByTileId(id: TileId) ?TileRoleInfo {
    for (registry, 0..) |info, i| {
        if (id.eql(topology.tile(i).id)) return info;
    }
    return null;
}
```

**Files changed:**
- `src/tickoni/topology/tile_role.zig` (new)
- `src/tickoni/c_abi/shim/tile_run.c` — replace strcmp with Zig API call
- `src/tickoni/c_abi/shim/topob.c` — remove strcmp, use Zig lookup
- `src/tickoni/runtime/topo_build.zig` — use TileRoleInfo directly
- `src/tickoni/runtime/c_abi/topob.h` — add tile_is_audit_stem() declaration
- `src/tickoni/c_abi/shim/topob.c` — implement tile_is_audit_stem()

### Phase 2: Index-independent topology — TileId-based channels

**Goal:** Channels reference tiles by TileId, not by array index.

**Current:**
```zig
.{ .src_idx = 0, .dst_idx = 1, ... }
```

**Target:**
```zig
.{ .src_id = TileId.ingest, .dst_id = TileId.normalize, ... }
```

**Changes:**

1. `src/tickoni/runtime/link/types.zig` — Channel struct:
   ```zig
   pub const Channel = struct {
       src_id: TileId,      // was: src_idx: u32
       dst_id: TileId,      // was: dst_idx: u32
       depth: u32,
       mtu: u32,
       // ...
   };
   ```

2. `src/tickoni/runtime/topology.zig` — Topology.validate():
   ```zig
   for (self.channels) |ch| {
       if (findById(self.tiles, ch.src_id) == null) return error.UnknownChannelSource;
       if (findById(self.tiles, ch.dst_id) == null) return error.UnknownChannelDestination;
   }
   ```

3. `src/tickoni/runtime/topo_build.zig` — channel wiring:
   ```zig
   const src_name_z = toZ(&src_name_buf, ch.src_id.slice());
   const dst_name_z = toZ(&dst_name_buf, ch.dst_id.slice());
   ```

4. `src/app/tickoni/tile_registry.zig` — validate() uses TileId matching.

5. `src/app/tickoni/topologies.zig` — all channels use TileId values.

6. `src/app/tickoni/supervisor.zig` — spawn/monitor loops use TileId lookup.

### Phase 3: Replace fixed [8] arrays

**Goal:** Supervisor handles arbitrary tile counts.

**Changes:**

1. `ProcessState` — replace `[8]` with `[]` slices:
   ```zig
   cncs: []?*c_abi.cnc.Cnc,
   children: []ChildRecord,
   ```

2. `ProcessPipelineConfig` — replace `[8]u32`:
   ```zig
   crash_after_heartbeats: []u32,
   ```

3. All loop bounds use `.len`, not hardcoded 8.

**Files:** `src/app/tickoni/supervisor.zig`

### Phase 4: Property-based scratch/workspace assignment

**Goal:** Tile-specific workspace/scratch declared by role, not strcmp in C.

**Changes:**

1. `src/tickoni/runtime/topo_build.zig` — direct Zig lookup:
   ```zig
   for (topo_desc.tiles) |t| {
       const reqs = tile_role.findByTileId(t.id) orelse continue;
       if (reqs.scratch_footprint > 1) {
           c_abi.topob.topobSetTileObjPropertyUlong(topo, t.id.slice(), 0,
               scratch_footprint_key, reqs.scratch_footprint);
       }
   }
   ```

2. `src/tickoni/c_abi/shim/topob.c` — remove `tickoniTileScratchRequirements()`
   strcmp logic entirely. Make it return defaults.

3. Remove `"metric"` and `"tkaudt"` strcmp checks from C shims.

## Verification

- All unit tests in `topologies.zig`, `topo_build.zig`, `tile_registry.zig`
  pass with TileId-based channels.
- Integration tests run successfully.
- No `strcmp(tile_name, "tkaudt")` or `strcmp(tile_name, "metric")` remains
  in `topob.c` or `tile_run.c`.
- Reordering tiles in `payment_tiles[]` does not require updating any channel
  definitions.
- Changing `.name` field values does not break any C shim comparisons.

## Dependency Graph

```
Phase 0 (fix inconsistency)
    ↓
Phase 1 (TileRole enum, centralize identity checks)
    ↓
Phase 2 (TileId-based channels, index-independent topology)
    ↓
Phase 3 (Dynamic arrays, no fixed [8])
    ↓
Phase 4 (Property-based scratch/workspace — remove C strcmps)
```

Phases 1 and 2 are highest impact. Phase 1 fixes the immediate broken state
and establishes the abstraction. Phase 2 makes topology genuinely order-independent.

## What NOT to do

- Don't make the orchestrator "smart" about tile names by parsing them.
  Tile names are implementation details; the role enum is the right abstraction.
- Don't add a config file to map tile names to roles. This is compile-time
  knowledge — the topology defines which tiles run and what they do.
- Don't use string-based routing (e.g., "if name starts with 'tk' it's a
  pipeline tile"). Use explicit enum values.
