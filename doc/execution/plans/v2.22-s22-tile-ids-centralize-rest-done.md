# tile_ids: Complete centralization (remainder)

**Parent:** `v2.22-sXX-tile-ids-central.md` (step 1–2 done; steps 3–5 incomplete)
**Goal:** Eliminate the remaining ~150 scattered tile ID string literals in Tickoni source code. Replace all inline strings and deprecated constants with canonical `tile_ids.*` references.

## What's Already Done (from v2.22-sXX-tile-ids-central)

- ✅ `src/tickoni/runtime/tile_ids.zig` — created with all 16 tiles, `lookup()`, `all` array
- ✅ `audit_shared.zig` — deleted
- ✅ `runtime.zig` — `decided_by` type changed from `[6]u8` to `tile_ids.TileId`
- ✅ Payment pipeline audit consumers — `normalize.zig`, `policy.zig`, `process.zig`, `audit_stage.zig`, `replay.zig` — use `tile_ids.tknorm`, `tile_ids.tkpoly`, etc.
- ✅ C shim `audit_schema.h` — `#define TILE_ID_*` macros created
- ✅ C shim `tile_run.c` — `strcmp(..., "tkaudt")` already uses `TILE_ID_TKAUDT` macro via `tile_is_audit()`
- ✅ C shim `tk_audit_stem.c` — already uses `TILE_ID_TKAUDT` (from `audit_schema.h` via include)

## Remaining Work

### Step 1: Fix core source (production code, not tests)

#### 1a. `tile_registry.zig` — registry entries and test string arrays

The `id()` helper already wraps `tile_ids.lookup(s)`, so the code is functionally correct. Replace string literals with `tile_ids.*` constants for canonical references.

**Registry entries (lines 188–242)** — the `.id = id("tkings")` etc. calls:

```
.id = id("tkings")    → .id = tile_ids.tkings
.id = id("tknorm")    → .id = tile_ids.tknorm
.id = id("tkdedu")    → .id = tile_ids.tkdedu
.id = id("tkpoly")    → .id = tile_ids.tkpoly
.id = id("tkaudt")    → .id = tile_ids.tkaudt
.id = id("tkrepl")    → .id = tile_ids.tkrepl
.id = id("metric")    → .id = tile_ids.metric
.id = id("tkdiag")    → .id = tile_ids.tkdiag
```

**Test `inline for` loops (lines 299, 311, 319, 489)** — iterate tile names as strings. Since these are test-only and use `tile_ids.lookup(name)` immediately after, leave as-is. They test the lookup function itself.

#### 1b. `supervisor.zig` — `std.mem.eql` string comparisons

Lines 750 and 761 compare `tile_name` against `"tkaudt"` using string equality. Replace with `tile_ids.tkaudt.eql(tile_name)`.

#### 1c. `topob.c` — `strcmp` with raw strings

Lines 417, 419, 430, 436: `strcmp(tile_name, "metric")` and `strcmp(tile_name, "tkaudt")`. These need to use the `TILE_ID_METRIC` and `TILE_ID_TKAUDT` macros from `audit_schema.h` (already `#include`d).

#### 1d. `jsonl.zig` — `std.mem.copyForwards` with raw strings

Lines 200 and 281: `std.mem.copyForwards(u8, &event.header.tile_id, "tkings")`. Replace with `std.mem.copyForwards(u8, &event.header.tile_id, tile_ids.tkings.slice())`.

#### 1e. `audit_sink.zig` — remove deprecated tile_id constants

Lines 25–27: `tile_id_tknorm`, `tile_id_tkdedu`, `tile_id_tkpoly` are marked `Deprecated` in the comment and already superseded by `tile_ids.*`. Remove them and update any remaining consumers.

**Note:** The `AuditAppendInput.tile_id` field is `[6]u8` and `buildPolicyDecisionEvent(tile_id: [6]u8)` — these accept raw bytes. Callers pass `msg.decided_by.bytes` (a `TileId`'s `.bytes` field), which is the correct pattern. No type change needed for `audit_sink.zig`'s ABI — callers convert.

### Step 3: Update integration tests

#### 3a. Tile name arrays in replay tests

`test_investment_replay.zig` lines 187–189, 378–380: arrays of tile name strings like `["tkings", "tknorm", ...]`. These are test fixtures comparing expected tile name order. Replace with `.slice()` calls or build the array from `tile_ids.all`.

#### 3b. `expectEqualStrings` assertions

Across `topologies.zig`, `test_minimal_setup.zig`, `test_process_topology.zig`, `launch_spec.zig`, `topology_spec.zig` — assertions like `expectEqualStrings("tkings", topo.tiles[0].name.slice())`.

These test that the topology produces the expected tile names. Replace with:
```zig
try std.testing.expectEqualStrings(tile_ids.tkings.slice(), topo.tiles[0].name.slice());
```

#### 3c. `TileId.parse("...")` in tests

Tests like `test_metric_watchdog.zig`, `topo_build.zig`, `tile.zig` use `TileId.parse("tkings")` to create test TileIds. These should use `tile_ids.tkings` directly since the canonical TileId is available.

**Caveat:** `TileId.parse()` is the only runtime string→TileId path (and should stay). Tests that want to verify parse correctness can keep using it. Tests that just need a known TileId should use `tile_ids.*`.

### Step 4: Update log calls in pipeline tiles (lower priority)

#### 4a. `log.enter` / `log.exit` / `log.kvFmt` / `log.err` / `log.debug`

All pipeline tile files use string tile names as the first arg to logging macros:
- `ingest.zig`: `"tkings"` (lines 14, 15, 34, 36)
- `normalize.zig`: `"tknorm"` (lines 14, 15, 29, 36, 39)
- `dedupe.zig`: `"tkdedu"` (lines 12, 13, 25, 29)
- `audit_stage.zig`: `"tkaudt"` (lines 17, 18, 32, 36, 39)

- `policy.zig`: `"tkpoly"` (lines 15, 16, 32, 37, 42, 46)
- `diag.zig`: `"tkdiag"` (lines 11, 12, 18, 24)

Replace with `tile_ids.<name>.slice()`. This is mechanical but touches many files. The log macros accept `[]const u8`, so `.slice()` works directly.

## Execution Order

1. **Core source** (step 1): `tile_registry.zig`, `supervisor.zig`, `topob.c`, `jsonl.zig`, `audit_sink.zig` — these are production code with the highest risk of breaking if wrong.
2. **Test fixtures** (step 2): `fixture_events.zig`, `audit_trace.zig` — data-driven test inputs.
3. **Integration tests** (step 3): All `test/integration/*.zig`, `topologies.zig` tests, `topo_build.zig` tests, `test_metric_watchdog.zig` — mechanical replacements.
4. **Log calls** (step 4): All pipeline tile log calls (`ingest`, `normalize`, `dedupe`, `audit_stage`, `replay`, `policy`, `diag`) — lowest risk, purely cosmetic/cleanliness.
5. **Build + test**: `zig build test-unit-tk` then `zig build test-integration-tk`.

## Risks

- `topob.c` `strcmp` with `TILE_ID_*` macros: The macros expand to string literals, so `strcmp(tile_name, TILE_ID_TKAUDT)` works exactly like `strcmp(tile_name, "tkaudt")`. No ABI change.
- `audit_sink.zig` deprecated constants: Verify no remaining consumers before deleting. The `AuditAppendInput.tile_id` field is still `[6]u8` (correct — callers convert `TileId.bytes` to `[6]u8`).
- Test files importing tile-named *modules* (e.g., `const tkpoly = @import("tkpoly")`) — these import the `tkpoly` *module*, not a TileId value. They are unrelated to tile ID centralization. Only change them if they also use tile ID string literals as data.
- Log call changes are purely cosmetic but touch many files. Do them last so the critical structural changes build and pass first.
