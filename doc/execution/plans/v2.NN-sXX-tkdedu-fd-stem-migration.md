## Gap Analysis

### What exists today

| Component | Current state |
|-----------|---------------|
| tkdedu process-mode code | `process.zig:runDedupeProcess` — 30 lines, reads from input link, linear dedup check via `seenOrRemember`, marks duplicate, forwards to output link |

| tkdedu in topology spec | tile index 2, name="tkdedu", channels: [tknorm→tkdedu (depth=64, mtu=128), tkdedu→tkpoly (depth=64, mtu=128)] |
| tkdedu in supervisor spawn | Uses `__tile-run` (not `__stem-run`) |
| tkdedu stem files | `tk_dedu_stem.c` — DOES NOT EXIST. `tk_dedu_stem.h` — DOES NOT EXIST |
| audit_schema.h | Contains TILE_ID_TKDEDU, PaymentMessage, PAYMENT_MSG_SIZE (56 bytes) |
| stem_helpers.h | Shared boilerplate for ALL stem tiles: STK_GET_CTX, stk_derive_wksp, STK_UNPRIV_INIT, STK_EVENT_EXHAUSTED, stk_publish_progress, stk_validate_frag, stk_chunk_to_gaddr |
| tknorm stem | `tk_normalize_stem.c` (1-in, 1-out, DURING_FRAG + AFTER_CREDIT) — reference for output publish |
| tkaudt stem | `tk_audit_stem.c` (1-in, 0-out, DURING_FRAG only) — reference for scratch arrays |

### What's missing

The tkdedu stem tile needs to implement:

1. **Context struct** (`tkdedu_ctx_t`) — counters (duplicates, processed), dedup arrays (seen_keys, seen_hashes) in scratch, flags (input_exhausted), output tracking (output_ready, output_sz, output_chunk), workspace pointer, event_count gating
2. **Scratch layout** — `tkdedu_scratch_align()` = 8, `tkdedu_scratch_footprint()` = sizeof(ctx) + alignment + seen_keys[N] + seen_hashes[N] + PaymentMessage output buffer (56 bytes), where N = event_count
3. **DURING_FRAG callback** — Read PaymentMessage from input dcache, copy to scratch, increment pipeline_hops, skip dedup check for malformed_drop messages, linear scan seen_keys/seen_hashes for duplicate, mark duplicate and increment counter if found, add to seen arrays if new, set output_ready
4. **AFTER_CREDIT callback** — If output_ready, publish to output dcache via fd_stem_publish, reset output_ready, charge_busy=0
5. **SHOULD_SHUTDOWN macro** — CNC HALT + event_count exhaustion
6. **privileged_init** — Get ctx from scratch, set wksp from input mcache, allocate dedup arrays and output buffer from scratch, init counters
7. **unprivileged_init** — Find CNC object, set ctx->cnc
8. **tkdedu_run entry point** — Get ctx from scratch, enter stem loop
9. **fd_topo_run_tile_t** — TK_DEDU_RUN with all callbacks wired
10. **Shared header** — Extern declaration for TK_DEDU_RUN, tk_get_dedu_run_tile(), scratch footprint accessor
11. **Dispatch chain** — tile_is_dedu() in tile_run.c
12. **Supervisor wiring** — detect tkdedu for __stem-run, pass TKDEDU_EVENT_COUNT env
13. **Build wiring** — topo_run.shims, shims.zim, codec.zim, topob.c

### Key differences from tknorm

| Aspect | tknorm (1-in, 1-out) | tkdedu (1-in, 1-out) |
|--------|----------------------|----------------------|
| Core logic | Validates framing, computes FNV-1a hash, stamps decision | Linear dedup check against seen_keys/seen_hashes arrays |
| Hash function | FNV-1a (same seed as runtime.zig: audit_seed=0ULL) | No hash computation — uses event_hash already computed by tknorm |
| Dedup state | None | Large scratch-allocated arrays (2N u64s, where N=event_count) |
| Output buffer | Scratch-reserved PaymentMessage slot | Same pattern — scratch-reserved slot |
| Decision logic | malform drop vs allow | Pass through; only marks `duplicate = true` |
| Event count | Uses TKNORM_EVENT_COUNT env | Needs TKDEDU_EVENT_COUNT env |

### Key differences from tkaudt

| Aspect | tkaudt (1-in, 0-out) | tkdedu (1-in, 1-out) |
|--------|----------------------|----------------------|
| Output links | 0 — no AFTER_CREDIT needed | 1 — needs AFTER_CREDIT for publish |
| State | AuditEvent ring buffer + hash chain | Dedup arrays (seen_keys, seen_hashes) |
| Decision | Builds new audit records | Forwards input as-is, marks duplicate |
| Event gating | TKAUDT_EVENT_COUNT | TKDEDU_EVENT_COUNT |

### 1a: Create `src/tickoni/c_abi/shim/tk_dedu_stem.c`

**Structure:**

```c
/* tk_dedu_stem.c — Stem fd_stem tile for tkdedu.

   Tile behavior:
   - DURING_FRAG: read PaymentMessage from input dcache, increment
     pipeline_hops, skip dedup for malformed_drop, linear scan
     seen_keys/seen_hashes for duplicate, mark + forward as-is
   - AFTER_CREDIT: if output_ready, publish to output dcache via
     fd_stem_publish, reset output_ready
   - SHOULD_SHUTDOWN: CNC HALT + event_count exhaustion

   Uses stem_helpers.h for shared boilerplate:
   STK_GET_CTX, stk_derive_wksp, STK_UNPRIV_INIT,
   stk_validate_frag, stk_chunk_to_gaddr, STK_EVENT_EXHAUSTED,
   stk_publish_progress
*/

#define _GNU_SOURCE

#include "firedancer.h"
#include "audit_schema.h"
#include "../stem_helpers.h"

#include "../../../disco/topo/fd_topo.h"
#include "../../../util/fd_wksp.h"
#include "../../../util/fd_util.h"

#include <string.h>
#include <stddef.h>

/* Context — MUST be defined BEFORE STEM_CALLBACK_CONTEXT_TYPE */
typedef struct {
    /* Counters */
    uint64_t duplicates;
    uint64_t processed;

    /* Dedup state — scratch-allocated arrays */
    uint64_t seen_count;
    uint64_t *seen_keys;
    uint64_t *seen_hashes;

    /* Output state (set in during_frag, consumed in after_credit) */
    int      output_ready;
    uint64_t output_sz;
    uint64_t output_chunk;

    /* CNC reference for shutdown detection */
    void     *cnc;

    /* Tile pointer */
    fd_topo_tile_t const *tile;

    /* Workspace pointer for dcache writes */
    void *wksp;

    /* Scratch-allocated output PaymentMessage buffer */
    PaymentMessage *output_msg;

    /* Event count gating */
    uint64_t event_count;
    int      input_exhausted;
} tkdedu_ctx_t;

#define TKDEDU_CTX_ALIGN alignof(tkdedu_ctx_t)
#define TKDEDU_OUTPUT_CAPACITY 1

/* Generate stem specialization */
#define STEM_NAME                         tkdedu
#define STEM_BURST                        (1UL)
#define STEM_LAZY                         ((long)10e6)
#define STEM_CALLBACK_CONTEXT_TYPE        tkdedu_ctx_t

#define STEM_CALLBACK_SHOULD_SHUTDOWN(ctx) \

    ( (ctx)->cnc && fd_cnc_signal_query( (fd_cnc_t *)(ctx)->cnc ) == FD_CNC_SIGNAL_HALT ) )

#include "../../../disco/metrics/fd_metrics.h"
#include "../../../disco/stem/fd_stem.c"

/* ─── Scratch footprint ─── */

static ulong
tkdedu_scratch_align( void ) {
    return TKDEDU_CTX_ALIGN;
}

static ulong
tkdedu_scratch_footprint_tile( fd_topo_tile_t const * tile ) {
    (void)tile;
    /* Context + alignment */
    ulong footprint = fd_ulong_align_up( sizeof(tkdedu_ctx_t), TKDEDU_CTX_ALIGN );

    /* Dedup arrays: N entries each (N determined at runtime from env).
       For the footprint query, we report a minimum baseline that is
       always valid (at least 1 entry). The actual allocation size
       depends on event_count and is handled in privileged_init via
       fd_scratch_alloc with the runtime-computed size.
      
       However, fd_topob's scratch_footprint callback is called during
       topology build and must return a fixed value. We use a
       conservative estimate: if event_count > 0, we need 2*N*8 bytes
       for the arrays. If event_count == 0 (rare edge case), we still
       need room for at least one entry.
       
       NOTE: The footprint is queried with tile == NULL for the
       no-argument wrapper, and with tile != NULL for the per-tile
       version. For the per-tile version, we can read event_count
       from the environment. For the no-argument wrapper, we use
       a safe default. */
    ulong event_count = 10000;  /* default — matches supervisor config */
    {
        const char *env = getenv("TKDEDU_EVENT_COUNT");
        if (env) {
            event_count = strtoull(env, NULL, 10);
            if (event_count == 0) event_count = 10000;  /* fallback */
        }
    }

    /* seen_keys and seen_hashes follow aligned context */
    ulong arr_align = fd_ulong_align_up( footprint, alignof(uint64_t) );
    footprint = arr_align + sizeof(uint64_t) * event_count * 2;

    /* output_msg follows aligned arrays */
    footprint = fd_ulong_align_up( footprint, alignof(PaymentMessage) );
    footprint += sizeof(PaymentMessage) * TKDEDU_OUTPUT_CAPACITY;

    return footprint;
}

ulong
tkdedu_scratch_footprint( void ) {
    return tkdedu_scratch_footprint_tile( NULL );
}

/* ─── Callbacks ─── */

static void
tkdedu_privileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tkdedu_ctx_t * ctx = STK_GET_CTX(tkdedu_ctx_t, scratch, TKDEDU_CTX_ALIGN);

    ctx->duplicates = 0;
    ctx->processed = 0;
    ctx->seen_count = 0;
    ctx->output_ready = 0;
    ctx->cnc = NULL;
    ctx->event_count = 0;
    ctx->input_exhausted = 0;

    /* Derive workspace pointer from input mcache */
    ctx->wksp = stk_derive_wksp(topo, tile, 0);

    /* Read event_count from environment */
    {
        const char *env = getenv("TKDEDU_EVENT_COUNT");
        if (env) {
            ctx->event_count = strtoull(env, NULL, 10);
            FD_LOG_NOTICE(( "tkdedu: event_count=%lu from env", (unsigned long)ctx->event_count ));
        }
    }

    /* Allocate dedup arrays from scratch */
    ulong arr_align = fd_ulong_align_up( (ulong)ctx + sizeof(tkdedu_ctx_t), alignof(uint64_t) );
    uint64_t * arr = (uint64_t *)arr_align;
    ctx->seen_keys = arr;
    ctx->seen_hashes = arr + ctx->event_count;

    /* Point output_msg at scratch block after arrays */
    ulong out_align = fd_ulong_align_up( (ulong)arr + sizeof(uint64_t) * ctx->event_count * 2,
                                          alignof(PaymentMessage) );
    ctx->output_msg = (PaymentMessage *)out_align;

    FD_LOG_NOTICE(( "tkdedu: privileged init ctx=%p seen_keys=%p seen_hashes=%p output=%p wksp=%p",
                    ctx, ctx->seen_keys, ctx->seen_hashes, ctx->output_msg, ctx->wksp ));
}

static void
tkdedu_unprivileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tkdedu_ctx_t * ctx = STK_GET_CTX(tkdedu_ctx_t, scratch, TKDEDU_CTX_ALIGN);

    /* Shared boilerplate: find CNC and set ctx->cnc */
    STK_UNPRIV_INIT(topo, tile, ctx);

    FD_LOG_NOTICE(( "tkdedu: unprivileged init tile_id=%lu cnc=%p", tile->id, ctx->cnc ));
}

static void
tkdedu_during_frag( tkdedu_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    ulong          ctl ) {
    (void)in_idx; (void)seq; (void)sig; (void)ctl;

    /* Shared boilerplate: empty check, size check, wksp check, chunk→gaddr */
    if (!stk_validate_frag(sz, PAYMENT_MSG_SIZE, ctx->wksp))
        return;
    PaymentMessage const * msg_in = stk_chunk_to_gaddr(ctx->wksp, chunk);

    /* Copy input to output buffer */
    memcpy(ctx->output_msg, msg_in, sizeof(PaymentMessage));
    ctx->output_msg->pipeline_hops += 1;

    /* Dedup check: skip for malformed_drop (tknorm already rejected it) */
    if (ctx->output_msg->decision != (uint8_t)POLICY_MALFORMED_DROP) {
        /* Linear scan for duplicate */
        int is_dup = 0;
        for (uint64_t i = 0; i < ctx->seen_count; i++) {
            if (ctx->seen_keys[i] == ctx->output_msg->raw.idempotency_key &&
                ctx->seen_hashes[i] == ctx->output_msg->event_hash) {
                is_dup = 1;
                break;
            }
        }

        if (is_dup) {
            ctx->output_msg->duplicate = 1;
            ctx->duplicates += 1;
        } else {
            /* Remember this (key, hash) pair */
            ctx->seen_keys[ctx->seen_count] = ctx->output_msg->raw.idempotency_key;
            ctx->seen_hashes[ctx->seen_count] = ctx->output_msg->event_hash;
            ctx->seen_count += 1;
        }
    }

    /* Shared boilerplate: event-count gating */
    STK_EVENT_EXHAUSTED(ctx, ctx->event_count, ctx->processed);

    /* Mark output ready */
    ctx->output_ready = 1;
    ctx->output_sz = PAYMENT_MSG_SIZE;

    /* Shared boilerplate: progress publishing */
    stk_publish_progress(ctx->cnc, ctx->processed);

    ctx->processed += 1;
}

static void
tkdedu_after_credit( tkdedu_ctx_t *    ctx,
                     fd_stem_t *       stem,
                     fd_stem_tile_in_t * poll_in,
                     int *             charge_busy ) {
    (void)poll_in;

    if (ctx->output_ready) {
        /* Allocate from output dcache */
        ulong out_chunk = fd_dcache_find_free( stem, 0, ctx->output_sz, ctx->output_sz );
        if (out_chunk) {
            /* Copy output message to dcache slot */
            void * dst = fd_wksp_laddr_fast(ctx->wksp, out_chunk * FD_CHUNK_ALIGN);
            memcpy(dst, ctx->output_msg, ctx->output_sz);

            /* Publish */
            fd_stem_publish(stem, 0, ctx->output_sz, out_chunk, ctx->output_sz, 0, 0, 0);
        }

        ctx->output_ready = 0;
    }

    *charge_busy = 0;
}

/* ─── Run entry point ─── */

static void
tkdedu_run( fd_topo_t *      topo,
            fd_topo_tile_t * tile ) {
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tkdedu_ctx_t * ctx = (tkdedu_ctx_t *)fd_ulong_align_up( (ulong)scratch, TKDEDU_CTX_ALIGN );

    ulong cnc_obj_id = tk_topo_find_tile_obj( topo, tile->id, "cnc" );
    if (FD_UNLIKELY(cnc_obj_id == ULONG_MAX))
        FD_LOG_ERR(( "tkdedu: CNC object not found for tile %lu", tile->id ));
    ctx->cnc = fd_topo_obj_laddr( topo, cnc_obj_id );

    tkdedu_run(topo, tile);  /* stem_run loop */

    tile->allow_shutdown = 1;
}
```

**Pitfalls to watch:**
- **Scratch footprint with dynamic arrays:** The dedup arrays are N×8 bytes each where N = event_count. The footprint callback must handle this dynamically (read env var in `tkdedu_scratch_footprint_tile`). If `tkdedu_scratch_footprint_tile` is called with `tile == NULL`, it must still return a valid footprint.
- **Array allocation in privileged_init:** The arrays must be allocated from scratch at the right offsets. `privileged_init` computes the offsets and assigns pointers.
- **Output dcache publish:** tkdedu has 1 output link (to tkpoly), so AFTER_CREDIT must allocate and publish. Use the same pattern as tknorm's tknorm_after_credit.
- **Dedup skip for malformed_drop:** The Zig code explicitly skips dedup check when `msg.decision == .malformed_drop`. The C code must do the same.
- **Linear scan is O(n):** Each message does a linear scan of seen_count entries. For N events, this is O(N²) total. This matches the existing process-mode behavior.

## Risks and Mitigations

1. **Scratch footprint with dynamic arrays:** The dedup arrays are N×8 bytes each where N = event_count (from env var). The `tkdedu_scratch_footprint_tile` callback reads the env var to compute the footprint. **Mitigation:** If the env var is not set, default to 10000 (matching supervisor's default event_count). Both `tkdedu_scratch_footprint()` (no-arg wrapper) and `tkdedu_scratch_footprint_tile(tile)` (per-tile) must return the same value.

2. **Array allocation offsets:** The dedup arrays and output buffer must be allocated at deterministic offsets from scratch. **Mitigation:** `privileged_init` computes offsets sequentially: context → seen_keys → seen_hashes → output_msg, with proper alignment between each.

3. **Dedup semantics parity:** The C linear scan must produce identical duplicate counts to the Zig `seenOrRemember` function. **Mitigation:** The linear scan matches the Zig `for (seen_keys[0..seen_count], seen_hashes[0..seen_count])` loop exactly. Both skip dedup for malformed_drop messages.

4. **Output dcache publish:** tkdedu has 1 output link (to tkpoly), so AFTER_CREDIT must allocate from the output dcache and call `fd_stem_publish`. **Mitigation:** Follow the tknorm spike plan's pattern. The output buffer is scratch-allocated. `fd_stem_publish` signature: `(stem, out_idx, data_sz, data_chunk, wire_sz, tag, 0, 0)`.

5. **Event count gating:** tkdedu exits when processed >= event_count. **Mitigation:** Use STK_EVENT_EXHAUSTED macro from stem_helpers.h, identical pattern to tkaudt and tknorm.
