# tkaudt — Stem Tile Migration (Consolidated Plan)

> **Status:** Plan only — not yet executed.
> **Prerequisite:** None.
> **Scope:** Migrate tkaudt from process-mode to `fd_stem` tile, incrementally — wire a minimal stub first, verify it runs without regression, then fill in real audit logic.
> **Root cause of previous regression:** Process-mode code was deleted before the stem tile was ever activated. The stem tile code itself was never created; the cleanup plan claimed it existed.

---

## Guiding Principle

**Wire early, implement late.** Get the stem tile running in the pipeline with a minimal stub (count + CNC write, no hash chain, no full audit event) as soon as possible. This lets us verify the entire wiring path — supervisor spawn, `__stem-run`, workspace join, `fd_topo_run_tile`, stem callbacks, CNC counters — before touching any real audit logic. Once the stub runs without crashing, we incrementally replace stub behavior with full audit functionality.

This is the inverse of the previous approach: instead of "implement full → wire → crash when wired", we do "wire stub → verify no crash → implement full".

#### Step 1.2: Create `tk_audit_stem.c` — stub implementation

**File:** `src/tickoni/c_abi/shim/tk_audit_stem.c` (new)

Stub behavior:
1. On each `DURING_FRAG`: increment `audited` counter, write to CNC app[0]
2. On `BEFORE_CREDIT`: track idle ticks, publish `audited` to CNC
3. On `SHOULD_SHUTDOWN`: exit when `input_exhausted` (1000 idle ticks) or CNC HALT
4. No hash chain, no audit record building — just counting
5. `TK_AUDIT_RUN` struct with all callbacks wired

/* tk_audit_stem.c — Stub fd_stem tile for tkaudt.
   Phase 1: counting stub only (no hash chain, no audit event building).
   Goal: wire the stem tile into the pipeline, verify it runs without crashing,
         then incrementally add real audit logic.
   
   Follows the tk_metric_tile.c pattern:
   - STEM_CALLBACK_CONTEXT_TYPE = tk_audit_ctx_t
   - STEM_CALLBACK_DURING_FRAG = tk_audit_during_frag
   - STEM_CALLBACK_BEFORE_CREDIT = tk_audit_before_credit
   - STEM_CALLBACK_SHOULD_SHUTDOWN = inline macro
   - stem_run compiled as static (separate from fd_stem.c's exported stem_run)
*/

   which conflicts with our static stem_run compiled from fd_stem.c. */

#define STEM_CALLBACK_SHOULD_SHUTDOWN(ctx) \

/* ─── Context ─── */

typedef struct {
    /* Audit state (stub: just a counter) */
    uint64_t audited;           /* Total fragments processed */
    uint64_t max_latency_hops;  /* Peak pipeline depth */
    uint64_t consecutive_empty; /* Ticks with no DURING_FRAG */
    
    /* Lifecycle */
    int32_t input_exhausted;    /* Set after 1000 idle ticks */
    int32_t done;
    
    /* CNC reference */
    void *cnc;
    
    /* Scratch-allocated audit records (not yet used in stub) */
    uint64_t audit_count;
    uint64_t prev_hash;
    
    /* Tile pointer for allow_shutdown */
    fd_topo_tile_t *tile;
} tk_audit_ctx_t;

#define TKAUDT_CTX_ALIGN alignof(tk_audit_ctx_t)
#define TKAUDT_IDLE_THRESHOLD 1000
#define TKAUDT_AUDIT_CAPACITY 16384

/* ─── Scratch footprint ─── */

ulong
tk_audit_scratch_align( void ) {
    return TKAUDT_CTX_ALIGN;
}

ulong
tk_audit_scratch_footprint_tile( ulong version, uint num_tiles ) {
    if( version == 0 ) return 0;
    if( num_tiles == 0 ) return 0;
    ulong footprint = fd_alignment( TKAUDT_CTX_ALIGN, sizeof(tk_audit_ctx_t) );
    /* Reserve space for audit records array (not yet used in stub, but layout-ready) */
    footprint += fd_alignment( alignof(AuditEvent), sizeof(AuditEvent) * TKAUDT_AUDIT_CAPACITY );
    return footprint;
}

/* ─── Callbacks ─── */

static void
tk_audit_privileged_init( tk_audit_ctx_t * ctx, fd_topo_t * topo, fd_topo_tile_t * tile ) {
    (void)topo;
    (void)tile;
    /* Scratch is already zeroed by Firedancer. */
    ctx->audited = 0;
    ctx->max_latency_hops = 0;
    ctx->consecutive_empty = 0;
    ctx->input_exhausted = 0;
    ctx->done = 0;
    ctx->cnc = NULL;
    ctx->audit_count = 0;
    ctx->prev_hash = 0;
    ctx->tile = tile;
}

static void
tk_audit_unprivileged_init( tk_audit_ctx_t * ctx, fd_topo_t * topo, fd_topo_tile_t * tile ) {
    (void)topo;
    (void)tile;
    /* Find the CNC for this tile. */
    ulong cnc_addr = tk_topo_find_tile_obj( topo, (ulong)tile->id, "cnc" );
    if( cnc_addr ) {
        ctx->cnc = (void *)(ulong)cnc_addr;
    }
    FD_LOG_NOTICE(( "tkaudt: stem tile initialized, cnc=%p", ctx->cnc ));
}

static void
tk_audit_during_frag( tk_audit_ctx_t * ctx,
                      ulong            in_idx,
                      ulong            seq,
                      ulong            sig,
                      ulong            chunk,
                      ulong            sz,
                      uint             ctl ) {
    (void)in_idx; (void)seq; (void)sig; (void)ctl;
    
    /* Validate fragment size */
    if( sz != PAYMENT_MSG_SIZE ) return;
    
    /* Parse fragment */
    PaymentMessage * msg = (PaymentMessage *)(ulong)chunk;
    
    /* Update max_latency_hops (stub: no real audit event building) */
    uint64_t hops = (uint64_t)msg->pipeline_hops + 1;
    if( hops > ctx->max_latency_hops )
        ctx->max_latency_hops = hops;
    
    /* Increment counter and publish to CNC */
    ctx->audited += 1;
    ctx->consecutive_empty = 0;
    
    /* Write to CNC app[0] so supervisor's snapshot loop can observe progress.
       This is critical: if the counter stays at 0, the supervisor never
       detects completion and the tile hangs forever. */
    if( ctx->cnc ) {
        ulong * app = (ulong *)fd_cnc_app_laddr( (fd_cnc_t *)ctx->cnc );
        if( app ) {
            app[0] = ctx->audited;
        }
    }
}

static void
tk_audit_before_credit( tk_audit_ctx_t * ctx,
                        fd_stem_context_t * stem,
                        int * charge_busy ) {
    (void)stem;
    
    /* Track idle ticks */
    ctx->consecutive_empty += 1;
    if( ctx->consecutive_empty >= TKAUDT_IDLE_THRESHOLD ) {
        ctx->input_exhausted = 1;
    }
    
    *charge_busy = 0;
}

/* ─── Run entry point ─── */

void
tk_audit_run( fd_topo_t * topo, fd_topo_tile_t * tile ) {
    /* Find scratch space for this tile. */
    ulong scratch_off = fd_topo_obj_laddr( topo, tile->mcache_obj_id );
    tk_audit_ctx_t * ctx = (tk_audit_ctx_t *)scratch_off;
    
    /* Initialize scratch. */
    fd_topo_run_tile_t * run_tile = tile->run_tile;
    run_tile->privileged_init( ctx, topo, tile );
    run_tile->unprivileged_init( ctx, topo, tile );
    
    /* Enter the stem_run loop. */
    stem_run( topo, tile );
}

/* ─── fd_topo_run_tile_t ─── */

fd_topo_run_tile_t TK_AUDIT_RUN = {
    .name                     = "audit_tile",
    .keep_host_networking     = 0,
    .allow_connect            = 0,
    .allow_renameat           = 0,
    .rlimit_file_cnt          = 0,
    .rlimit_address_space     = 0,
    .rlimit_data              = 0,
    .rlimit_nproc             = 0,
    .for_tpool                = 0,
    .max_event_sz             = NULL,
    .populate_allowed_seccomp = NULL,
    .populate_allowed_fds     = NULL,
    .scratch_align            = tk_audit_scratch_align,
    .scratch_footprint        = tk_audit_scratch_footprint_tile,
    .loose_footprint          = NULL,
    .privileged_init          = (void (*)( fd_topo_t const *, fd_topo_tile_t const * ))tk_audit_privileged_init,
    .unprivileged_init        = (void (*)( fd_topo_t const *, fd_topo_tile_t const * ))tk_audit_unprivileged_init,
    .run                      = (void (*)( fd_topo_t *, fd_topo_tile_t * ))tk_audit_run,
    .rlimit_file_cnt_fn       = NULL,
};

fd_topo_run_tile_t const *
tk_get_audit_run_tile( void ) {
    return &TK_AUDIT_RUN;
}

## Risk Summary

| Risk | Severity | Mitigation |
|------|----------|------------|
| Stem tile crashes on first run | Medium | Phase 2 uses minimal stub — crash is wiring-related, easily debuggable |
| CNC counter not visible to supervisor | Medium | Counter is written in `DURING_FRAG` and `BEFORE_CREDIT` — supervisor snapshot loop should see it |
| Scratch layout mismatch | Low | `TKAUDT_AUDIT_CAPACITY` and `ctx` size computed from C struct — verified by `scratch_footprint_tile` |
| Fragment size mismatch | Low | `PAYMENT_MSG_SIZE` validated in `DURING_FRAG` — non-matching fragments are silently skipped |
| Process-mode code deleted too early | **High** | **Explicit invariant: NEVER delete process-mode code until Phase 3 passes** |
| `__stem-run` path doesn't find topology | Medium | Follow the same workspace-join pattern as `__tile-run` |
| Duplicate `stem_run` symbol | High | Separate static libraries for each stem tile (audit vs metric) — build system enforces this |
| Idle threshold too aggressive | Low | 1000 ticks is the same threshold as metric tile; can be tuned if needed |
