# Plan: Migrate tkdedu to fd_stem

> **For Hermes:** Execute this plan as a single task. tkdedu is a standard 1-in, 1-out pipeline tile — same DURING_FRAG + AFTER_CREDIT pattern as tknorm.

**Goal:** Migrate tkdedu (deduplication tile) from the `tile_process.zig` WorkFn closure pattern to Firedancer's `fd_stem` callback lifecycle.

**Architecture:** Follow Firedancer's per-tile pattern — `tk_dedupe_stem.c` defines `STEM_CALLBACK_*` macros and includes `fd_stem.c` directly. No global callback registry. Self-contained like `tk_metric_tile.c`.

## Current State (Before Migration)

**File:** `src/tickoni/tiles/payment_pipeline/dedupe.zig`

```zig
pub fn runDedupe(state: *PaymentPipelineState) void {
    defer state.q_dedu_poly.close();
    var offset: u64 = 0;
    while (state.q_norm_dedu.pop(&state.stop)) |msg_in| {
        var msg = msg_in;
        msg.pipeline_hops += 1;
        offset += 1;
        if (msg.decision != .malformed_drop and state.seenOrRemember(msg)) {
            msg.duplicate = true;
            _ = state.duplicates.fetchAdd(1, .release);
            log.kvFmt("tkdedu", "runDedupe", ...);
        }
        state.q_dedu_poly.push(msg, &state.stop) catch break;
    }
}
```

**Behavior:**
- Consumes from `q_norm_dedu` (1 input link, from tknorm)
- Checks `seenOrRemember(msg)` — idempotency key + event hash table
- Marks duplicates (`msg.duplicate = true`), increments `state.duplicates` counter
- Preserves `malformed_drop` decisions unchanged (does not re-check already-rejected messages)
- Publishes to `q_dedu_poly` (1 output link, to tkpoly)

## Task 1: Create `tk_dedupe_stem.c` — fd_stem tile shim

**File:** `src/tickoni/c_abi/shim/tk_dedupe_stem.c` (new)

**Structure:**

```c
// tk_dedupe_stem.c — fd_stem callbacks for tkdedu deduplication tile

// 1. Tile context — dedup state lives in scratch space
typedef struct {
    /* Dedup table: idempotency keys and event hashes (from PaymentPipelineState) */
    /* Copied from seen_keys and seen_hashes arrays in the original Zig state */
    uint64_t seen_keys[DEDUP_TABLE_SIZE];
    uint64_t seen_hashes[DEDUP_TABLE_SIZE];
    uint64_t seen_count;

    /* Counters */
    uint64_t duplicates;      /* Duplicate count (replaces state.duplicates.fetchAdd) */
    uint64_t processed;       /* Total events processed */
    uint64_t pipeline_hops;   /* Incremented per event */

    /* Input tracking — for idle detection (SHOULD_SHUTDOWN) */
    uint64_t consecutive_empty;  /* Ticks with no DURING_FRAG */
    int32_t  done;               /* Set when idle threshold reached or stop */

    /* Output state — set in DURING_FRAG, published in AFTER_CREDIT */
    int32_t  output_ready;       /* 1 = fragment ready to publish */
    uint8_t  output_buf[MAX_FRAGMENT_SZ];  /* Output fragment storage */
    uint32_t output_sz;          /* Output fragment size */
} tkdedu_ctx_t;

#define TKDEDU_CTX_ALIGN alignof(tkdedu_ctx_t)
#define DEDUP_TABLE_SIZE 65536   /* Same capacity as Zig state */

// 2. Stem-specific macros
#define STEM_CALLBACK_CONTEXT_TYPE    tkdedu_ctx_t
#define STEM_CALLBACK_CONTEXT_ALIGN   TKDEDU_CTX_ALIGN
#define STEM_BURST                    128
#define STEM_LAZY                     0

// 3. Callback names
#define STEM_CALLBACK_BEFORE_CREDIT  tkdedu_before_credit
#define STEM_CALLBACK_DURING_FRAG    tkdedu_during_frag
#define STEM_CALLBACK_AFTER_CREDIT   tkdedu_after_credit
#define STEM_CALLBACK_SHOULD_SHUTDOWN tkdedu_should_shutdown

// 4. BEFORE_CREDIT — track idle ticks, check for stop
static void
tkdedu_before_credit( tkdedu_ctx_t *  ctx,
                      fd_stem_t *     stem,
                      int *           charge_busy ) {
    /* Track consecutive ticks with no input.
     * After N consecutive ticks, mark as done (same as Zig loop exiting
     * when q_norm_dedu.pop() returns null). */
    ctx->consecutive_empty++;
    if (ctx->consecutive_empty >= 1000) {
        ctx->done = 1;
    }
    *charge_busy = 0;
}

// 5. DURING_FRAG — consume, dedup, prepare output
static void
tkdedu_during_frag( tkdedu_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    uint           ctl ) {
    /* 1. Read input fragment (same as q_norm_dedu.pop()) */
    /* 2. Increment pipeline_hops and processed counter */
    ctx->pipeline_hops++;
    ctx->processed++;
    ctx->consecutive_empty = 0;  /* Reset idle tracking */

    /* 3. Dedup check: if not malformed_drop and seenOrRemember -> mark duplicate */
    /*    (same logic as Zig: msg.decision != .malformed_drop
     *     and state.seenOrRemember(msg)) */
    /*    If duplicate: set msg.duplicate = true, increment duplicates counter */

    /* 4. Prepare output fragment in output_buf (same as q_dedu_poly.push()) */
    /*    Copy processed message into output_buf, set output_ready = 1, output_sz */
    ctx->output_ready = 1;
    ctx->output_sz = sz;  /* Or adjusted size if fragment was modified */
}

// 6. AFTER_CREDIT — publish to tkpoly
static void
tkdedu_after_credit( tkdedu_ctx_t *    ctx,
                     fd_stem_t *       stem,
                     fd_stem_tile_in_t * poll_in,
                     int *             charge_busy ) {
    /* If output fragment is ready from during_frag, publish now.
     * Otherwise this is just a credit-check tick. */
    if (ctx->output_ready) {
        fd_stem_publish(stem, 0, ctx->output_sz,
                        ctx->output_buf, ctx->output_sz, 0, 0, 0);
        ctx->output_ready = 0;
    }
    *charge_busy = 0;
}

// 7. SHOULD_SHUTDOWN — done or HALT
static int
tkdedu_should_shutdown( tkdedu_ctx_t * ctx ) {
    return ctx->done;
}

// 8. Include fd_stem.c — generates stem_run() with tkdedu callbacks baked in
#include "../../../../../../disco/stem/fd_stem.c"
```

## Key Implementation Notes

1. **Dedup table layout:** The `seen_keys` and `seen_hashes` arrays from `PaymentPipelineState` must be stored in `tkdedu_ctx_t` within the tile's scratch space. `stem_run()` finds the context as the first object in the tile's workspace.

2. **Fragment publishing:** Use `fd_stem_publish()` instead of `q_dedu_poly.push()`. The signature matches what Firedancer's tiles already use.

3. **Backpressure:** Stem handles backpressure via `cr_avail`. `stem_run` won't call `AFTER_CREDIT` if no credits are available from tkpoly — same effect as `q_dedu_poly.push() catch break`.

4. **Idle detection:** The Zig loop exits when `q_norm_dedu.pop()` returns null. In stem, there's no explicit "no input" signal — we track consecutive empty ticks in `BEFORE_CREDIT` and set `done` after 1000 ticks (same as the original idle threshold).

5. **Test isolation:** tkdedu's test in `dedupe.zig` tests `runDedupe(&state)` directly — this remains unchanged and will continue to pass. The stem shim is tested via integration/pipeline tests.

---

## Risks and Mitigations

1. **Fragment size mismatch:** Input/output fragment sizes may differ if dedup modifies the message layout. Mitigated by tracking `output_sz` separately from input `sz`.

2. **Idle threshold tuning:** 1000 consecutive empty ticks may be too aggressive or too slow. Mitigated by matching the threshold used in other tiles (tknorm, tkpoly).

3. **Dedup table capacity:** The `DEDUP_TABLE_SIZE` must match the Zig state's `seen_keys`/`seen_hashes` capacity. Mitigated by using a `#define` constant derived from the Zig config.

4. **Non-Linux fallback:** On macOS, tkdedu continues using the WorkFn pattern. This means two code paths until fd_stem is ported. Mitigated by keeping the per-tile loop as fallback.
