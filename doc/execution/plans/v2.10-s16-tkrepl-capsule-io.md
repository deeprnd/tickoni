# V2.10.S16: tkrepl — Replay Capsule I/O Logic

> **For Hermes:** This is the missing capsule I/O implementation for tkrepl. The current spike has `runReplay()` polling `audit_done` atomic with zero links. This plan defines the Firedancer topology I/O: reading replay capsules from input dcache and publishing divergence reports to tkings via output dcache.

**Goal:** Implement capsule loading/verification on input, and divergence reporting on output, for tkrepl fd_stem migration.

**Prerequisite:** tkings must be migrated to fd_stem first (v2.10.S14), so tkrepl can publish divergence results to tkings via the `tkrepl_tkings` output link.

---

## Architecture Decision

**Current state (spike):** tkrepl polls `audit_done` atomic from `PaymentPipelineState`, deterministically recomputes expected audit chain from synthetic inputs via `deterministicReplayDivergences()`, and sets `replay_checked`/`replay_match`/`replay_divergences` atomics. Zero links. No capsule file I/O — it generates synthetic events internally.

**Target state (Firedancer topology):**
- **1 input link** (`replay_capsule_input`) — receives replay capsule JSON from replay entrypoint (external source)
- **1 output link** (`tkrepl_tkings`) — publishes replay divergence reports to tkings
- **`AFTER_CREDIT`** (input) — receives capsule fragments
- **`DURING_FRAG`** (output) — publishes divergence reports
- **`BEFORE_CREDIT`** — polls shutdown (replay_checked/stop)
- **`SHOULD_SHUTDOWN`** — lifecycle control

**Why capsule I/O matters:**
- The spike generates synthetic events from `runtime.syntheticPayment()` — no external capsule needed
- Real replay must load a capsule from disk (JSON), verify its integrity, then replay deterministically from that capsule
- Capsule I/O enables replay from captured production events, not just synthetic test streams
- Divergence reporting to tkings enables CaseOps to display replay results

## Fragment Format

### Input: Replay Capsule Fragment

```c
/* tkrepl_capsule_fragment_t — replay capsule received via input link */
typedef struct {
    uint16_t schema_version;    /* Must match replay_capsule_schema_version */
    uint16_t ticket_id_len;     /* Length of ticket_id */
    uint64_t event_count;       /* Expected number of audit records */
    
    /* ticket_id (variable length, padded to 64 bytes) */
    char ticket_id[64];
    
    /* Hash of the full capsule JSON for integrity verification */
    uint64_t capsule_hash;
    
    /* Count of model/adapter substitutions in the capsule */
    uint32_t model_sub_count;
    uint32_t adapter_sub_count;
    
    /* Replay assertions from the capsule */
    uint8_t no_live_model_call;
    uint8_t no_live_adapter_call;
    uint8_t no_paper_fill_emitted;
    
    /* Padding to 128 bytes (typical fragment MTU) */
    uint8_t reserved[46];
} tkrepl_capsule_fragment_t;

#define TKREPL_CAPSULE_FRAG_SIZE sizeof(tkrepl_capsule_fragment_t)
```

### Output: Divergence Report Fragment

```c
/* tkrepl_divergence_fragment_t — divergence report published via output link */
typedef struct {
    uint32_t divergences;       /* Total divergence count */
    uint32_t is_match;          /* 1 = match (0 divergences), 0 = mismatch */
    uint32_t capsule_id;        /* Capsule ID that was replayed */
    uint64_t event_count;       /* Expected event count */
    uint64_t actual_count;      /* Actual audit record count */
    
    /* First divergence details (if any) */
    uint64_t first_div_seq;     /* Sequence number of first divergence */
    uint64_t first_div_expected_hash; /* Expected record hash */
    uint64_t first_div_actual_hash;   /* Actual record hash */
    char first_div_field[32];   /* Field that diverged */
    
    /* Padding to 128 bytes */
    uint8_t reserved[32];
} tkrepl_divergence_fragment_t;

#define TKREPL_DIV_FRAG_SIZE sizeof(tkrepl_divergence_fragment_t)
```

## tkrepl Context

```c
typedef struct {
    /* Capsule state */
    int32_t capsule_loaded;     /* 0 = not loaded, 1 = loaded and verified */
    tkrepl_capsule_fragment_t current_capsule;
    uint64_t capsule_hash;      /* Computed hash of loaded capsule */
    
    /* Replay state */
    int32_t replay_checked;     /* Set when replay completes */
    int32_t replay_match;       /* 1 = match, 0 = mismatch */
    uint32_t replay_divergences;
    uint32_t divergence_count;
    
    /* Output state */
    tkrepl_divergence_fragment_t divergence_report;
    
    /* Shutdown */
    int32_t done;               /* Set when replay_checked or stop */
} tkrepl_ctx_t;

#define TKREPL_CTX_ALIGN alignof(tkrepl_ctx_t)
```

## tkrepl Input: DURING_FRAG (Capsule Receive)

```c
static void
tkrepl_during_frag( tkrepl_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    uint           ctl ) {
    /* 1. Validate fragment size */
    if (sz != TKREPL_CAPSULE_FRAG_SIZE) return;
    
    /* 2. Copy capsule fragment */
    tkrepl_capsule_fragment_t * frag = (tkrepl_capsule_fragment_t *)chunk;
    ctx->current_capsule = *frag;
    
    /* 3. Verify schema version */
    if (frag->schema_version != REPL_CAPSULE_SCHEMA_VERSION) {
        /* Record divergence, set replay_match = 0 */
        ctx->replay_match = 0;
        return;
    }
    
    /* 4. Verify capsule hash (integrity check) */
    /* TODO: Wire to actual capsule JSON hash computed at load time */
    
    /* 5. Mark capsule as loaded */
    ctx->capsule_loaded = 1;
    
    /* 6. Init divergence tracking */
    ctx->replay_divergences = 0;
    ctx->divergence_count = 0;
    ctx->replay_checked = 0;
}
```

## tkrepl Output: AFTER_CREDIT (Divergence Publish)

After the deterministic replay completes (same logic as `deterministicReplayDivergences()` in the spike), publish the divergence report:

```c
static void
tkrepl_after_credit( tkrepl_ctx_t *    ctx,
                     fd_stem_t *       stem,
                     fd_stem_tile_in_t * poll_in,
                     int *             charge_busy ) {
    /* 1. Check if replay is complete (replay_checked from shared state or local flag) */
    if (!ctx->replay_checked) {
        *charge_busy = 0;
        return;
    }
    
    /* 2. Build divergence report */
    ctx->divergence_report.divergences = ctx->replay_divergences;
    ctx->divergence_report.is_match = ctx->replay_match;
    ctx->divergence_report.event_count = ctx->current_capsule.event_count;
    ctx->divergence_report.actual_count = ctx->actual_audit_count;
    
    /* 3. Publish to tkings via output link */
    fd_stem_publish(
        stem,
        TKREPL_TKINGS_OUTPUT_IDX,  /* Output link index */
        TKREPL_DIV_FRAG_SIZE,      /* Fragment size */
        divergence_chunk,          /* Chunk pointer (shared memory) */
        TKREPL_DIV_FRAG_SIZE,      /* Data size */
        0, 0, 0
    );
    
    *charge_busy = 0;
}
```

---

## tkrepl BEFORE_CREDIT (Shutdown Polling)

```c
static void
tkrepl_before_credit( tkrepl_ctx_t * ctx,
                      fd_stem_t *    stem,
                      int *          charge_busy ) {
    /* Check replay_checked and stop from shared state.
     * These are the same atomics the spike reads. */
    
    if (ctx->replay_checked || ctx->stop) {
        ctx->done = 1;
    }
    
    *charge_busy = 0;
}
```

---

## tkrepl SHOULD_SHUTDOWN

```c
static int
tkrepl_should_shutdown( tkrepl_ctx_t * ctx ) {
    return ctx->done;
}
```

## Post-I/O: Full Replay Integration (Future)

After capsule I/O is working, tkrepl can be extended with:
1. **Capsule re-injection** — feed replay capsule events back into tkings (the `tkrepl_tkings` link can also carry replayed events, not just divergence reports)
2. **Model/adapter substitution** — use capsule's `model_substitutions` and `adapter_substitutions` to replace external calls during replay
3. **CaseOps integration** — push divergence reports to the CaseOps UI via WebSocket
4. **Audit JSONL export** — write replay audit trail to JSONL file

These are out of scope for this plan. The capsule I/O implementation only covers fragment receive (input) and divergence report publish (output).

---

## Key Design Decisions

1. **Fragment size: 128 bytes.** Fits within typical dcache MTU, carries enough capsule/replay data for meaningful I/O.
2. **Capsule load on DURING_FRAG.** Capsule arrives as a fragment from the replay entrypoint; tkrepl validates and stores it.
3. **Divergence report on AFTER_CREDIT.** Published after replay completes, so tkings receives results at the right time.
4. **Shutdown via replay_checked/stop.** Same trigger as the spike, preserving the pipeline lifecycle.
5. **Output to tkings only.** Divergence reports go to tkings for CaseOps; no fan-out to multiple consumers.
6. **Deterministic replay logic unchanged.** The spike's `deterministicReplayDivergences()` is reused as-is; only I/O wiring changes.

## Summary

| Tile | Before (I/O) | After (I/O) | Callbacks Added |
|------|--------------|-------------|----------------|
| `tkrepl` | 0-in, 0-out (shared memory polling) | 1-in (capsule), 1-out (divergence) | DURING_FRAG (receive), AFTER_CREDIT (publish), BEFORE_CREDIT (shutdown) |
| `tkings` | 1-in (from tknorm) | 2-in (+ from tkrepl) | Receive divergence reports |

This plan is scoped to capsule I/O only. The deterministic replay logic (deterministicReplayDivergences) is unchanged from the spike — only the I/O layer is implemented. Full replay integration (capsule re-injection, model/adapter substitution) is future work.
