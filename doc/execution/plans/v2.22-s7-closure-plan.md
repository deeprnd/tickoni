#### 1.3 Create `doc/execution/retail-runtime-support.md`
This is the primary deliverable for T4/T5/T8/T9. Must document for Windows:

- **Supported binaries and runtime tier**: `windows_retail` tier, what tiles are available/stubbed
- **Install paths**: `%LOCALAPPDATA%\tickoni\`, `~\.tickoni\` for config/evidence
- **Storage locations**: evidence dir, config dir, log dir — all user-scoped, no sudo
- **Manual verification**: SHA256 checksums, build reproducibility from same commit
- **Update/uninstall behavior**: user-scoped, no admin rights, evidence preserved by default, full reset opt-in
- **Unsupported features**: no seccomp/sandbox, no shared-memory topology, no AF_PACKET, no sandbox adapter substitute, no full tile runtime, no replay proof on retail tier
- **Demo commands**: `tickoni doctor`, `tickoni demo investment --manifest <path>`
- **Privacy defaults**: telemetry disabled by default, no opt-in diagnostics yet
- **Execution defaults**: paper/sandbox/mock/sandbox-substitute default, live execution disabled
- **Package inclusion rules**: only Tickoni-owned code and reused Firedancer substrate
