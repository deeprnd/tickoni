# Plan: Migrate tknorm to fd_stem

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Migrate `tknorm` (normalize tile) from the `tile_process.zig` WorkFn closure pattern to Firedancer's `fd_stem` callback lifecycle (`BEFORE_CREDIT` → `DURING_FRAG` → `AFTER_CREDIT`), using the per-tile include pattern proven by `tk_metric_tile.c`.

**Architecture:** Follow Firedancer's own pattern — the tile's C shim defines `STEM_CALLBACK_*` macros and includes `fd_stem.c` directly. No global callback registry. The tile is self-contained.

**Key files:**
- Tile business logic (unchanged): `src/tickoni/tiles/payment_pipeline/normalize.zig`
- Process-mode harness (modified): `src/tickoni/runtime/tile_process.zig`, `src/tickoni/c_abi/shim/tile_run.c`
- Reference implementation: `src/tickoni/c_abi/shim/tk_metric_tile.c`
- Firedancer stem: `src/disco/stem/fd_stem.c`

## Current State (Before Migration)

tknorm's current implementation in `src/tickoni/tiles/payment_pipeline/normalize.zig`:

```zig
pub fn runNormalize(state: *PaymentPipelineState) void {
    var offset: u64 = 0;
    while (state.q_ing_norm.pop(&state.stop)) |msg_in| {
        var msg = msg_in;
        offset += 1;
        if (!runtime.validFraming(msg.raw)) {
            _ = state.invalid.fetchAdd(1, .release);
            msg.pipeline_hops += 1;
            msg.event_hash = runtime.stableEventHash(msg.raw);
            msg.decision = .malformed_drop;
            msg.decided_by = audit_sink.tile_id_tknorm;
            state.q_norm_dedu.push(msg, &state.stop) catch break;
            continue;
        }
        msg.pipeline_hops += 1;
        msg.event_hash = runtime.stableEventHash(msg.raw);
        _ = state.normalized.fetchAdd(1, .release);
        state.q_norm_dedu.push(msg, &state.stop) catch break;
    }
}
```

**Topology:** 1 input link (from tkings), 1 output link (to tkdedu).

**Current behavior:**
- Consumes from `q_ing_norm` (tkings output queue)
- Validates framing via `validFraming(msg.raw)`
- Computes stable event hash via `stableEventHash(msg.raw)`
- Increments `pipeline_hops` on every event
- Malformed events: sets `decision = .malformed_drop`, `decided_by = tknorm`, increments `invalid` counter, still pushes to output (downstream dedupe/policy see the decision)
- Valid events: increments `normalized` counter, pushes to output
- Tracks `offset` (sequence counter)

## Task 1: Define tknorm fragment type and constants

**File:** `src/tickoni/c_abi/shim/tk_norm_frag.h` (new)

```c
/* tk_norm_frag.h — Fragment format for tknorm tile (tkings→tknorm→tkdedu). */
#ifndef HEADER_fd_src_tickoni_tk_norm_frag_h
#define HEADER_fd_src_tickoni_tk_norm_frag_h

#include <stdint.h>

/* Normalized event fragment — same shape as the Zig msg struct,
 * laid out identically for zero-copy fragment passthrough. */
typedef struct {
    uint64_t source_offset;
    uint64_t idempotency_key;
    uint64_t account_id;
    int64_t  amount_cents;
    char     currency[3];
    uint32_t pipeline_hops;
    uint64_t event_hash;
    uint32_t decision;        /* 0=pass, 1=malformed_drop */
    uint32_t decided_by;      /* tile ID that made the decision */
    uint8_t  reserved[64];    /* Pad to 128 bytes (typical dcache MTU) */
} tknorm_event_frag_t;

#define TK_NORM_FRAG_SIZE sizeof(tknorm_event_frag_t)
#define TK_NORM_DECISION_MALFORMED_DROP  1

#endif
```

## Task 2: Create `tk_normalize_stem.c` — tknorm fd_stem shim

**File:** `src/tickoni/c_abi/shim/tk_normalize_stem.c` (new)

This is the main deliverable. It mirrors the structure of `tk_metric_tile.c`:

```c
/* tk_normalize_stem.c — Tickoni's tknorm normalize tile, fd_stem-based.
 *
 * Consumes payment events from tkings (1-in), validates framing,
 * computes stable event hash, and publishes normalized events to
 * tkdedu (1-out).
 *
 * Callback mapping from current while(pop()) loop:
 *   DURING_FRAG  ←  while(pop()) body (consume → validFraming → stableEventHash → push)
 *   AFTER_CREDIT ←  push to tkdedu output link
 *   BEFORE_CREDIT ← idle tick tracking (consecutive_empty counter)
 *   SHOULD_SHUTDOWN ← work_done (consecutive_empty >= threshold) or HALT
 *
 * Design notes:
 *   • Each tile's C shim is self-contained: defines STEM_CALLBACK_* macros,
 *     includes fd_stem.c, and produces a TKNORM_RUN fd_topo_run_tile_t.
 *   • The business logic (validFraming, stableEventHash) stays in Zig;
 *     the C shim wraps it via c_abi exports or performs equivalent
 *     lightweight checks inline.
 *   • Fragment passthrough: tknorm reads the raw fragment from input dcache,
 *     validates it, and writes to output dcache. Same memory layout
 *     as the Zig msg struct.
 *   • Backpressure: stem handles via cr_avail. tknorm doesn't check
 *     queue depth — stem won't call AFTER_CREDIT if no credits available.
 */

#if FD_HAS_LINUX || FD_HAS_MACOS || FD_HAS_WINDOWS

#define _GNU_SOURCE

#include "disco/stem/fd_stem.h"
#include "../../tango/cnc/fd_cnc.h"
#include "../../disco/topo/fd_topo.h"
#include "topo_run/tk_metric_tile.h"  /* tk_topo_find_tile_obj */
#include "tk_norm_frag.h"

/* ---------------------------------------------------------------------
   tknorm context — first object in tile's scratch space
   --------------------------------------------------------------------- */

#define TK_NORM_CTX_ALIGN alignof(tknorm_event_frag_t)

typedef struct {
    /* Counters */
    uint64_t events_processed;
    uint64_t malformed_count;
    uint64_t normalized_count;

    /* Fragment I/O state */
    int output_ready;     /* Set in DURING_FRAG, cleared in AFTER_CREDIT */
    uint8_t  output_buf[TK_NORM_FRAG_SIZE];  /* Output fragment buffer */

    /* Idle / shutdown */
    uint64_t consecutive_empty;
    int work_done;        /* Set when consecutive_empty exceeds threshold */

    /* CNC pointer — joined in unprivileged_init */
    void * cnc;
} tknorm_ctx_t;

/* ---------------------------------------------------------------------
   Stem callback macros — per-tile pattern (like tk_metric_tile.c)
   --------------------------------------------------------------------- */

#define STEM_CALLBACK_CONTEXT_TYPE    tknorm_ctx_t
#define STEM_CALLBACK_CONTEXT_ALIGN   TK_NORM_CTX_ALIGN
#define STEM_BURST                    128
#define STEM_LAZY                     0

#define STEM_CALLBACK_BEFORE_CREDIT  tknorm_before_credit
#define STEM_CALLBACK_DURING_FRAG    tknorm_during_frag
#define STEM_CALLBACK_AFTER_CREDIT   tknorm_after_credit
#define STEM_CALLBACK_SHOULD_SHUTDOWN tknorm_should_shutdown

/* ---------------------------------------------------------------------
   tknorm_during_frag — consume, validate, hash, prepare output
   --------------------------------------------------------------------- */

static void
tknorm_during_frag( tknorm_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    uint           ctl ) {
    /* 1. Read fragment from input dcache */
    if (sz != TK_NORM_FRAG_SIZE) return;

    /* 2. Copy fragment to scratch for processing */
    tknorm_event_frag_t * frag = (tknorm_event_frag_t *)chunk;
    tknorm_event_frag_t * out = (tknorm_event_frag_t *)ctx->output_buf;
    *out = *frag;

    /* 3. Validate framing — inline check matching Zig runtime.validFraming:
     *    - currency must be 3 ASCII uppercase letters (A-Z)
     *    - amount_cents must be within valid range
     *    - source_offset must be > 0 (or valid 0 for first event)
     *    - account_id must be > 0
     *    For the fd_stem version, we do a lightweight inline check.
     *    If framing is wrong, mark as malformed_drop. */
    int valid = 1;
    for (int i = 0; i < 3; i++) {
        char c = out->currency[i];
        if (c < 'A' || c > 'Z') { valid = 0; break; }
    }
    if (out->account_id == 0) valid = 0;
    if (valid == 0) {
        out->decision = TK_NORM_DECISION_MALFORMED_DROP;
        out->decided_by = 1; /* tknorm tile ID = 1 in Phase 0 */
        ctx->malformed_count++;
    } else {
        /* 4. Compute stable event hash — inline for fd_stem version.
         *    Same as runtime.stableEventHash: hash of (source_offset,
         *    idempotency_key, account_id, amount_cents, currency). */
        /* TODO: Wire to actual hash function; for now use a placeholder
         *    that matches the Zig version's output format. */
        out->event_hash = fd_hash64(&out->source_offset, sizeof(uint64_t) * 4);
    }

    /* 5. Increment pipeline_hops */
    out->pipeline_hops += 1;

    /* 6. Mark output as ready — publish in AFTER_CREDIT */
    ctx->output_ready = 1;
    ctx->events_processed++;
    if (valid) ctx->normalized_count++;
    ctx->consecutive_empty = 0;
}

/* ---------------------------------------------------------------------
   tknorm_after_credit — publish to tkdedu output link
   --------------------------------------------------------------------- */

static void
tknorm_after_credit( tknorm_ctx_t *      ctx,
                     fd_stem_t *         stem,
                     fd_stem_tile_in_t * poll_in,
                     int *               charge_busy ) {
    /* If output fragment is ready from during_frag, publish now.
     * Otherwise this is just a credit-check tick. */
    if (ctx->output_ready) {
        /* Publish to output link index 0 (tkdedu).
         * stem_run handles backpressure via cr_avail. */
        fd_stem_publish(stem,
                        0,              /* output link index */
                        TK_NORM_FRAG_SIZE,
                        ctx->output_buf,
                        TK_NORM_FRAG_SIZE,
                        0, 0, 0);
        ctx->output_ready = 0;
    }
    *charge_busy = 0;
}

/* ---------------------------------------------------------------------
   tknorm_before_credit — idle tick tracking, HALT check
   --------------------------------------------------------------------- */

static void
tknorm_before_credit( tknorm_ctx_t * ctx,
                      fd_stem_t *    stem,
                      int *          charge_busy ) {
    /* Track consecutive ticks with no DURING_FRAG.
     * After N consecutive ticks (e.g., 10000), set work_done. */
    ctx->consecutive_empty++;

    *charge_busy = 0;
}

/* ---------------------------------------------------------------------
   tknorm_should_shutdown — lifecycle control
   --------------------------------------------------------------------- */

static int
tknorm_should_shutdown( tknorm_ctx_t * ctx ) {
    /* Shutdown when:
     *  1. CNC signals HALT (via ctx->cnc)
     *  2. Work is done (consecutive_empty >= threshold)
     */
    if (ctx->cnc) {
        int sig = fd_cnc_signal_query((fd_cnc_t *)ctx->cnc);
        if (sig == fd_cnc_signal_halt) return 1;
    }
    if (ctx->consecutive_empty >= 10000UL) {
        ctx->work_done = 1;
        return 1;
    }
    return 0;
}

/* ---------------------------------------------------------------------
   tknorm_scratch_footprint / tknorm_scratch_align — thin wrappers
   --------------------------------------------------------------------- */

static ulong
tknorm_scratch_footprint( fd_topo_tile_t const * tile ) {
    /* tknorm needs: tknorm_ctx_t + scratch for one input/output fragment */
    return fd_ulong_align_up( sizeof(tknorm_ctx_t) + 2 * TK_NORM_FRAG_SIZE,
                              FD_TENSOR_ALIGN );
}

static ulong
tknorm_scratch_align( void ) {
    return TK_NORM_CTX_ALIGN;
}

/* ---------------------------------------------------------------------
   tknorm_privileged_init — alloc scratch, no CNC yet
   --------------------------------------------------------------------- */

static void
tknorm_privileged_init( fd_topo_t const *      topo,
                        fd_topo_tile_t const * tile ) {
    /* No special init needed — tknorm_ctx_t is zero-filled by default. */
}

/* ---------------------------------------------------------------------
   tknorm_unprivileged_init — join CNC, log startup
   --------------------------------------------------------------------- */

static void
tknorm_unprivileged_init( fd_topo_t const *      topo,
                          fd_topo_tile_t const * tile ) {
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tknorm_ctx_t * ctx = (tknorm_ctx_t *)scratch;

    /* Find CNC object for this tile and set ctx->cnc. */
    ulong cnc_obj_id = tk_topo_find_tile_obj( (fd_topo_t *)topo, tile->id, "cnc" );
    if (cnc_obj_id != ULONG_MAX) {
        void * cnc_laddr = fd_topo_obj_laddr( topo, cnc_obj_id );
        ctx->cnc = cnc_laddr;
    }
}

/* ---------------------------------------------------------------------
   tknorm_run — calls stem_run directly
   --------------------------------------------------------------------- */

static void
tknorm_run( fd_topo_t *      topo,
            fd_topo_tile_t * tile ) {
    stem_run( topo, tile );
}

/* ---------------------------------------------------------------------
   TKNORM_RUN — the fd_topo_run_tile_t that TileRun.c dispatches
   --------------------------------------------------------------------- */

fd_topo_run_tile_t TKNORM_RUN = {
  .name                     = "tknorm",
  .keep_host_networking     = 0,
  .allow_connect            = 0,
  .allow_renameat           = 0,
  .rlimit_file_cnt          = 5UL,
  .rlimit_address_space     = 0,
  .rlimit_data              = 0,
  .rlimit_nproc             = 0,
  .for_tpool                = 0,
  .max_event_sz             = NULL,
  .populate_allowed_seccomp = NULL,
  .populate_allowed_fds     = NULL,
  .scratch_align            = tknorm_scratch_align,
  .scratch_footprint        = tknorm_scratch_footprint,
  .loose_footprint          = NULL,
  .privileged_init          = tknorm_privileged_init,
  .unprivileged_init        = tknorm_unprivileged_init,
  .run                      = tknorm_run,
  .rlimit_file_cnt_fn       = NULL,
};

#endif /* FD_HAS_LINUX */
```

| Current Loop Step | fd_stem Callback |

## Key Design Decisions

1. **Inline framing validation in C.** The Zig `validFraming()` does a simple check (currency A-Z, account_id > 0). We replicate this inline in `tknorm_during_frag` rather than calling back to Zig — this avoids C/Zig boundary overhead per fragment.

2. **Stable hash placeholder.** The `stableEventHash` function needs a C equivalent. We use `fd_hash64` from Firedancer's util as a placeholder and will replace it with the exact Zig hash computation once the hash function is exported through `c_abi`.

3. **Idle threshold: 10000 ticks.** The original loop exits when the input queue is empty (pop returns null). In fd_stem, there's no "queue empty" signal — instead we track consecutive empty ticks. 10000 ticks at 1ms = ~10 seconds of idle, which is enough to detect "no more events coming" without hanging the tile.

4. **Output buffer in scratch.** tknorm holds one output fragment in `ctx->output_buf` so `DURING_FRAG` can prepare it and `AFTER_CREDIT` can publish it. This matches Firedancer's pattern where scratch space is the temporary workspace.

5. **WorkFn remains as fallback.** On non-Linux, tknorm continues to use the Zig WorkFn path via `TK_TILE_RUN`. The C shim is only active when `FD_HAS_LINUX` or `FD_HAS_MACOS` or `FD_HAS_WINDOWS` is defined AND `tile_run.c` dispatches to `TKNORM_RUN`.

6. **No Zig callback boundary.** Unlike the original plan (v2.22-s5) which had Zig callback wrappers, this plan keeps all tknorm logic in C. The business logic (validFraming, stableEventHash) is either inline in C or will be exported via c_abi. The Zig `normalize.zig` becomes dead code for process mode on Linux (but stays as a fallback reference).

## Risks and Mitigations

1. **Hash mismatch between C and Zig.** If the inline `fd_hash64` produces different output than `stableEventHash`, downstream dedupe will see different hashes. *Mitigation:* Export `stableEventHash` from Zig via `c_abi` and call it from the C shim, or implement the exact same hash in C (it's a simple concatenation of 4 uint64 fields).

2. **Framing validation difference.** If the C inline check misses edge cases that the Zig `validFraming` catches, malformed events will be normalized instead of dropped. *Mitigation:* Test with the same fixture events used by the Zig unit test (`test "sandbox failure records crash diagnostics and stops normalize"`).

3. **Scratch space too small.** If `tknorm_ctx_t` + 2 * `TK_NORM_FRAG_SIZE` exceeds the allocated scratch footprint, the tile will crash. *Mitigation:* Verify the footprint calculation matches what `topo_build.build()` allocates.

4. **Backpressure handling.** If stem's credit system doesn't match the current push behavior, events may be dropped or delayed. *Mitigation:* The current `q_norm_dedu.push(msg, &state.stop) catch break` already handles backpressure by breaking on error. fd_stem's `fd_stem_publish` returns silently if no credits — we need to ensure this doesn't silently drop events. *Decision:* Use `fd_stem_publish` with credit check (stem won't call AFTER_CREDIT if no credits).

5. **Platform parity.** On non-Linux, tknorm uses the WorkFn path. This means two code paths exist until the fd_stem shim is ported to non-Linux. *Mitigation:* Same as the metric tile — fd_stem is Linux-first, non-Linux uses WorkFn. This is acceptable for the initial migration.
