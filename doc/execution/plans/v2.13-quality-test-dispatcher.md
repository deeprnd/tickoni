# Plan: Align quality, security, and remaining test lanes to dispatcher pattern

## Problem

Only `test-unit` and `test-integration` follow the dispatcher pattern:
- Bare command → bash `case` on `{{ os }}-{{ arch }}` → platform-specific impl
- Badge update in `-all` aggregator via `run-badged-command.py`
- Platform aliases: `-linux-x86`, `-linux-arm`, `-macos-x86`, `-macos-arm`, `-windows-x86`, `-windows-arm`

Six other lanes break this pattern:

| Lane | Issue |
|------|-------|
| `test-system` | No dispatcher; aliases point TO bare recipe (reversed direction) |
| `test-coverage` | Badge update embedded in lane recipe; no dispatcher |
| `test-e2e` | No dispatcher; bare recipe is `@true` |
| `test-perf` | Badge in lane, verbose `{{ justfile_dir }}/` path, no dispatcher |
| `quality-yaml` | Bare alias (one-liner) instead of dispatcher |
| `quality-spell` | Bare alias (one-liner) instead of dispatcher |
| `security-sanitize` | Aliases point TO bare recipe (reversed); no dispatcher |
| `security-seccomp` | Aliases point TO bare recipe (reversed); no dispatcher |
| `security-proof` | Aliases point TO bare recipe (reversed); no dispatcher |
| `security-gitleaks` | Aliases point TO bare recipe (reversed); no dispatcher |
| `security-engine` | No dispatcher; no `-all` aggregator; no badge |

## Target Pattern

Every lane follows this structure:

```
# 1. Bare dispatcher with case statement
{lane}:
    #!/usr/bin/env bash
    set -euo pipefail
    case "{{ os }}-{{ arch }}" in
    linux-x86) exec just {lane}-linux-x86 ;;
    linux-arm) exec just {lane}-linux-arm ;;
    macos-x86) exec just {lane}-macos-x86 ;;
    macos-arm) exec just {lane}-macos-arm ;;
    windows-x86) exec just {lane}-windows-x86 ;;
    windows-arm) exec just {lane}-windows-arm ;;
    *) echo "unsupported host platform for {lane}: {{ os }}-{{ arch }}" >&2; exit 1 ;;
    esac

# 2. Canonical implementation (linux-x86)
{lane}-linux-x86:
    <actual command>

# 3. Platform aliases — reuse linux-x86 if no platform-specific impl exists
{lane}-linux-arm: {lane}-linux-x86
{lane}-macos-x86: {lane}-linux-x86
{lane}-macos-arm: {lane}-linux-x86
{lane}-windows-x86: {lane}-linux-x86
{lane}-windows-arm: {lane}-linux-x86

# 4. Badge update in -all aggregator only
{lane}-all:
    {{ python }} contrib/tool/readme/run-badged-command.py {badge} bash -c "just {lane}"
```
