## V2.10.S1 — Platform detection script and script cleanup

### Scope

Create `contrib/platform.sh` as the single cross-platform OS/arch detection source and eliminate all scattered detection code.

### Detection model for `platform.sh`

```
platform.sh os         → linux | macos | windows
platform.sh arch       → x86 | arm  (NOT x86_64/aarch64 — normalised)
platform.sh platform   → linux-x86 | linux-arm | macos-x86 | macos-arm | windows-x86 | windows-arm
```

- `tk_os()` / `tk_arch()` / `tk_platform()` as internal shell functions (namespaced `tk_` prefix).
- Sourceable: `source contrib/platform.sh` sets `TK_OS`, `TK_ARCH`, `TK_PLATFORM` global variables AND prints them.
- `platform.sh os` / `platform.sh arch` / `platform.sh platform` / `platform.sh` (all 3) work as standalone invocations.

### Windows arch detection (the hard part)

`detect-windows-arch.sh` has 5 fallback layers:
1. `$TK_WINDOWS_HOST_ARCH` (explicit override)
2. Powershell: `(Get-ComputerInfo).OsArchitecture`, `(Get-CimInstance Win32_Processor ...).Architecture`, `reg query`
3. `pwsh` fallback
4. `cmd` fallback
5. `$MSYSTEM_CARCH`, `$PROCESSOR_ARCHITEW6432`, `$PROCESSOR_ARCHITECTURE`, `$PROCESSOR_IDENTIFIER`
6. `uname -m`

This must all live inside `tk_arch()` and be hidden behind `platform.sh`. The shell-only approach (no powershell dependency in the sourceable snippet) is:

```bash
tk_arch() {
    local candidate
    for candidate in \
        "${TK_WINDOWS_HOST_ARCH:-}" \
        "${MSYSTEM_CARCH:-}" \
        "${PROCESSOR_ARCHITEW6432:-}" \
        "${PROCESSOR_ARCHITECTURE:-}" \
        "${PROCESSOR_IDENTIFIER:-}" \
        "$(uname -m 2>/dev/null || true)"
    do
        case "${candidate,,}" in
            arm64|aarch64|arm64-bit*|arm\ 64-bit*|*arm64*|12) echo arm; return 0 ;;
            x86_64|amd64|x64|x86-64*|*amd64*|*x64*|9) echo x86; return 0 ;;
        esac
    done
    echo "unknown"
}
```

On Windows under MSYS, `PROCESSOR_ARCHITECTURE` = "AMD64" and `PROCESSOR_ARCHITEW6432` = "AMD64" for x86, "ARM64" for ARM. `uname -m` on MSYS returns `x86_64` or `aarch64`. The case above covers all permutations.

### Steps

1. **Create `contrib/platform.sh`** (~60 lines)
   - `tk_os()`: maps `uname -s` → linux/macos/windows, also checks `MSYSTEM`, `PROCESSOR_ARCHITECTURE` on Windows
   - `tk_arch()`: the normalisation logic from `detect-windows-arch.sh` above, plus Powershell fallback if MSYSTEM/CMD available
   - `tk_platform()`: concatenates `$(tk_os)-$(tk_arch)`
   - Standalone invocation: if `$0` is `platform.sh`, reads arg from `$1` and prints result
   - Sourceable: sets `TK_OS`, `TK_ARCH`, `TK_PLATFORM` globals
