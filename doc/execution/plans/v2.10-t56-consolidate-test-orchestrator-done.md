# Consolidate test orchestrator and remove dead code

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Remove the bash wrapper `run_system_test.sh`, delete the dead `zig-build` subcommand, and add a unified `system-test` command to `orchestrator.py` that handles the full lifecycle.

**Architecture:** Orchestrator.py becomes the single Python entrypoint. It keeps three subcommands: `llm-server-start`, `llm-server-stop`, and `system-test` (which runs start → zig-test → stop). The justfile routes directly to orchestrator.py, eliminating bash entirely.

**Tech Stack:** Python 3, justfile, bash (only for the shell used by just)

---

## Task 1: Add `system-test` subcommand to orchestrator.py

**Objective:** Implement the full lifecycle (start server → zig-test → stop server) as a single orchestrator.py command.

**Files:**
- Modify: `contrib/test/orchestrator.py`

**Step 1: Add the `system_test` method to the Orchestrator class**

Add after the `dynamic_test_opts` method (around line 65):

```python
    def system_test(self):
        """Run the full system-test lifecycle: start server, run tests, stop server."""
        print("=== Phase 1: Start llama.cpp server ===")
        rc = self.llm_server_start()
        if rc != 0:
            print("Server failed to start, aborting", file=sys.stderr)
            return rc

        print("\n=== Phase 2: Run zig-test ===")
        rc = self.zig_test("system-test")
        if rc != 0:
            print("zig-test failed, proceeding to cleanup", file=sys.stderr)

        print("\n=== Phase 3: Stop llama.cpp server ===")
        self.llm_server_stop()

        return rc
```

**Step 2: Add the argparse subparser for `system-test`**

Add after the `dynamic-test-opts` parser (around line 86):

```python
    # system-test
    sub.add_parser("system-test", help="Full system-test lifecycle: start → zig-test → stop")
```

And in the command dispatch (around line 100):

```python
    elif args.command == "system-test":
        sys.exit(orch.system_test())
```

**Step 3: Update the docstring**

Update the module docstring to reflect the new unified command. Replace:

```
Usage:

    python3 orchestrator.py llm-server-stop           # kill server by PID
```

With:
