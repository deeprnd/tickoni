# Plan: Migrate tkings to fd_stem

> **For Hermes:** Execute tasks sequentially. Each step is self-contained. The build compiles after every step, but the full pipeline will hang (or the remaining tiles will starve) until tkings is migrated and produces events through the stem-based link.

**Goal:** Replace tkings's custom polling loop with Firedancer's `fd_stem` callback lifecycle (`BEFORE_CREDIT` → `AFTER_CREDIT`), following the per-tile pattern proven by `tk_metric_tile.c`. tkings generates synthetic payment events and publishes them to tknorm via the output dcache link.

**Prerequisite:** None. tkings is a standalone producer tile — it has no input links, no fan-in, and does not depend on other tiles' stem migration. It is the first tile in the pipeline (index 0) and the only tile that generates events from scratch.

**Key files:**
- Tile business logic (unchanged): `src/tickoni/tiles/payment_pipeline/ingest.zig`
- Process-mode harness (modified): `src/tickoni/runtime/tile_process.zig`, `src/tickoni/c_abi/shim/tile_run.c`
- Tile registry (modified): `src/app/tickoni/tile_registry.zig`
- Reference implementation: `src/tickoni/c_abi/shim/tk_metric_tile.c`
- Firedancer stem: `src/disco/stem/fd_stem.c`

---

## Architecture Decision

**Current state (thread-mode spike):** tkings uses a `while` loop in `runIngest()` that calls `syntheticPayment()` to generate events and `q_ing_norm.push()` to push them into a shared queue. A sandbox_fail_at test hook simulates crash behavior.

**Current state (process-mode):** `runIngestProcess()` in `process.zig` uses `rt.link.Producer.publish()` to push events into Tango shared-memory. It loops `event_count` times, checks `halted(cnc)` each iteration, and writes a `produced` counter.

**Target state (fd_stem):** tkings becomes a producer-only tile in the Firedancer topology — `BEFORE_CREDIT` checks HALT/heartbeat, `AFTER_CREDIT` generates the next event and publishes it via `fd_stem_publish()`, `SHOULD_SHUTDOWN` returns non-zero when `event_count` is reached or HALT is received. No input links. The stem's credit system drives the loop.

**Why tkings is the hardest stem pattern:** Producer-only tiles have no input to naturally drive the stem's polling loop. Firedancer's `stem_run` is designed around consumers that react to incoming fragments. A producer must work against the callback flow — `AFTER_CREDIT` fires when there is credit available on the output link (i.e., tknorm's mcache has room), and the tile must generate and publish within that callback.

## Task 1: Create `tk_ingest_stem.c` — tkings stem shim

**File:** `src/tickoni/c_abi/shim/tk_ingest_stem.c` (new)

**Objective:** A self-contained C file that follows the Firedancer per-tile pattern — define STEM macros, implement callbacks, include `fd_stem.c` directly, export `stem_run`.

**Context structure:**

```c
/* tkings_ctx_t — tkings stem tile context.
 * Allocated from scratch space by privileged_init/unprivileged_init.
 * This is the first object from scratch, found by stem_run via
 * fd_topo_obj_laddr(topo, tile->tile_obj_id). */
typedef struct {
    /* Event generation state */
    uint64_t event_counter;     /* Current offset (0..event_count-1) */
    uint64_t event_count;       /* Total events to generate */
    uint64_t produced;          /* Events successfully published */
    
    /* Test hooks */
    uint64_t sandbox_fail_at;   /* Generate crash at this offset */
    
    /* Lifecycle */
    int stop_flag;              /* Set by BEFORE_CREDIT when HALT arrives */
    int done;                   /* Set when event_count reached or HALT */
    
    /* CNC for HALT detection (set in unprivileged_init) */
    void *cnc;
    
    /* Output link state */
    uint64_t output_seq;        /* Next sequence number for fd_stem_publish */
    
    /* Reserved for future fields / padding to alignment */
    uint8_t reserved[256];
} tkings_ctx_t;

#define TKINGS_CTX_ALIGN alignof(tkings_ctx_t)
```

**BEFORE_CREDIT (HALT check + heartbeat):**

```c
/* tkings_before_credit — every stem_run iteration.
 * Checks HALT signal, sets stop_flag. No fragment processing here. */
static void
tkings_before_credit( tkings_ctx_t * ctx,
                      fd_stem_t *    stem,
                      int *          charge_busy ) {
    _ = stem;
    
    /* Check HALT via CNC (set in unprivileged_init) */
    if (ctx->cnc) {
        fd_cnc_signal_t sig = fd_cnc_signal_query((fd_cnc_t *)ctx->cnc);
        if (sig == FD_CNC_SIGNAL_HALT) {
            ctx->stop_flag = 1;
            ctx->done = 1;
        }
    }
    
    /* Heartbeat — keep supervisor from marking this tile stale */
    if (ctx->cnc) {
        fd_cnc_heartbeat((fd_cnc_t *)ctx->cnc, fd_stem_tick_id(stem));
    }
    
    *charge_busy = 0;
}
```

**AFTER_CREDIT (generate + publish):**

```c
/* tkings_after_credit — fires when output link has credit.
 * Generates the next synthetic event and publishes it to tknorm. */
static void
tkings_after_credit( tkings_ctx_t *    ctx,
                     fd_stem_t *       stem,
                     fd_stem_tile_in_t * poll_in,
                     int *             charge_busy ) {
    _ = poll_in; /* tkings has 0 input links */
    
    if (ctx->stop_flag) {
        *charge_busy = 0;
        return;
    }
    
    /* Stop if all events produced */
    if (ctx->event_counter >= ctx->event_count) {
        ctx->done = 1;
        *charge_busy = 0;
        return;
    }
    
    /* Sandbox fail hook — simulate crash at specific offset */
    if (ctx->sandbox_fail_at != 0 && ctx->event_counter == ctx->sandbox_fail_at) {
        /* Record crash state via CNC app region or shared memory.
         * For now, set stop_flag and break. */
        ctx->stop_flag = 1;
        ctx->done = 1;
        FD_LOG_NOTICE(( "tkings: sandbox_fail_at triggered at offset %lu", ctx->event_counter ));
        *charge_busy = 0;
        return;
    }
    
    /* Generate synthetic event at this offset.
     * This mirrors the logic from ingest.zig:syntheticPayment() and
     * process.zig:runIngestProcess(). The fragment buffer must be
     * allocated from the dcache slot that stem_run provides. */
    
    /* Read the output dcache chunk provided by stem_run for this
     * iteration. The output link index is 0 (to tknorm). */
    
    /* Build PaymentMessage in the output slot:
     * - raw.source_offset = ctx->event_counter
     * - raw.idempotency_key = 10000 + canonical_offset
     * - raw.account_id = 42 + canonical_offset % 17
     * - raw.amount_cents = 1000 + canonical_offset (or policy_limit+1 for offset 7)
     * - raw.currency = "USD"
     * - raw.malformed = false
     * - event_hash = stableEventHash(raw)
     * - pipeline_hops = 1
     * - decision = .allow
     * - decided_by = "tkpoly" */
    
    /* Publish the fragment to output link 0 */
    fd_stem_publish( stem,
                     0,                     /* output link index */
                     ctx->event_counter,    /* tag */
                     chunk,                 /* dcache chunk pointer from stem_run */
                     PAYLOAD_SZ,            /* data size */
                     0,                     /* ctrl flags */
                     0,                     /* tsorig */
                     0 );                   /* tspub */
    
    ctx->event_counter += 1;
    ctx->produced += 1;
    
    *charge_busy = 0;
}
```

**Privileged/unprivileged init (mirrors tk_metric_tile pattern):**

```c
/* tkings_privileged_init — called before stem_run.
 * Allocates scratch space and initializes the context. */
static void
tkings_privileged_init( fd_topo_t const *      topo,
                        fd_topo_tile_t const * tile ) {
    FD_LOG_NOTICE(( "tkings_stem: privileged_init ENTER tile_id=%u", tile->id ));
    
    /* scratch_footprint and scratch_align are called by Firedancer
     * before this point to allocate scratch space. ctx is at the
     * base of that scratch. */
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tkings_ctx_t * ctx = (tkings_ctx_t *)scratch;
    
    /* Zero-initialize context */
    memset( ctx, 0, sizeof(*ctx) );
    
    /* Read config from the topo object properties or from a config
     * region. The event_count, sandbox_fail_at, and policy_limit_cents
     * must be passed in from the launcher. For now, read from a
     * known location in the tile's workspace.
     * 
     * TODO: Wire event_count from the process config file or
     * topo object property. See v2.14.S8 T12 for how the supervisor
     * writes process config to shmem. */
    
    FD_LOG_NOTICE(( "tkings_stem: privileged_init EXIT tile_id=%u", tile->id ));
}

/* tkings_unprivileged_init — called after privileged_init, before stem_run.
 * Joins CNC and sets ctx->cnc. */
static void
tkings_unprivileged_init( fd_topo_t const *      topo,
                          fd_topo_tile_t const * tile ) {
    FD_LOG_NOTICE(( "tkings_stem: unprivileged_init ENTER tile_id=%u tile_obj_id=%lu",
                    tile->id, tile->tile_obj_id ));
    
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tkings_ctx_t * ctx = (tkings_ctx_t *)scratch;
    
    /* Find and join CNC for this tile */
    ulong cnc_obj_id = tk_topo_find_tile_obj( (fd_topo_t *)topo, tile->id, "cnc" );
    if (cnc_obj_id != ULONG_MAX) {
        void * cnc_laddr = fd_topo_obj_laddr( topo, cnc_obj_id );
        ctx->cnc = cnc_laddr;
    }
    
    FD_LOG_NOTICE(( "tkings_stem: unprivileged_init EXIT tile_id=%u", tile->id ));
}
```

**tkings_run — the entry point called by Firedancer's runtime:**

```c
static void
tkings_run( fd_topo_t *      topo,
            fd_topo_tile_t * tile ) {
    FD_LOG_NOTICE(( "tkings_stem: tkings_run ENTER tile_id=%u tile_obj_id=%lu",
                    tile->id, tile->tile_obj_id ));
    
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tkings_ctx_t * ctx = (tkings_ctx_t *)scratch;
    
    /* Ensure ctx->cnc is set (from unprivileged_init).
     * If unprivileged_init hasn't run yet (crash in privileged_init),
     * ctx->cnc will be NULL — stem_run's SHOULD_SHUTDOWN will always
     * return 0, but the tile will still stop when done. */
    
    /* Allow shutdown after stem_run exits */
    tile->allow_shutdown = 1;
    
    stem_run( topo, tile );
    
    FD_LOG_NOTICE(( "tkings_stem: tkings_run EXIT tile_id=%u produced=%lu",
                    tile->id, (unsigned long)ctx->produced ));
}
```

## Task 4: Wire event_count into tkings context

**File:** `src/tickoni/c_abi/shim/tk_ingest_stem.c` (privileged_init)

The tkings tile needs to know `event_count`, `policy_limit_cents`, and `sandbox_fail_at` from the process config. Two approaches:

**Approach A (simple, recommended for first pass):** Read from a config file written to shmem by the supervisor. The supervisor writes `payment_pipeline.config` at `<shmem_path>/payment_pipeline.config`. The C code reads this file in `privileged_init`.

**Approach B (cleaner):** Store config as topo object properties set by `topo_build.zig`. Each tile's properties (scratch_footprint, etc.) are already set this way. Add `tkings.event_count`, `tkings.policy_limit_cents`, etc.

**Recommendation:** Start with Approach B — it keeps config inside the Firedancer topology and avoids file I/O in a tile that should be minimal. `topo_build.zig` already has a `tickoniTileScratchRequirements()` hook pattern for per-tile properties.

## Key Design Decisions

1. **Per-tile include pattern.** Follows `tk_metric_tile.c` exactly — define STEM macros, include `fd_stem.c`, export `stem_run`. No global callback registry. Each tile's C shim is self-contained.

2. **Producer-only callback mapping.** tkings has no input links, so `DURING_FRAG` never fires. Only `BEFORE_CREDIT` (HALT check) and `AFTER_CREDIT` (generate/publish) are used. `stem_run` handles `in_cnt == 0` by skipping input polling and only running these callbacks.

3. **Credit-driven publishing.** `AFTER_CREDIT` fires when the output link (tknorm's mcache) has available credits. This naturally implements backpressure — if tknorm is busy, stem_run won't call AFTER_CREDIT for tkings, and no events are generated.

4. **Sandbox fail hook.** Mirrors `ingest.zig`'s sandbox_fail_at logic — when `event_counter == sandbox_fail_at`, set `done = 1` and break. No actual sandbox violation needed for stem mode (the process supervisor handles crash isolation).

5. **Platform fallback.** Linux uses `TKINGST_RUN` (fd_stem). macOS/Windows use `TK_TILE_RUN` (existing `runIngestProcess()`). The migration is purely additive on Linux.

6. **Event generation logic unchanged.** The `syntheticPayment()` logic (idempotency_key, amount, malformed detection at offset 5, duplicate injection at offset 3, policy limit breach at offset 7) is identical to the spike. Only the transport layer changes.

---

## Risks and Mitigations

1. **Producer-only stem is tricky.** Firedancer's stem_run is designed for consumers. For tkings, `AFTER_CREDIT` is the primary work callback, but it only fires when there's credit on the output link. If tknorm's consumer hasn't joined yet (timing issue), stem_run may starve. Mitigation: verify tile boot order in supervisor — tkings must boot before tknorm starts consuming.

2. **Config wiring is new.** Unlike other tiles that read from shared state, tkings needs `event_count` and `policy_limit_cents` passed in from outside. Mitigation: topo object properties (Approach B) keep everything inside Firedancer's topology model.

3. **Fragment payload size.** The PaymentMessage struct (128 bytes with padding) must fit within the dcache MTU set in topology (128 bytes). Verified: PaymentMessage is exactly 128 bytes.

4. **CNC heartbeat.** The supervisor expects periodic heartbeats. tkings must call `fd_cnc_heartbeat()` in BEFORE_CREDIT (same pattern as other tiles). Mitigation: included in BEFORE_CREDIT callback.
