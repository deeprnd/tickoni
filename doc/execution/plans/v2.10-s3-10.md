# S3.10 — Deep Security: Separate Sanitize Lanes

**Status:** TODO
**Parent:** S3 — Security
**Created:** 2026-09-05

## Problem

`security-sanitize-check-all` runs all three sanitize checks sequentially in one CI job:
- `sanitize-check-fd` → clang + ASan/UBSan
- `sanitize-check-tk` → gcc + Zig ReleaseSafe
- `sanitize-check-qt` → cmake + clang + Qt6

They share no toolchain. Failure in one blocks everything.

Concrete bug: CI installs `qtbase5-dev` (Qt5) but `src/tickoni/terminal/CMakeLists.txt` line 8 does `find_package(Qt6 REQUIRED ...)`. Qt5 packages do not provide `Qt6Config.cmake`.

## Goal

Separate the three sanitize checks into independent CI lanes, each with its own setup and deps. Fix Qt6 package install.

## Files

- `.github/workflows/_ci-security-deep.yml` — CI workflow
- `justfile` — just recipes
- `contrib/security/security.sh` — shell dispatcher

## Steps

1. **CI `_ci-security-deep.yml`** — Add three independent check values:
   - `sanitize-fd` → runs `sanitize-check-fd` only (clang setup + FD deps)
   - `sanitize-tk` → runs `sanitize-check-tk` only (gcc setup + FD deps + zig)
   - `sanitize-qt` → runs `sanitize-check-qt` only (cmake+clang setup + Qt6 apt install + Qt setup)

2. **`justfile`** — Add base recipes:
   - `security-sanitize-check-fd` → calls `bash contrib/security/security.sh sanitize-check-fd`
   - `security-sanitize-check-tk` → calls `bash contrib/security/security.sh sanitize-check-tk`
   - Update `security-sanitize-check-all` to call the three individual recipes
   - Keep existing `*-linux-x86` aliases

3. **`contrib/security/security.sh`** — Already has `cmd_sanitize_check_fd` and `cmd_sanitize_check_tk` — just update usage text to document the three separate commands.

4. **Qt6 fix** — In CI `sanitize-qt` lane, install `qt6-base-dev qt6-qmake qt6-base-dev-tools` instead of `qtbase5-dev qtbase5-dev-tools qtmultimedia5-dev`.

## Verification

- `just security-sanitize-check-fd` — passes (clang + ASan/UBSan on FD)
- `just security-sanitize-check-tk` — passes (gcc + Zig ReleaseSafe)
- `just security-sanitize-check-qt` — passes (cmake + clang + Qt6)
- CI `sanitize-fd`, `sanitize-tk`, `sanitize-qt` each run independently with correct setup
