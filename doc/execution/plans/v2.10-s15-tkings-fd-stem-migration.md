## Why tkings is different from all other stem tiles

All migrated tiles are **consumers** (1-in, 0-out or 1-in, 1-out) whose stem loop is driven by fragment arrival on an input link. tkings is the **only producer-only tile** (0-in, 1-out). It has no input link, so there is no `DURING_FRAG` callback. The stem loop still runs (`stem_run` always calls `BEFORE_CREDIT` even with no input), but event generation must live in a callback that fires every iteration.

### Producer-only callback mapping

| Callback | Role |
|----------|------|
| `DURING_HOUSEKEEPING` | CNC liveness (heartbeat + BOOT→RUN) — via `stem_helpers.h` |
| `BEFORE_CREDIT` | HALT check, event generation, and **publish** |
| `SHOULD_SHUTDOWN` | `event_count` reached OR CNC HALT |
| `AFTER_CREDIT` | **NOT defined** — tkings publishes from `BEFORE_CREDIT` |

**Why publish from `BEFORE_CREDIT` instead of `AFTER_CREDIT`:**
- `BEFORE_CREDIT` runs every stem loop iteration, regardless of credits or input availability
- `AFTER_CREDIT` only runs when credits are available on an output with a reliable consumer
- If published from `AFTER_CREDIT`, the final event could be lost: when `event_count` is reached, `SHOULD_SHUTDOWN` is evaluated at the TOP of the loop. If `input_exhausted` is set in `AFTER_CREDIT` and `SHOULD_SHUTDOWN` fires before the next `AFTER_CREDIT`, the last publish never happens
- Publishing from `BEFORE_CREDIT` guarantees every event is published before the shutdown check

## Tile Context

```c
typedef struct {
    /* CNC reference for shutdown detection and counter publishing */
    void *cnc;

    /* Event generation state */
    uint64_t produced;          /* Total events produced (published) */
    uint64_t event_count;       /* Stop after this many events */
    int64_t  policy_limit_cents; /* For model request mode (test builds) */

    /* Output dcache state (computed in unprivileged_init) */
    void *   out_wksp;
    ulong    out_chunk0;
    ulong    out_wmark;
    ulong    out_chunk;

    /* Event count gating */
    int      input_exhausted;   /* Set when produced >= event_count */

    /* Workspace pointer */
    void *wksp;

    /* Diagnostic sender state (for tkdiag fan-in) */
    uint32_t diag_seq;
    int      diag_has_link;     /* 1 if a diagnostic output link exists */
} tkings_ctx_t;

#define TKINGS_CTX_ALIGN alignof(tkings_ctx_t)
```

**Step 4a — Create the main stem shim:**

**File:** `src/tickoni/c_abi/shim/tk_ingest_stem.c`

```c
/* V2.10.S15: tkings stem shim — synthetic event producer for Firedancer stem.
 *
 * tkings is the only producer-only tile (0-in, 1-out) in the Tickoni pipeline.
 * It has no input link, so there is no DURING_FRAG callback. Event generation
 * and publishing both happen in BEFORE_CREDIT, which fires every stem loop
 * iteration regardless of credits.
 *
 * Pattern: follows tk_policy_stem.c and tk_metric_tile.c.
 * Uses stem_helpers.h for CNC liveness and unprivileged init.
 */

#define STEM_NAME tkings
#define STEM_BURST 1
#define STEM_LAZY 1000000UL

#include "../../util/fd_util.h"
#include "../stem_helpers.h"
#include "../topo_run/tk_ingest_stem.h"
#include "../../../disco/stem/fd_stem.c"

/* ------------------------------------------------------------------------ */
/* Context                                                                  */
/* ------------------------------------------------------------------------ */

typedef struct {
    void *cnc;
    uint64_t produced;
    uint64_t event_count;
    int64_t  policy_limit_cents;
    void *   out_wksp;
    ulong    out_chunk0;
    ulong    out_wmark;
    ulong    out_chunk;
    int      input_exhausted;
    void *wksp;
    uint32_t diag_seq;
    int      diag_has_link;
    int      tile_idx;
} tkings_ctx_t;

#define TKINGS_CTX_ALIGN alignof(tkings_ctx_t)

STEM_CALLBACK_CONTEXT_TYPE(tkings, tkings_ctx_t, TKINGS_CTX_ALIGN)

/* ------------------------------------------------------------------------ */
/* BEFORE_CREDIT — event generation + publish                               */
/* ------------------------------------------------------------------------ */

static void
tkings_before_credit( tkings_ctx_t * ctx,
                      fd_stem_t *    stem,
                      int *          charge_busy ) {
    /* 1. HALT check */
    if (ctx->cnc && fd_cnc_signal_query((fd_cnc_t *)ctx->cnc) == FD_CNC_SIGNAL_HALT) {
        *charge_busy = 1;
        return;
    }

    /* 2. Event count exhaustion check */
    if (ctx->input_exhausted) {
        *charge_busy = 1;
        return;
    }

    /* 3. Generate synthetic event */
    /* Inline event generation — matches runIngest() from ingest.zig */
    /* syntheticPayment(ctx, ctx->produced); */
    PaymentMessage msg = {0};
    msg.offset = ctx->produced;
    msg.amount_cents = 1000;
    msg.policy_limit_cents = ctx->policy_limit_cents;

    /* 4. Publish to output dcache */
    memcpy(fd_chunk_to_laddr(ctx->out_wksp, ctx->out_chunk), &msg, sizeof(PaymentMessage));

    fd_stem_publish(stem, 0, 0, ctx->out_chunk, sizeof(PaymentMessage), 0, 0, 0);

    ctx->out_chunk = fd_dcache_compact_next(
        ctx->out_chunk, sizeof(PaymentMessage),
        ctx->out_chunk0, ctx->out_wmark
    );

    /* 5. Publish CNC counter */
    stk_publish_counter(ctx->cnc, 0, ctx->produced);

    /* 6. Diagnostic fragment (if link exists) */
    if (ctx->diag_has_link) {
        /* Publish to tkdiag via UNRELIABLE diagnostic output link */
        tk_diag_fragment_t diag = {
            .tile_id = (uint8_t)ctx->tile_idx,
            .tile_type = TK_DIAG_TYPE_INGEST,
            .seq = ++ctx->diag_seq,
            .events_processed = ctx->produced,
            .backpressure_waits = 0,
        };
        /* stem_diag.h pattern: fd_stem_publish to UNRELIABLE link */
    }

    /* 7. Update produced counter */
    ctx->produced += 1;

    /* 8. Check exhaustion */
    if (ctx->produced >= ctx->event_count) {
        ctx->input_exhausted = 1;
    }

    *charge_busy = 0;
}

STEM_CALLBACK_BEFORE_CREDIT(tkings, tkings_before_credit)

/* ------------------------------------------------------------------------ */
/* SHOULD_SHUTDOWN — event exhaustion + HALT                                 */
/* ------------------------------------------------------------------------ */

#define STEM_CALLBACK_SHOULD_SHUTDOWN(ctx) \
  ( (ctx)->input_exhausted || \
    ( (ctx)->cnc && fd_cnc_signal_query( (fd_cnc_t *)(ctx)->cnc ) == FD_CNC_SIGNAL_HALT ) )

/* ------------------------------------------------------------------------ */
/* DURING_HOUSEKEEPING — CNC liveness                                       */
/* ------------------------------------------------------------------------ */

#define STEM_CALLBACK_DURING_HOUSEKEEPING(ctx) stk_cnc_liveness( (ctx)->cnc )

/* ------------------------------------------------------------------------ */
/* Privileged init                                                          */
/* ------------------------------------------------------------------------ */

static void
tkings_privileged_init( void * wksp, void * cfg ) {
    tkings_ctx_t * ctx = (tkings_ctx_t *)stk_alloc_ctx( wksp, STEM_CTX_SIZE, TKINGS_CTX_ALIGN );

    /* Zero the context — unprivileged_init fills in the rest */
    memset(ctx, 0, STEM_CTX_SIZE);

    /* Set policy_limit_cents from config (if available) */
    if (cfg) {
        ctx->policy_limit_cents = *(int64_t *)cfg;
    }
}

/* ------------------------------------------------------------------------ */
/* Unprivileged init                                                        */
/* ------------------------------------------------------------------------ */

static void
tkings_unprivileged_init( tkings_ctx_t * ctx,
                          void *         wksp,
                          void *         topo,
                          int            tile_idx,
                          fd_topo_tile_t * tile ) {
    STK_UNPRIV_INIT(ctx, wksp, topo, tile_idx, tile, "tkings");

    /* Validate: tkings has exactly 1 output link, 0 input links */
    if (tile->out_cnt != 1) {
        FD_LOG_ERR(( "tkings_unprivileged_init: expected out_cnt==1, got %lu", tile->out_cnt ));
    }
    if (tile->in_cnt != 0) {
        FD_LOG_ERR(( "tkings_unprivileged_init: expected in_cnt==0, got %lu", tile->in_cnt ));
    }

    /* Read event_count from the workspace's pipeline config */
    ctx->event_count = stk_read_event_count(wksp, tile_idx);

    /* Set up output dcache from link 0 */
    ulong out_chan_id = tile->out_link_id[0];
    ulong out_dcache_lladdr = fd_topo_find_dcache(topo, out_chan_id);
    ctx->out_wksp = c_abi.topob.topoWkspPtr((fd_topo_t *)topo,
                        c_abi.topob.topoFindWorkspace((fd_topo_t *)topo, tile->wksp_id));
    ctx->out_chunk0 = fd_dcache_compact_first_chunk(ctx->out_wksp, out_dcache_lladdr, ctx->out_wmark);

    /* Find the CNC object for this tile */
    ctx->cnc = c_abi.topob.topoObjLaddr((fd_topo_t *)topo, c_abi.topob.topoTileCncObjId(tile));

    /* Check for diagnostic link (tkdiag fan-in) */
    ctx->diag_has_link = (tile->out_cnt > 1) ? 1 : 0;
    ctx->tile_idx = tile_idx;
}

/* ------------------------------------------------------------------------ */
/* Run entry point                                                          */
/* ------------------------------------------------------------------------ */

static int
tkings_run_entry( void * wksp, void * topo, void * tile, int tidx ) {
    tkings_ctx_t * ctx = (tkings_ctx_t *)stk_get_ctx();

    /* Verify CNC is joined (should have been done in privileged_init or
       by the stem infrastructure). If not, try to find it. */
    if (!ctx->cnc) {
        /* CNC should have been resolved in unprivileged_init */
        FD_LOG_ERR(( "tkings_run_entry: CNC not joined" ));
    }

    /* The stem loop is provided by fd_stem.c's stem_run() */
    return tkings_run(wksp, topo, tile);
}

/* ------------------------------------------------------------------------ */
/* TK_INGEST_RUN — the fd_topo_run_tile_t descriptor                        */
/* ------------------------------------------------------------------------ */

fd_topo_run_tile_t TK_INGEST_RUN = {
    .name                     = "tkings",
    .keep_host_networking     = 0,
    .allow_connect            = 0,
    .allow_renameat           = 0,
    .rlimit_file_cnt          = 0,
    .rlimit_address_space     = 0,
    .rlimit_data              = 0,
    .rlimit_nproc             = 0,
    .for_tpool                = 0,
    .max_event_sz             = NULL,
    .populate_allowed_seccomp = NULL,
    .populate_allowed_fds     = NULL,
    .scratch_align            = tkings_tile_scratch_align,
    .scratch_footprint        = tkings_tile_scratch_footprint,
    .loose_footprint          = NULL,
    .privileged_init          = tkings_privileged_init,
    .unprivileged_init        = tkings_unprivileged_init,
    .run                      = tkings_run_entry,
    .rlimit_file_cnt_fn       = NULL,
};

/* Run-tile accessors (for tile_run.c) */
STK_DEFINE_RUN_TILE_ACCESSORS(tkings)
```

## Key Design Decisions

1. **Publish from `BEFORE_CREDIT`, not `AFTER_CREDIT`.** Guarantees every event is published before shutdown. The stem loop calls `BEFORE_CREDIT` every iteration; `AFTER_CREDIT` may be skipped if `SHOULD_SHUTDOWN` fires.

2. **Inline event_count check in `BEFORE_CREDIT`.** There's no `AFTER_FRAG` to call `STK_EVENT_EXHAUSTED` from. The check is two lines: after publish, compare `produced >= event_count`, set `input_exhausted`.

3. **No `DURING_FRAG`.** 0 input links means no `stem_run` callback is generated for `DURING_FRAG`. This is the simplest stem pattern after `SHOULD_SHUTDOWN` only.

4. **Diagnostic fan-in preserved.** tkings continues to send diagnostic fragments to tkdiag via an unreliable link, using the same `stem_diag.h` pattern as the process-mode `DiagSender`.

5. **Model request mode deferred.** The test-build `ModelRequestSource` path is NOT migrated in this step. The stem tile produces plain `PaymentMessage` events only.

6. **Event generation logic unchanged.** The `runtime.syntheticPayment()` function and its determinism are unchanged. The stem shim calls the same function at the same offset, producing identical events in the same order.

## Summary

| Tile | Before | After | Callbacks |
|------|--------|-------|-----------|
| `tkings` | 0-in, 1-out, `LaunchMode.tile`, `process_fn` | 0-in, 1-out, `LaunchMode.stem`, `process_fn = null` | `DURING_HOUSEKEEPING` (liveness), `BEFORE_CREDIT` (generate + publish), `SHOULD_SHUTDOWN` (exhaustion + HALT) |

This is the **first producer-only tile** in the fd_stem migration. All previously migrated tiles (tknorm, tkdedu, tkpoly, tkaudt, tkdiag, tkmodl, tkagnt, tkdisp, tkcase, tktool, tkadpt) are consumers. tkings is the sole producer, and its migration establishes the pattern for any future producer tiles (tkrepl re-injection feeds into tkings, not a second producer).
