## Gap Analysis

### What exists today

| Component | Current state |
|-----------|---------------|
| tknorm process-mode code | `normalize.zig` — 39 lines, reads from q_ing_norm, validates framing, computes stableEventHash, publishes to q_norm_dedu |
| tknorm in tile_registry | `process_fn = normalizeProcess`, in_cnt=1, out_cnt=1 |
| tknorm in topology spec | tile index 1, name="tknorm", channels: [tkings→tknorm (depth=64, mtu=128), tknorm→tkdedu (depth=64, mtu=128)] |
| tknorm in supervisor spawn | Uses `__tile-run` (not `__stem-run`) |
| tknorm stem files | `tk_normalize_stem.c` — DOES NOT EXIST. `tk_norm_stem.h` — DOES NOT EXIST |
| audit_schema.h | Contains TILE_ID_TKNORM, RawPayment, PaymentMessage, PolicyOutcome, PAYMENT_MSG_SIZE (56 bytes) |
| tkaudt stem | `tk_audit_stem.c` (435 lines, 1-in/0-out, DURING_FRAG only) — reference implementation |
| metric stem | `tk_metric_tile.c` (219 lines, 0-in/0-out, observer) — reference for delegating to existing tile |

### What's missing

The tknorm stem tile needs to implement:

1. **Context struct** (`tknorm_ctx_t`) — counters (normalized, invalid), flags (input_exhausted), output tracking (output_ready, output_sz, output_chunk), workspace pointer for dcache writes
2. **Scratch layout** — `tknorm_scratch_align()` = 8 (alignof of context), `tknorm_scratch_footprint()` = sizeof(ctx) + alignment + PaymentMessage output buffer (56 bytes)
3. **DURING_FRAG callback** — Read PaymentMessage from input dcache, validate framing (currency=USD, amount_cents>0, not malformed), compute FNV-1a hash, stamp decision/decided_by, track normalized/invalid counters, set output_ready
4. **AFTER_CREDIT callback** — If output_ready, publish to output dcache via fd_stem_publish, reset output_ready, charge_busy=0
5. **SHOULD_SHUTDOWN macro** — CNC HALT + idle threshold (10000 ticks) + event_count exhaustion
6. **privileged_init** — Get ctx from scratch, set wksp from input mcache, init counters
7. **unprivileged_init** — Find CNC object, set ctx->cnc
8. **tknorm_run entry point** — Get ctx from scratch, enter stem loop
9. **fd_topo_run_tile_t** — TK_NORM_RUN with all callbacks wired
10. **Shared header** — Extern declaration for TK_NORM_RUN, tk_get_norm_run_tile(), scratch footprint accessor
11. **Dispatch chain** — tile_is_norm() in tile_run.c
12. **Supervisor wiring** — detect tknorm for __stem-run, pass TKNORM_EVENT_COUNT env
13. **Build wiring** — topo_run.shims, shims.zim, codec.zig, topob.c

### Key differences from tkaudt

| Aspect | tkaudt (1-in, 0-out) | tknorm (1-in, 1-out) |
|--------|----------------------|----------------------|
| Output links | 0 — no AFTER_CREDIT needed | 1 — needs AFTER_CREDIT for publish |
| Audit events | Builds complex AuditEvent in scratch ring buffer | Simple pass-through: reads msg, stamps decision, forwards as-is |
| Hash chain | SipHash1-3 chain over audit records | FNV-1a hash per event (same as Zig stableEventHash) |
| Decision logic | Reads decision FROM input (from tkpoly) | Makes decision IN stem (validFraming → malformed_drop or pass) |
| Output buffer | N/A | Scratch-reserved PaymentMessage slot for fd_stem_publish |

### Key differences from metric tile

Metric is an observer (0-in, 0-out) that delegates to Firedancer's `fd_metric_tile.c`. tknorm is a pipeline tile (1-in, 1-out) that must implement its own callbacks — it cannot delegate.

### Shared stem infrastructure: `stem_helpers.h`

Extracted from tkaudt. Common boilerplate identical across ALL Tickoni stem tiles:

| Helper | What it does | Lines saved per tile |
|--------|-------------|---------------------|
| `STK_GET_CTX` | `fd_topo_obj_laddr` + align + cast | 2-3 lines × 3 places |
| `stk_derive_wksp` | wksp from input mcache | 5 lines |
| `stk_find_cnc` / `stk_publish_progress` | CNC lookup, progress write | 3-4 lines each |
| `STK_UNPRIV_INIT` | unprivileged_init CNC setup | 5 lines |
| `STK_EVENT_EXHAUSTED` | event_count → input_exhausted | 2 lines |
| `stk_validate_frag` + `stk_chunk_to_gaddr` | DURING_FRAG preamble | 8 lines |

**Total lines eliminated per tile: ~30-40 lines of identical boilerplate.**

Usage in each tile: `#include "stem_helpers.h"` then replace the boilerplate with the macros/inline helpers above. Tile-specific logic (ctx struct, hash, validation, decision) stays in the tile's own file.

**Files created by this refactoring:** `src/tickoni/c_abi/shim/stem_helpers.h`

**FNV-1a hash** (tile-specific — stays in this file):

```c
/* FNV-1a 64-bit hash — must match normalize.zig:stableEventHash exactly */
static uint64_t
tknorm_stable_event_hash( RawPayment const * raw ) {
    uint64_t h = 0xcbf29ce484222325ULL;  /* FNV-1a offset basis */

    /* Hash idempotency_key (u64, byte by byte, little-endian) */
    { uint64_t x = raw->idempotency_key; for (int i = 0; i < 8; i++) { h ^= (x & 0xff); h *= 0x100000001b3ULL; x >>= 8; } }

    /* Hash account_id (u32, byte by byte, little-endian) */
    { uint32_t x = raw->account_id; for (int i = 0; i < 4; i++) { h ^= (x & 0xff); h *= 0x100000001b3ULL; x >>= 8; } }

    /* Hash amount_cents (i64 → u64 bitcast, byte by byte, little-endian) */
    { uint64_t x = (uint64_t)(int64_t)raw->amount_cents; for (int i = 0; i < 8; i++) { h ^= (x & 0xff); h *= 0x100000001b3ULL; x >>= 8; } }

    /* Hash currency (3 bytes) */
    for (int i = 0; i < 3; i++) { h ^= raw->currency[i]; h *= 0x100000001b3ULL; }

    return h;
}

typedef struct {

static ulong
tknorm_scratch_footprint_tile( fd_topo_tile_t const * tile ) {
    (void)tile;
    ulong footprint = fd_ulong_align_up( sizeof(tknorm_ctx_t), TKNORM_CTX_ALIGN );

    return footprint;
}

/* ─── Callbacks ─── */

static void
tknorm_privileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tknorm_ctx_t * ctx = STK_GET_CTX(tknorm_ctx_t, scratch, TKNORM_CTX_ALIGN);

    ctx->normalized = 0;
    ctx->invalid = 0;
    ctx->output_ready = 0;
    ctx->idle_ticks = 0;
    ctx->cnc = NULL;
    ctx->event_count = 0;
    ctx->input_exhausted = 0;

    /* Derive workspace pointer from input mcache */
    ctx->wksp = stk_derive_wksp(topo, tile, 0);

    /* Point output_msg at scratch block after context */
    ulong ctx_end = fd_ulong_align_up( (ulong)ctx + sizeof(tknorm_ctx_t), alignof(PaymentMessage) );
    ctx->output_msg = (PaymentMessage *)ctx_end;

    /* Read event_count from environment */
    {
        const char *env = getenv("TKNORM_EVENT_COUNT");
        if (env) {
            ctx->event_count = strtoull(env, NULL, 10);
            FD_LOG_NOTICE(( "tknorm: event_count=%lu from env", (unsigned long)ctx->event_count ));
        }
    }

    FD_LOG_NOTICE(( "tknorm: privileged init ctx=%p output=%p wksp=%p",
                    ctx, ctx->output_msg, ctx->wksp ));
}

static void
tknorm_unprivileged_init( fd_topo_t const * topo, fd_topo_tile_t const * tile ) {
    (void)topo;
    (void)tile;

    void * scratch = fd_topo_obj_laddr( (fd_topo_t *)topo, tile->tile_obj_id );
    tknorm_ctx_t * ctx = STK_GET_CTX(tknorm_ctx_t, scratch, TKNORM_CTX_ALIGN);

    /* Shared boilerplate: find CNC and set ctx->cnc */
    STK_UNPRIV_INIT(topo, tile, ctx);

    FD_LOG_NOTICE(( "tknorm: unprivileged init tile_id=%lu cnc=%p", tile->id, ctx->cnc ));
}

static void
tknorm_during_frag( tknorm_ctx_t * ctx,
                    ulong          in_idx,
                    ulong          seq,
                    ulong          sig,
                    ulong          chunk,
                    ulong          sz,
                    ulong          ctl ) {
    (void)in_idx; (void)seq; (void)sig; (void)ctl;

    /* Shared boilerplate: empty check, size check, wksp check, chunk→gaddr */
    if (!stk_validate_frag(sz, PAYMENT_MSG_SIZE, ctx->wksp))
        return;
    PaymentMessage const * msg_in = stk_chunk_to_gaddr(ctx->wksp, chunk);

    /* Copy input to output buffer */
    memcpy(ctx->output_msg, msg_in, sizeof(PaymentMessage));

    /* Validate framing: currency must be "USD", amount_cents > 0, not malformed */
    int valid = 1;
    if (msg_in->raw.malformed) valid = 0;
    if (memcmp(&msg_in->raw.currency, "USD", 3) != 0) valid = 0;
    if (msg_in->raw.amount_cents <= 0) valid = 0;

    /* Compute stable event hash */
    ctx->output_msg->event_hash = tknorm_stable_event_hash(&msg_in->raw);

    /* Stamp pipeline_hops */
    ctx->output_msg->pipeline_hops += 1;

    if (!valid) {
        ctx->output_msg->decision = (uint8_t)POLICY_MALFORMED_DROP;
        memcpy(ctx->output_msg->decided_by, TILE_ID_TKNORM, sizeof(TILE_ID_TKNORM));
        ctx->invalid += 1;
    } else {
        ctx->output_msg->decision = (uint8_t)POLICY_ALLOW;
        memcpy(ctx->output_msg->decided_by, TILE_ID_TKNORM, sizeof(TILE_ID_TKNORM));
        ctx->normalized += 1;
    }

    /* Shared boilerplate: event-count gating */
    STK_EVENT_EXHAUSTED(ctx, ctx->event_count, ctx->normalized + ctx->invalid);

    /* Mark output ready */
    ctx->output_ready = 1;
    ctx->output_sz = PAYMENT_MSG_SIZE;
    /* Chunk offset will be set in after_credit when we allocate from output dcache */

    /* Shared boilerplate: progress publishing */
    stk_publish_progress(ctx->cnc, ctx->normalized + ctx->invalid);
}

static void
tknorm_after_credit( tknorm_ctx_t *    ctx,
                     fd_stem_t *       stem,
                     fd_stem_tile_in_t * poll_in,
                     int *             charge_busy ) {
    (void)poll_in;

    if (ctx->output_ready) {
        /* Allocate from output dcache */
        ulong out_chunk = fd_dcache_find_free( stem, 0, ctx->output_sz, ctx->output_sz );
        if (out_chunk) {
            /* Copy output message to dcache slot */
            void * dst = fd_wksp_laddr_fast(ctx->wksp, out_chunk * FD_CHUNK_ALIGN);
            memcpy(dst, ctx->output_msg, ctx->output_sz);

            /* Publish */
            fd_stem_publish(stem, 0, ctx->output_sz, out_chunk, ctx->output_sz, 0, 0, 0);
        }

        ctx->output_ready = 0;
    }

    *charge_busy = 0;
}

/* ─── Run entry point ─── */

static void
tknorm_run( fd_topo_t *      topo,
            fd_topo_tile_t * tile ) {
    void * scratch = fd_topo_obj_laddr( topo, tile->tile_obj_id );
    tknorm_ctx_t * ctx = (tknorm_ctx_t *)fd_ulong_align_up( (ulong)scratch, TKNORM_CTX_ALIGN );

    ulong cnc_obj_id = tk_topo_find_tile_obj( topo, tile->id, "cnc" );
    if (FD_UNLIKELY(cnc_obj_id == ULONG_MAX))
        FD_LOG_ERR(( "tknorm: CNC object not found for tile %lu", tile->id ));
    ctx->cnc = fd_topo_obj_laddr( topo, cnc_obj_id );

    tknorm_run(topo, tile);  /* stem_run loop */
}
```

## Risks and Mitigations

1. **FNV-1a hash mismatch:** The C inline FNV-1a must produce identical output to Zig's `stableEventHash`. **Mitigation:** Write a unit test that computes the hash in both C and Zig for the same input and verifies equality. The hash uses FNV-1a offset basis `0xcbf29ce484222325` and prime `0x100000001b3` — same as Zig.

2. **Framing validation differences:** C must validate exactly the same conditions as Zig's `validFraming()`: `!malformed`, `currency=="USD"`, `amount_cents > 0`. **Mitigation:** The C validation mirrors the Zig code exactly. The integration test verifies all fixture events pass the same way in both paths.

3. **Output dcache publish:** tknorm has 1 output link (to tkdedu), so `AFTER_CREDIT` must allocate from the output dcache and call `fd_stem_publish`. **Mitigation:** Follow the tknorm spike plan's pattern. The output buffer is scratch-allocated. `fd_stem_publish` signature: `(stem, out_idx, data_sz, data_chunk, wire_sz, tag, 0, 0)`.

4. **Idle threshold timing:** The C stem uses 10000 ticks for idle shutdown (same as tkaudt). **Mitigation:** The `event_count` gating provides a deterministic exit path, making idle threshold irrelevant for test scenarios.

5. **Scratch footprint mismatch:** If topob.c and the stem tile compute different scratch sizes, the topology won't build correctly. **Mitigation:** Both use `sizeof(tknorm_ctx_t)` + alignment + `sizeof(PaymentMessage)` × 1.
