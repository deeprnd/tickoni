# V0.37: Firedancer Integration

**Labels:** `type/epic`, `area/platform`
**GitHub Issue:** [70](https://github.com/deeprnd/tickoni/issues/70)

Tickoni is built on Firedancer infrastructure — shared-memory queues, topology
builder, workspace discipline, lifecycle, metrics, and diagnostics — but the
current codebase still entangles the Firedancer validator build with the
Tickoni supervisor build, pulls Solana validator semantics into Tickoni-owned
code, and lacks a clean product topology. This epic hardens the integration by
separating build paths, removing Solana/Agave references from Tickoni-owned
code, and establishing a clean tile topology that excludes all validator tiles.

## Product Intent

Operators and CI need to build and test Tickoni without Agave, Solana schemas,
or validator tile code on the system. Tickoni reuses the Firedancer infrastructure
library substrate — not the validator protocol layer. This epic delivers a build
pipeline and product topology that enforce that boundary end-to-end.

## Users And Jobs

- [CI Operator]: Build and test Tickoni without Agave or Solana-specific build
  dependencies installed
- [Developer]: Add Tickoni code that uses Firedancer substrate without
  accidentally pulling in validator tile names or Solana schemas
- [Reviewer]: Verify Tickoni-owned code has no Solana/Agave references

## Success Metrics

- Tickoni builds and passes all tests without Agave or Solana tooling on the path
- No Agave/Flamenco/Solana references in Tickoni-owned .zig, .c, and .h files
- Product topology registers only Tickoni tile IDs; validator tile names are excluded
- Firedancer C infrastructure libraries build standalone without the validator binary

## Demo Moment

- Command or flow:
  1. Build Firedancer C libs only: `just build-fd`
  2. Build Tickoni supervisor: `just build-tk`
  3. Run Tickoni tests: `just test-unit-tk && just test-integration-tk`
  4. Verify no Solana references: `grep -ri 'agave\|flamenco\|solana' src/app/tickoni/ src/tickoni/`
- Expected result: All steps pass; Tickoni is fully independent of Agave and Solana

## Scope

### In Scope

- Remove Agave gating from Tickoni build system

- Changes to Firedancer upstream
- Adding new Tickoni tiles
- CaseOps UI, `tkapi`, or HTTP handler changes

- Agent runtime changes

### How Many Stories

Five stories cover the full scope: build isolation, integration tests, topology
hardening, code cleanup, and documentation/closure. Each story is independently
verifiable — build isolation can be confirmed without the test suite, and
topology cleanup is independent of code cleanup.

### Decomposition Rules

1. **Independent delivery**: each story must be independently verifiable.
2. **One capability per story**: build path, test boundary, topology registry,
   code cleanliness, and documentation are each a separate capability.
3. **Split by capability lifecycle**: S1 = build path, S2 = runtime integration
   tests, S3 = product registry, S4 = code cleanliness, S5 = docs and closure.
4. **Closure story**: S5 handles evidence, demo, and quality gates.
5. **Domain boundaries**: build system and tests are separate from topology and
   code cleanup; each has its own verification method.

### Bad Splits (Avoid)

- Merging build isolation and code cleanup — different verification methods.
- Putting integration tests inside the topology story — test coverage and
  topology correctness are separate concerns.
- Combining documentation into any implementation story — docs must come last.

## Dependencies And Decisions

- No prerequisite epics.
- Decision: Firedancer C infrastructure libraries remain buildable and linkable
  by Tickoni; the Solana protocol layer (flamenco, validator tiles) is excluded
  from the Tickoni build path.
- Decision: `just build-fd` builds only Firedancer C infrastructure libs; the
  full validator binary is a separate, non-Tickoni build.
- Decision: No changes to Firedancer upstream; all changes are Tickoni-owned.
- Decision: Comments referencing Solana for comparison/context are acceptable;
  only substantive code references must be cleaned.
