# V0.0: Proof Of Correctness

**Status: Done**
**Milestone:** M0
**Labels:** `epic`, `area/platform`, `area/security`, `area/trust`, `area/audit`

This is the trust foundation. V0.0 gives Tickoni a property that most systems
can't claim: it can prove it works the same way every time.

Not "we believe it's correct" — "here's the replay, watch it produce the same
result twice." In a world of unreliable AI and unpredictable systems, that's
not a nice-to-have. That's the product.

---

## Product Intent

Users (and auditors) don't trust systems they can't verify. V0.0 builds a
runtime that can authenticate, normalize, deduplicate, and audit financial
events in a way that produces identical results across runs — and a replay
mechanism that proves it.

V0.0 proves Tickoni can:
- Accept synthetic financial events with stable framing and source attribution
- Normalize events to canonical facts with content-stable hashes
- Deduplicate by idempotency key and content hash, not timing or insertion order
- Evaluate capability envelopes with explicit allow/deny/require-approval outcomes
- Record append-only, hash-chained audit events that form a verifiable chain
- Replay a captured run with external effects disabled and detect divergence
- Report health and diagnostic state without reading internal tile state

This is not an implementation detail. The replay-and-prove capability is the
foundation that makes every later user-facing increment trustworthy. Without V0.0,
M1's "safe to try" is just a demo with no way to verify it.

## User Story

As a user who wants to test an investment idea without risk, I need to trust
that the system I'm testing with actually works — not just that it produces
output, but that it produces the *same* output every time. As an auditor or
operator, I need to be able to replay any run and verify the audit chain,
without relying on the system's word.

## Success Demo

One offline command:
1. Feeds a synthetic financial event through the full pipeline
2. Produces an audit record with hash chain
3. Replays the same event sequence with external effects disabled
4. Reports zero divergence

The demo proves the entire event path is deterministic and verifiable.

## Non-Goals

- no user-facing interface or API
- no live market data, broker, or payment integration
- no financial correctness validation — V0.0 proves structural correctness,
  not business logic correctness

## Evidence Gate

- Identical source event payloads produce identical canonical content hashes
  across process runs.
- verifyChain passes on any journal produced by a normal run.
- Replay of an unmodified captured run reports zero divergences.
- Replay never calls a network endpoint, database, or external system.
