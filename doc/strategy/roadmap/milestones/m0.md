# M0: The Trust Foundation

## Description

M0 establishes Tickoni's first verifiable property: a system that can prove
it works the same way every time.

```text
synthetic event -> full pipeline -> hash-chained audit -> replay verification
```

Before M0, Tickoni is code. After M0, it is a system that can demonstrate
structural correctness — accepting events, normalizing them to stable facts,
deduplicating deterministically, enforcing policy, recording an auditable
chain, and replaying without external effects to prove the output is identical.

This is the trust foundation. Every user-facing increment that follows depends
on it. Without M0, M1's "safe to try" is a demo with no way to verify it.

## Included Epics

Product increments:

- `V0.0`: Proof Of Correctness (supervisor, ingestion, normalization,
  deduplication, policy, audit, replay, metrics, diagnostics)

## Why This Is A Milestone

M0 crosses the threshold from implementation to verifiable product.

Before M0: the system is code that happens to process events. No one can
independently verify that it works the same way on a different run, a different
machine, or after a code review.

After M0: the system can replay a captured run with external effects disabled
and prove zero divergence. The audit chain can be verified by anyone. The
normalization and deduplication logic is content-stable — identical inputs
produce identical outputs regardless of timing or insertion order.

M1's "safe to try" depends on this property. A user can't be confident they're
testing an investment idea in a reliable environment unless the underlying
runtime has been proven correct first.

## Completion Signal

One offline command feeds a synthetic event through the full pipeline, produces
a hash-chained audit record, replays the event sequence with external effects
disabled, and reports zero divergence.

Internal completion checks:

- Identical source event payloads produce identical canonical content hashes
  across process runs.
- verifyChain passes on any journal produced by a normal run.
- Replay reports zero divergences for unmodified captured runs.
- Replay performs no external system calls.
