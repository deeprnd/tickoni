# M3: Release-Ready

## Description

M3 is where Tickoni hands the keys to the operator.

We built a system that makes investment proposals responsibly — bounded, auditable, policy-checked. Responsible for whom? If only the Tickoni team can operate it, we built an internal tool, not a product.

M3 answers with three changes working together. First, a native investment terminal — a dense, keyboard-first Qt desktop application that turns investment intent into a policy-checked, explainable, and replayable proposal. The operator opens it and sees normalized intent, account state, basket, policy outcome, before/after impact, proposal identity, and replay status — without reading fixture output, audit JSONL, or diagnostic files. Second, a distributable package that ships on Linux, macOS, and Windows — download, verify the SHA256, install without admin, run `tickoni doctor`, execute a deterministic paper demo. No Linux workstation required. "Install without privileges" is a trust signal that most financial products cannot make. Third, a 14-layer security chain that measures security instead of promising it — CodeQL, CBMC proofs, seccomp validation, fuzzing, property invariants, SBOM generation, binary hardening — one command, every layer produces a real result.

These are not separate features. They are three perspectives on the same transformation: from a runtime engineers build to a product operators trust. The installer delivers the terminal. The terminal runs inside the runtime whose boundaries M2 proved. The security chain proves those boundaries are real, not aspirational.

- `V3.23`: Distribute a Runnable Tickoni Package with Installation, Verification, and Update Flow

## Why This Is A Milestone

M2 established real and enforced tile runtime boundaries. M3 makes those boundaries visible, distributable, and provable.

The milestone isn't "we have an installer." The milestone is "the system we built is now operable by anyone who can download and verify software, and provable by anyone who can run a CI check."

- **The terminal** (V3.19): A native desktop app, not a browser dashboard. Dense, keyboard-driven, function-first. It turns investment intent into a policy-checked proposal in one workflow — normalized intent, policy checks, before/after impact, proposal identity, replay proof. The operator doesn't read audit JSONL to understand what happened. The terminal shows it. This is the front door. M2's boundaries are the house.
- **The installer** (V3.23): A distributable package on Linux, macOS, and Windows — per-user scoped, checksum-verified, uninstallable with evidence preserved. The trust surface (version, platform tier, isolation tier) is shipped, not documented.
- **The security chain** (V3.35): Security that is measurable, not aspirational. 14 CI layers with deterministic pass/fail. No "tool not found," no skips, no no-op wrappers. The operator sees the full security posture at a glance.

M3 closes the loop: build a professional terminal, ship it as a distributable package, prove its security with measurable tooling. These are prerequisites for the proof and trust surfaces in M4.

## Completion Signal

M3 is complete when:

- A user downloads a release artifact, verifies its SHA256, installs without admin privileges, runs `tickoni doctor`, and executes a deterministic paper demo — all in one session, on any supported platform.
- The native Tickoni terminal renders the full investment workflow: normalized intent, account state, basket, policy outcome, before/after impact, proposal identity, and replay status — without requiring the operator to read fixture output, audit JSONL, replay logs, or diagnostic files.
- The restricted `SOXL` scenario shows the exact denied reason and exposes no quote or paper-action affordance for the rejected instrument.
- `just security-check-all` produces deterministic pass/fail from all 14 security layers — no "tool not found," no skips, no no-op wrappers.
- The installed runtime produces identical replay results to the source build for the same fixture.
- Uninstall removes binaries but preserves audit and replay evidence by default.
